## Java 托管资产启动契约

### 固定发行资产

JDT Language Server 采用 Eclipse snapshot 的不可变文件名（不是 `latest`）。经过 Temurin 21 实际启动验证，应使用 1.55.0；1.62.0 snapshot 的 Eclipse bundle 要求 JavaSE 25，不能与 Java 21 配套：

```text
URL: https://download.eclipse.org/jdtls/snapshots/jdt-language-server-1.55.0-202512042336.tar.gz
SHA-256: cfb2f2be82b28dce4debdb05f76e3bd408a05cf8d3cbd9b8da09a7f3f5826552
archiveFormat: tarGz
```

该归档解压后直接以服务器根目录为安装目录，已核验的关键路径为：

```text
plugins/org.eclipse.equinox.launcher_1.7.100.v20251111-0406.jar
config_mac/
config_mac_arm/
```

Java 运行时使用 Eclipse Temurin 21.0.12.1+1 JRE：

```text
darwin-arm64
URL: https://github.com/adoptium/temurin21-binaries/releases/download/jdk-21.0.12.1%2B1/OpenJDK21U-jre_aarch64_mac_hotspot_21.0.12.1_1.tar.gz
SHA-256: dec50fc6f9fcd4fe3ae8cabf5a5fa68f6afc48841f7698e468e9aa5d54beed84

darwin-x64
URL: https://github.com/adoptium/temurin21-binaries/releases/download/jdk-21.0.12.1%2B1/OpenJDK21U-jre_x64_mac_hotspot_21.0.12.1_1.tar.gz
SHA-256: 6717ec641fd9ce0bb209ca083ee23b42202ac68cb6fcc5753496e0e4a0f41989
```

Temurin macOS JRE 归档的可执行文件相对路径为：

```text
jdk-21.0.12.1+1-jre/Contents/Home/bin/java
```

已下载并核验两个架构归档：arm64 SHA-256 为 `dec50fc6f9fcd4fe3ae8cabf5a5fa68f6afc48841f7698e468e9aa5d54beed84`，x64 SHA-256 为 `6717ec641fd9ce0bb209ca083ee23b42202ac68cb6fcc5753496e0e4a0f41989`；两个归档都包含上述 `bin/java`，且 `tar -tvzf` 未发现符号链接条目，因此可由当前安全 tar 解包器安装。manifest 的 `executablePath` 必须写对应架构资产实际的顶层目录名，不得使用通配符。

JDT LS 1.55.0 + arm64 Temurin 21.0.12.1 的真实 stdio `initialize` 已返回 `serverInfo.name=JDT Language Server (Standard)`、`serverInfo.version=1.55.0-SNAPSHOT`，并提供 hover、definition、references、workspaceSymbol 等能力。此前 1.62.0 + Java 21 的验证结果为 exit 13，日志明确要求 JavaSE 25，因此不可作为本组合发布。

### JDT LS 启动参数

JDT LS 必须由托管 JRE 启动，不应依赖 PATH 上的 `java`。启动参数模板如下（`${...}` 由 `ApplicationLspService` 在安装目录和工作区私有数据目录确定后替换）：

```text
-Declipse.application=org.eclipse.jdt.ls.core.id1
-Dosgi.bundles.defaultStartLevel=4
-Declipse.product=org.eclipse.jdt.ls.core.product
-Dlog.protocol=true
-Dlog.level=ALL
-Xms1g
--add-modules=ALL-SYSTEM
--add-opens
java.base/java.util=ALL-UNNAMED
--add-opens
java.base/java.lang=ALL-UNNAMED
-jar
${executablePath}
-configuration
${installDir}/config_mac_arm   # darwin-arm64
${installDir}/config_mac       # darwin-x64
-data
${workspaceData}
```

`-data` 必须由 `lsp_workspace_data_dir` 返回，目录位于应用 `app_data_dir/lsp-workspaces/<sha256(workspace-root)>`，不得写进项目目录。不同工作区必须得到不同目录，同一工作区重启后应复用该目录。

### 前端启动器实现约束

当前复合运行时分支会把 `packagePath` 自动前置到 `launchArgs`。Java descriptor 的参数已经包含 `-jar ${executablePath}`，因此 Java 分支必须满足以下任一实现方式：

1. 复合运行时分支仅在 `launchArgs` 不含 `${executablePath}` 时自动前置服务器路径；或者
2. descriptor 不声明 `-jar`，由复合运行时分支负责前置服务器路径（不推荐，因为 JDT LS 的 jar 位置与命令参数契约不直观）。

推荐方式是第 1 项，并在模板替换中增加 `${executablePath}`。解析必须拒绝未替换的模板，避免将字面量传给 Java。

### 最小验收命令

```bash
# JDT LS 归档校验
curl -L --fail -o /tmp/jdtls.tar.gz \
  'https://download.eclipse.org/jdtls/snapshots/jdt-language-server-1.55.0-202512042336.tar.gz'
echo 'cfb2f2be82b28dce4debdb05f76e3bd408a05cf8d3cbd9b8da09a7f3f5826552  /tmp/jdtls.tar.gz' | shasum -a 256 -c -
tar -tzf /tmp/jdtls.tar.gz | grep -E '(^|/)config_mac(_arm)?/?$|plugins/org.eclipse.equinox.launcher_[^/]+\.jar$'

# JDT LS stdio initialize 验证（使用已安装的 Java 21）
java <上述参数> < /tmp/initialize.json > /tmp/jdtls-response.log
```

验收必须记录 Java 版本、JDT LS 归档 SHA-256、实际 launcher JAR 路径、实际 config 目录和工作区私有 `-data` 目录；仅运行 `java -version` 或检查文件存在不足以证明 LSP `initialize` 成功。
