# Tau Editor v0.6.41

发布日期：2026-11-08

本版本完善思维导图交互、多窗口标签管理与工作台主题适配。

### 思维导图

- 选中节点后，持续水流式脉冲沿后代连线传播，按层级错开，并支持系统减少动态效果设置。
- 概要支持直接编辑；边界快捷操作可切换添加或移除。
- 导入弹窗说明支持格式，并在读取解析时展示等待状态。支持 TauMap（`.taumap`）、XMind（`.xmind`）、FreeMind / Freeplane（`.mm`）、OPML（`.opml`）和 Markdown（`.md`、`.markdown`）。
- 状态栏展示思维导图字符数、主题数与关系数，补充新增节点快捷键提示。
- 文件树和云端文档列表增加思维导图格式标识。MindManager（`.mmap`）与 MindNode（`.mindnode`）暂不支持导入。

### 标签页与工作台

- 标签页显示完整文件名、隐藏路径行并缩短高度，支持拖动调整顺序。
- 可将子窗口标签合并回主窗口；同路径文件不会重复打开，合并成功后源标签关闭，空子窗口自动关闭。
- 自绘标题栏、工具栏、状态栏与思维导图浮层适配浅色主题，界面默认字体大小调整为 11px。
- 系统应用图标统一圆角；Plus / Pro 会员在窗口图标与 macOS Dock 显示金色会员图标。

### 安装包

GitHub Actions 为 macOS（Universal 与 Apple Silicon）、Windows 和 Linux 构建桌面安装包。macOS DMG 支持 Intel 与 Apple Silicon Universal 包，以及 Apple Silicon 原生包。
