# Tau Editor v0.6.6 图片预览关闭修复发布记录

## 1. 发布范围

- 修复图片查看器在深色面板空白区域点击无响应的问题。
- 图片查看器可见期间增加窗口级 Escape 关闭兜底，不再依赖焦点必须停留在 dialog 根节点。
- 保留关闭按钮、遮罩点击、滚轮缩放、双击缩放、拖拽平移、旋转和重置能力。

## 2. 代码改动

- `frontend/src/components/editor/ImageViewer.vue`
  - 视口空白区使用 `@click.self="closeViewer"`。
  - 增加可见期间的窗口级 Escape 监听，并在隐藏/卸载时清理。
- `tests/unit/components/ImageViewer.test.ts`
  - 新增视口空白区关闭与窗口级 Escape 回归测试。
- 版本同步：根 `package.json`、`frontend/package.json`、Tauri 配置和 Cargo manifest 升级到 `0.6.6`。
