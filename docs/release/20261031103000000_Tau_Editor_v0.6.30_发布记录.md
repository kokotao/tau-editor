# Tau Editor v0.6.30 发布记录

## 发布概要

- 版本号：`v0.6.30`
- 发布日期：2026-10-31
- 发布类型：思维导图交互体验打磨 + 云端 `.taumap` 支持（功能版本）
- 发布分支：`feature/cloud-doc-sync`

## 本次更新

### 思维导图交互体验（继续自研，未引入第三方导图库）

- **主题对比度修复（核心）**：mindmap 组件此前误用了不存在的 CSS 变量（`--background/--surface/--border/--accent/--hover/--danger`），暗色主题下渲染成「白底 + 浅色字」，按钮与文字看不清。全部改为真实 Tau token（`--bg-app/--panel-elevated/--text-primary/--border-soft/--accent-brand/--state-*` 等），并新增静态守卫测试防回退。
- **画布平移修复**：此前 `@pointerdown.self` 因 SVG 覆盖容器永不触发。改为容器统一监听，区分节点/折叠钮/内联编辑器与空白区域，空白拖动即平移。
- **节点拖拽完善**：>5px 进入拖拽，源节点半透明、目标节点高亮、拖拽期禁选择；松手在节点上改父级、空白取消、抑制误触 click。
- **右键菜单**：新增 MindmapContextMenu，画布节点/空白、大纲行均可右键（新增子主题/同级、重命名、复制、删除、折叠、属性面板等）。
- **边界（boundary）与概要（summary）**：schema 新增 `topic.boundary` / `topic.summary`，布局输出边界框与概要括线，画布渲染虚线圆角框 + 括线文本，属性面板可设置，可撤销可持久化。
- 大纲/属性面板左侧 resizer 可拖拽调宽（180–420px）。

### 云端 `.taumap` 支持

- 云端新建 `.taumap` 自动写入**合法空思维导图 JSON**（此前空正文导致打开报「不是合法 JSON」）；错误态提供「新建空白导图并覆盖」恢复按钮。
- 三端白名单加入 `.taumap`：桌面 `cloudUploadPolicy`、Rust `is_openable_text_path`、后端 Java `CloudDocPathValidator`。
- 修复云端新建的空分类在资源树不可见的问题；修复编辑器打开云端文件后右键「同步至云端」分类不回显的问题。
- Markdown 加粗渲染不明显：移除全局 `font-weight: normal` 重置，恢复 `<strong>` 加粗。
