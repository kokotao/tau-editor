# Tau Editor v0.6.2 发布记录

发布日期：2026-10-02

## 发布内容

- 资源区为空时静默展示，不再出现多余提示；文件名、创建时间、修改时间和大小可完整横向查看。
- 修复 Markdown 编辑器右键分类二级菜单被滚动容器裁剪、悬浮不出现的问题。
- 图片文件直接渲染为图片预览，Markdown 本地图片通过 Tauri asset URL 加载；图片标签页只读保护，避免误覆盖二进制文件。
- 代码文件支持轻量类、接口、类型、函数和方法定义跳转，悬浮显示签名与引用数量；支持已打开模型之间的导航。
- 继续保留 Markdown 工具栏、图片粘贴、表格、分割线、折叠块、Mermaid、代码语言选择和组合快捷键能力。

## 已知限制

代码导航是轻量级符号索引，跨文件范围仅限已打开的 Monaco 模型，尚未接入完整项目级 LSP。图片预览依赖 Tauri asset protocol 的受限路径范围；超出允许目录的图片需要先纳入工作区或受支持的用户目录。

## 回滚

如需回滚，使用 `v0.6.1` 安装包或 tag；本版本不改变文档格式、图片资源格式和用户设置存储结构。
