# Tau Editor v0.6.31（GitHub 发布说明，可直接粘贴）

## Tau Editor v0.6.31

商务化 UX 收口：右键新建二级菜单、云端导图多格式、右侧双栏面板与全局工具栏布局。

### 右键「新建文件」二级菜单

- 本地文件树与云端分类右键均可按类型新建：Markdown / Tau 思维导图 / FreeMind / OPML / 纯文本 / JSON。
- 新增「自定义格式」：输入任意文件后缀（如 doc / yaml / ts）即可按 `未命名.<后缀>` 创建；本地不限制白名单，云端受文本白名单约束。
- 新文件自动写入合法种子内容：`.taumap` 空导图 JSON、`.mm` 空 FreeMind 地图、`.opml` 含根 outline 的 OPML，打开即可创作。

### 云端思维导图多格式

- `.mm` / `.opml` 加入桌面与后端文本白名单（52→54），云端可直接新建、同步并打开这两种格式。
- `.xmind` 仍走本地导入/导出链路（二进制包格式，不属云端文本同步）。

### 右侧双栏面板

- 大纲列与属性列移到编辑器外壳右侧、**两列独立**：各自折叠、各自拖宽（180–420px）、互不影响。
- 开合由全局 Toolbar 的「大纲 / 属性」按钮或 `Ctrl+Alt+O / Ctrl+Alt+P` 控制，右面板不再自带 tab 条。

### 全局工具栏布局

- 思维导图工具组**居中**显示，长内容可横向滚动，不再被右侧状态区遮挡。
- Tau 原始工具（新建/打开/保存/撤销…）移到最左侧。
- 移除三个重复按钮（左栏开关 / 定位 / 右栏开关），由 Tauri 标题栏与文件树等价入口承担；保留 Markdown 预览切换。

### 验证

- 全量单测 2199 通过、类型检查与构建通过、真实 Chromium E2E 83 条全绿。

### 升级说明

- 覆盖安装即可。云端 `.mm/.opml` 新建/同步需配套服务端白名单更新，桌面端本就可用。
