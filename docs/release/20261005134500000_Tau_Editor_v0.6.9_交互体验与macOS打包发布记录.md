# Tau Editor v0.6.9 交互体验与 macOS 打包发布记录

## 发布结论

- 版本：`v0.6.9`
- 发布日期：`2026-10-05`
- GitHub 仓库：`kokotao/tau-editor`
- 发布类型：正式 Release
- 发布范围：macOS、Windows、Linux GitHub Release 安装包
- 平台包：macOS `.dmg`；Windows `.msi` / `.exe`；Linux `.deb` / `.AppImage` / `.rpm`

本版本聚焦编辑器工作台交互体验、侧栏吸附展开/折叠、上下文栏可用性、主题市场圆角一致性、通知动画和 macOS DMG 打包配置。跨平台安装包由 GitHub Actions 对 macOS、Windows、Ubuntu Runner 分别构建，并在完整矩阵通过后上传。

## 用户可见改动

### 1. 左侧资源管理器吸附按钮

- 资源管理器展开后，吸附按钮保持可见，可以再次点击折叠。
- 折叠/展开按钮改为贴边纵向把手样式，增加 hover、focus-visible 和毛玻璃反馈。
- 补充 `aria-label`、`aria-expanded`、`aria-controls`，支持辅助技术识别当前状态。
- 按钮基准位置调整为 `left: 20px`。
- 展开状态使用 `sidebarWidth - 35px` 位移，使按钮中心线贴合资源管理器右边缘。
- 资源管理器宽度、按钮位移和内容淡入淡出均使用平滑过渡。

### 2. 右侧上下文栏吸附按钮

- 上下文栏打开后吸附按钮继续保留，可再次点击关闭。
- 吸附按钮与上下文栏左边缘对齐，并补充可访问性属性。
- 上下文栏使用透明毛玻璃效果，降低遮挡感并保持内容可读性。

### 3. 动画与交互反馈

- 复用 Animate.css：资源管理器、上下文栏、设置抽屉和通知进入/退出均增加过渡动画。
- 资源管理器折叠时内容淡出并轻微位移，展开时内容从左侧平滑进入。
- 通知进入和退出增加方向性动画。
- `prefers-reduced-motion: reduce` 下禁用动画，保留可用性和可访问性。

### 4. 主题市场圆角

- 主题市场控件、卡片、预览区和操作按钮改用主题圆角变量。
- 主题市场圆角设置现在可以跟随主题配置生效，不再被固定像素值覆盖。

### 5. macOS DMG 打包

- Tauri DMG 配置增加自定义背景资源。
- macOS 打包脚本优先复用 Tauri 的 DMG helper，统一背景、窗口尺寸、应用图标和 Applications 拖放位置。
- 当 Tauri helper 或背景资源不可用时，保留 plain DMG 回退路径。
