# Tau Editor v0.6.32（GitHub 发布说明，可直接粘贴）

## Tau Editor v0.6.32

云文档 Markdown 图片修复：粘贴或导入图片后立即同步到云端，不再出现「本地有图、云端裂图」。

### 图片粘贴/导入即上传

- 在云端文档里粘贴截图或「插入图片」时，图片会**立即上传到云端附件**并绑定当前文档，不必再手动点「同步至云端」。
- 上传成功提示「图片已插入并同步到云端」；若上传失败或格式不支持，**图片仍会插入**（本地可正常预览），并提示可稍后同步重试。
- 图片格式与大小沿用云端同步口径：png / jpg / jpeg / gif / webp，单张 ≤ 20MB；svg / bmp / avif 等会被跳过并说明原因。
- 本地文档（非云文档）行为不变：仍只写入文档同级 `assets/` 并插入相对路径。

### 说明

- Markdown 中仍保存相对路径，本地预览与云端阅读均可正常显示。
- 「图片直链为云端 URL」需要服务端提供匿名/签名访问地址，当前附件接口需要登录态，暂不适用；本次通过「即传即存」解决裂图问题。

### 验证

- 全量单测 2232 通过、类型检查通过、真实 Chromium E2E 86 条全绿。

### 升级说明

- 覆盖安装即可，无需数据迁移。
