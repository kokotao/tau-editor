## Tau Editor v0.6.36

本次版本集中升级思维导图编辑、画布自定义与导出体验，并完善会员限制提示和云端分享冲突处理。

### 思维导图

- 画布样式支持背景色、内置配色和主题样式切换。
- 中心主题、分支主题、子主题支持独立样式模板，可批量应用到同级主题。
- 节点边框、连接线起始/结束箭头、关系线及概要/外框等高级样式可配置。
- 大纲选中与画布节点选中保持双向高亮，工具栏与文本选择浮动菜单交互更稳定。
- 支持图片节点与更多思维导图导出格式。

### 导出与会员

- 免费版支持 TauMap、PDF、JPG、Markdown 导出，并在导出文件中铺满 Tau Editor 品牌水印。
- Plus 在免费版基础上增加 FreeMind、SVG 导出。
- Pro 支持全部导出格式、导出水印自定义或关闭。
- 触发节点数量或画布限制时弹出会员权益确认框，展示功能对比与升级入口。

### 云端协作

- 普通用户单个导图文件只能创建一个工作表（画布）。
- 修复分享「覆盖云端并继续」遇到新版本冲突时重复显示确认状态的问题，改为明确错误提示并引导重新打开确认。
