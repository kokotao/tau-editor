# Tau Editor v0.6.1 发布记录（Markdown 编辑器增强版）

> 发布日期：2026-09-30
> Release 标签：`v0.6.1`
> 项目地址：https://github.com/kokotao/tau-editor

## 发布摘要

v0.6.1 聚焦 Markdown 编辑器体验：补齐顶部工具栏、右键快捷插入、选中文本浮动工具栏、SVG 图标、Markdown 快捷键、图片剪贴板导入和代码块语言选择，并修复标题、撤销、重做等工具按钮无响应问题。

## 主要变更

- 标题工具收缩为 `H` 入口，展开后可选择 H1-H6。
- 使用显眼的内联 SVG 图标替换 Markdown 工具栏中的字母和 ASCII 符号。
- 支持粗体、斜体、删除线、引用、无序/有序/任务列表、链接、目录和时间戳快捷插入。
- 支持图片、表格、分割线、折叠块和 Mermaid 快捷插入。
- 代码块支持常用语言选择及自定义语言输入，行内代码仍可直接插入。
- 支持 `Ctrl+B`、`Ctrl+I` 以及先后顺序不限的 `Ctrl+B + Ctrl+I` 加粗斜体组合快捷键。
- 支持将剪贴板图片直接粘贴到 Markdown 文档；图片写入文档同级 `assets/` 目录，Markdown 使用相对路径引用。
- 修复标题 H 工具、撤销和重做按钮点击无响应，撤销/重做状态与 Monaco 模型真实历史同步。
- 保留工作区文件树右键菜单和工作区上下文修复，并补充对应单元测试。
