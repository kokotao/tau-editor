# Tau Editor v0.6.45

## 首次使用与升级引导

- 首次安装、升级后首次启动以及 14 天未打开时，同时打开操作说明和可编辑的「示例思维导图」，默认显示操作说明页。
- 示例含 4 个工作表和 80+ 个主题，展示四种布局、节点与画布样式、备注/标签/链接/标记、文本高亮、边界/概要、关系线、图片节点、导入导出，以及文件工作区、代码编辑、Markdown、搜索导航和个性化设置等应用功能。
- 已有示例标签会复用并保留用户修改；标签或内存容量不足时下次启动会重试。

## 状态栏

- 底部状态栏增加折叠/展开按钮，隐藏后可从窗口底边直接重新显示。
- 新增 `Ctrl+Alt+Shift+S` 快捷键和命令面板命令“切换底部状态栏”；快捷键可自定义。
- 设置中可控制并记住状态栏显隐状态；后台文件夹上传进度入口在状态栏隐藏时仍保留。

## Markdown 预览

- 代码块与表格增加悬停显示的水平拖动条，支持鼠标拖动和键盘操作，同时保留触控板横向滚动。
- 隐藏原生滚动条的视觉层，避免出现重复滚动条。
- 预览宽度和缩放工具栏调整为更紧凑、半透明的样式，悬停或键盘聚焦时恢复清晰度。
