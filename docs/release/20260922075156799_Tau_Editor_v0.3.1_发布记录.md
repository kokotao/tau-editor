# Tau Editor v0.3.1 发布记录

> 类型：补录发布记录（发布日期 2026-08-24，文档补录于 2026-09-22）
> Tag：`v0.3.1`（`dd1ed2e`）
> GitHub Release：Tau Editor v0.3.1

## 发布目标

修复 Windows 下脚本类文件被编辑器抢占关联的问题，并把文件关联改为用户可配置能力。

## 用户可见变化

- 安装器不再把 `.bat` / `.cmd` 注册为 Tau Editor 打开，双击脚本恢复系统默认执行行为。
- 设置面板新增「文件关联」（仅 Windows），可在运行时勾选/取消各扩展名的默认打开程序。
- 脚本类扩展名（`bat` / `cmd` / `ps1` / `sh` / `bash` / `zsh`）默认不参与关联。
- 修复 `Cargo.lock` 依赖版本指向不可用 crate 导致构建失败的问题。

## 涉及提交

- `478ee7d` fix(windows): stop registering bat/cmd file associations
