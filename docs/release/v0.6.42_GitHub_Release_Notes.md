# Tau Editor v0.6.42

发布日期：2026-11-08

修复跨平台应用图标解码导致的 Linux / Windows 构建失败，并发布思维导图与工作台体验升级。

### 思维导图

- 选中节点后，持续水流式脉冲沿后代连线传播，按层级错开，并支持系统减少动态效果设置。
- 概要支持直接编辑；边界快捷操作可切换添加或移除。
- 导入弹窗说明实际支持格式，并在读取解析时展示等待状态。支持 TauMap（`.taumap`）、XMind（`.xmind`）、FreeMind / Freeplane（`.mm`）、OPML（`.opml`）和 Markdown（`.md`、`.markdown`）。
- 状态栏展示思维导图字符数、主题数与关系数，补充新增节点快捷键提示。
- 文件树和云端文档列表增加思维导图格式标识。MindManager（`.mmap`）与 MindNode（`.mindnode`）可识别并显示标识，但暂不支持导入。

### 标签页与工作台

- 标签页显示完整文件名、隐藏路径行并缩短高度，支持拖动调整顺序。
- 可将子窗口标签合并回主窗口；同路径文件不会重复打开，合并成功后源标签关闭，空子窗口自动关闭。
- 自绘标题栏、工具栏、状态栏与思维导图浮层适配浅色主题，界面默认字体大小调整为 11px。
- 系统应用图标统一圆角；Plus / Pro 会员在窗口图标与 macOS Dock 显示金色会员图标。

### 跨平台修复

- 修复 Linux 和 Windows 构建中调用 Tauri 不存在的 PNG `Image::from_bytes` API 导致的编译失败。
- 使用现有 `png` crate 解码并规范化图标像素为 RGBA，再创建 Tauri 窗口图标；macOS Dock 图标处理保持不变。
- 安装包由 GitHub Actions 构建并校验：macOS Universal 与 Apple Silicon DMG、Windows EXE/MSI、Linux DEB/AppImage/RPM。
