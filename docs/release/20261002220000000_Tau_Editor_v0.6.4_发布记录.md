# Tau Editor v0.6.4 发布记录

发布日期：2026-10-02

## 发布定位

修复 v0.6.2/v0.6.3 三平台构建因 CI TypeScript 兼容错误失败的问题，补齐 macOS、Windows、Linux 安装包，并将官网更新日志改为自动读取 GitHub Releases。

## 主要变更

- 将路径规范化逻辑中的 `Array.prototype.at()` 改为兼容 CI 类型库目标的索引访问，修复 TS2550 构建错误。
- 发布流水线校验 tag 与应用版本一致，防止错误版本资产上传。
- 构建后强制校验 macOS DMG、Linux DEB/AppImage/RPM、Windows MSI/EXE 六类安装包。
- 发布前再次校验 Release 资产集合完整，缺少任一系统安装包时阻止公开发布。
- 官网 Releases 时间线自动读取 GitHub 公开 Release，展示版本、日期、更新摘要和所有可下载资产；API 失败时回退内置记录。
- 补齐 CHANGELOG 中 v0.6.0/v0.6.1 详细章节，并记录版本审计结果。

## 验证

- `pnpm --dir frontend type-check`：通过。
- `pnpm --dir frontend build`：通过。
- `npm --prefix website run build`：通过。
- `node --check website/src/main.js`：通过。
- `.github/workflows/release.yml`：Ruby YAML 解析通过。
- 全量单元测试及关键官网逻辑检查在发布前执行。

## 资产要求

公开 Release 必须包含以下六类安装包：

- macOS：`.dmg`
- Linux：`.deb`、`.AppImage`、`.rpm`
- Windows：`.msi`、`.exe`

## 已知限制

- 官网 GitHub API 动态同步受浏览器网络和 GitHub API 限流影响，失败时会使用内置 fallback。
- macOS 未配置 Developer ID 公证时仍采用 ad-hoc 签名，首次启动可能需要系统手动放行。

## 回滚

应用代码可回滚到 `v0.6.3`；如需撤回安装包发布，应在 GitHub Release 页面删除 v0.6.4 资产或将其标记为草稿，不修改历史 tag。
