# Tau Editor v0.6.27 发布记录

## 发布概要

- 版本号：`v0.6.27`
- 发布日期：2026-10-28
- 发布类型：云文档右键上传能力 + Markdown 目录联动高亮（功能版本）
- 发布分支：`feature/cloud-doc-sync`

## 本次更新

### 云文档

- 云端文档「分类」右键新增「新建文件」：文件名净化后按 `tau/<工作区>/<文件名>` 在云端创建空文档，并交给既有落位链路在编辑器打开（树内不写本地盘，避免两份不同步副本）。
- 云端文档「分类」右键新增「上传文件…」：系统多选 → 上传计划（文本 / 二进制 / 跳过+原因）→ 串行队列 + 逐条进度弹窗；上限 100 个；`quota`/`unauthorized` 立即中止。
- 工作区文件树「文件夹」右键新增「上传该文件夹到云端」：递归收集（跳过 11 类构建/依赖目录与隐藏项，深度 8 / 文件 500 / 文本 12MB / 二进制 50MB）→ 以文件夹名建分类（建分类失败则复用同名，再退化为自由文本分类）→ 串行上传 + 确认/进度/汇总三段式弹窗。
- 云端已有同名且内容不同的文档默认**不覆盖**，逐条标注「已存在未覆盖」。
- 文本扩展名白名单抽为 `cloudUploadPolicy` 并与后端 `CloudDocPathValidator.TEXT_EXTENSIONS`（51 项）逐项对齐：无扩展名（Makefile）与 `.svelte`/`.lua` 等白名单外文件由「失败」变为「跳过并给原因」。
- 宏格式补齐后端已有的 `potm`/`xlam`；用户主动中止与配额/登录失效使用不同文案。

### 文档大纲

- 文档大纲随编辑器滚动实时高亮当前标题，并自动跟随（`scrollIntoView`）；用户手动滚动/悬停大纲后 3 秒内不自动抢回。
- Markdown 预览滚动同样驱动同一高亮状态（预览标题带 `data-source-line` 反查源码行）。
- 点击目录项立即高亮并跳转（导航锁 400ms，避免跳转事件把高亮改回上一项）。
- 代码文件的类/函数/键大纲同样按当前视口高亮。
