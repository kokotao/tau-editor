## 1. 版本定位

本版本聚焦 Markdown 图表渲染、桌面工作台布局和主题颜色可读性。用户可以在 Markdown 中直接使用更多 Mermaid 图表类型；宽屏工作台不再出现侧栏和编辑区之间的异常空白；浅色、深色及不同主题皮肤会自动选择可读的默认文字和背景颜色，同时保留用户自定义配色能力。

## 2. 亮点

- **Mermaid 多图表支持**：扩展 fenced code 白名单，支持流程图、时序图、类图、状态图、ER 图、甘特图、饼图、旅程图、Git 图、思维导图、时间线、象限图、XY 图、Sankey、Kanban、Architecture、Requirement、C4、ZenUML、Radar、Treemap、Venn 等常见类型。
- **桌面布局修复**：800px 以上工作区使用边缘对齐布局，移除多余面板间距；分隔条收窄为 1px 并保留悬浮、拖拽反馈。
- **主题模式可读性**：明暗模式切换时自动同步推荐的 Monaco 基底主题，避免浅色 UI 使用深色编辑器或深色 UI 使用浅色编辑器。
- **主题风格默认配色**：主题皮肤自动提供背景、面板、正文、次级文字和强调色；系统偏好不再覆盖应用内显式主题选择。
- **自定义颜色保护**：用户仍可通过设置、主题包和颜色选择器微调配色；正文与背景对比度不足时自动回退到当前模式的安全颜色。

## 4. 兼容性与已知限制

- 不涉及数据模型、API、用户数据、设置文件格式和保存逻辑迁移。
- Mermaid 语法错误会降级保留为代码块，不会阻塞 Markdown 预览；具体图表能力仍受 Mermaid 版本语法支持范围约束。
- 自定义颜色仍允许用户微调，但正文与背景低于可读性阈值时会使用当前主题的安全回退色。
- macOS 未配置 Apple Developer ID Secrets，本次产物使用 ad-hoc 签名；首次打开可能需要在系统设置中手动放行。
- 全量跨浏览器 E2E 未作为发布门禁完成：Firefox、WebKit、Mobile Safari 环境启动失败，部分用例超时；Chromium 关键路径已通过。

## 5. 升级与回滚

- 升级：直接覆盖安装即可，现有配置和用户数据无需迁移。
- 回滚：回到 `v0.4.2` 不影响配置文件和用户数据；如出现阻断问题，以后续补丁版本修复，不覆盖既有 tag。
