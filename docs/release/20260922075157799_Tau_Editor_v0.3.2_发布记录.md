# Tau Editor v0.3.2 发布记录

> 类型：补录发布记录（发布日期 2026-08-24，文档补录于 2026-09-22）
> Tag：`v0.3.2`（`6a96a83`，包含 `69a05e2`）
> GitHub Release：Tau Editor v0.3.2

## 发布目标

消除 Windows 平台 GUI 进程启动时反复弹出的黑色命令窗口，并把文件关联查询改为按需加载。

## 用户可见变化

- 启动、保存、打开文件等流程不再闪现命令行黑框（`reg` / `cmd` / `msiexec` / `explorer` 子进程统一加 `CREATE_NO_WINDOW`）。
- 「文件关联」设置页改为进入时才读取系统关联状态，启动阶段不再批量执行 `reg` 查询，冷启动更快。

## 涉及提交
