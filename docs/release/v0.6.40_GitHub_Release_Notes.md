## Tau Editor v0.6.40

本版本保留 v0.6.39 的全部功能和官网内容，并修复 Linux 构建条件编译问题，重新发布完整三平台安装包。

### 自研思维导图

- TauMap 自研数据模型、布局算法、SVG 画布、撤销与持久化由同一套引擎驱动。
- 支持四种布局、节点级视觉样式、彩虹分支、边界、概要、图片节点、属性面板和大纲联动。
- 普通滚轮平移，`Ctrl/Cmd + 滚轮`缩放；触控板双指滑动查看长画布和工具栏。

### 云端协作与官网

- 保留分享链接识别、密码预览、分享转存、云同步浅色主题和自动更新提示。
- 官网更新 2026 年 11 月实拍截图、导图演示 GIF，并突出 TauMap 自研思维导图创新能力。

### 跨平台修复

- 修复 Linux 目标编译时剪贴板文本读取分支缺失 `std::process::Command` 导入的问题。
- 重新执行 macOS、Windows、Linux 三平台安装包构建和资产完整性校验。
