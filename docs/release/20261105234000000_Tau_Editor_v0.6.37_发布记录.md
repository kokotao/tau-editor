## 发布内容

- 云文档历史版本支持 Markdown、思维导图、JSON、XML、YAML、SQL 与常见代码/配置文本只读预览。
- 历史预览支持宽屏双栏、导图适应面板/原始尺寸/源码切换，Markdown 外链统一交给系统浏览器。
- 思维导图新增 mini 快捷绘图工具、同级拖拽排序、全屏面板修复、三页签详情栏与右键同步/分享。
- lizi 后端历史预览接口已通过 WSL + JDK 17 构建并部署，线上 OpenAPI 已确认 GET 路由。
