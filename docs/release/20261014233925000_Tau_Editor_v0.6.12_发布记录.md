# Tau Editor v0.6.12 发布记录

发布日期：2026-10-14
仓库：`kokotao/tau-editor`
发布类型：正式 GitHub Release

## 发布摘要

v0.6.12 聚焦 Markdown 标签级预览状态、HTML/PDF/Excel 分栏预览、Windows 路径修复、二进制文件安全保护和跨窗口标签页操作。

## 用户可见改动

### Markdown 与文档预览

- Markdown 分栏布局和预览字号按标签独立保存，切换标签不会互相覆盖。
- Markdown 仅预览支持 `Ctrl/Cmd +`、`Ctrl/Cmd -`、`Ctrl/Cmd 0` 调整字号。
- Markdown 图片悬浮显示放大指针和双击提示，保留原始 `alt` 文本。
- HTML 文件支持分栏预览，相对资源按文档目录解析，并使用空 sandbox 隔离脚本。
- PDF、CSV、TSV、XLS、XLSX 文件支持分栏预览；XLS/XLSX 渲染首个工作表。

### 稳定性与安全

- 修复 Windows 复制文件路径时盘符前多出斜杠的问题。
- 新增受控 `read_file_bytes` Tauri 命令，解决 PDF 其他盘符预览和 Excel 文件读取权限问题。
- XLS/XLSX 文件统一进入二进制预览保护，避免保存预览文本覆盖原始文件。
- 增加 PDF/Excel 快速切换、旧请求和组件卸载后的竞态保护。
- 会话恢复保留每个 Markdown 标签自己的布局和字号。

### 标签页与跨窗口

- 支持从标签页右键菜单在新窗口打开当前标签。
- 支持多个 Tauri 窗口之间拖拽、合并和移动标签。

## 已知限制

- macOS 安装包沿用 ad-hoc 签名；未配置 Developer ID 公证时，首次打开仍需在系统设置中允许。
- PDF/XLSX 预览会一次性读取文件内容，超大文件可能有额外内存压力。
