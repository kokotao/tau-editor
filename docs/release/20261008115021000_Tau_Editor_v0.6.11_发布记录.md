# Tau Editor v0.6.11 发布记录

发布日期：2026-10-08
仓库：`kokotao/tau-editor`
发布类型：正式 GitHub Release

## 发布摘要

v0.6.11 聚焦更新安装体验、macOS 工作台导航、编辑器路径上下文和状态栏可访问性，同时收口 Markdown 预览、图片预览、主题市场、工具栏与标签页交互。

## 用户可见改动

### 更新下载与安装体验

- 更新包改为流式写入，按下载进度发出 `app:update-download-progress` 事件。
- 支持服务端不返回总大小的下载场景，并将已知总量的进度限制在 0–100%。
- 设置页更新说明继续使用安全 Markdown 渲染，外部网页链接交给系统浏览器打开。
- macOS 标题栏可以直接查看更新状态并触发匹配设备安装包下载。

### 工作台导航

- macOS 原生标题栏增加返回/前进、Quick Open、命令面板、资源区、上下文栏和 Markdown 预览入口。
- 新增编辑器路径面包屑，可定位工作区、文件夹、文件并联动文件树。
- 导航历史保存文件、行号和列号，切换文件后可以恢复原编辑位置。

### 编辑器与可访问性

- 状态栏编码、语言模式和主题选择改为支持键盘方向键、Home/End、Escape、焦点管理和视口边界定位的自绘选择器。
- Markdown 预览新增“林间薄荷”“雾紫信笺”“深海蓝调”风格，并修复外链打开、Teleport 右键菜单和主题同步。
- 图片预览、主题市场、工具栏、标签页和设置面板完成布局与主题适配收口。
- 新增编辑器路径面包屑组件及单元测试；同步更新 AppShell、MarkdownPreview、SettingsPanel、StatusBar、ThemeMarketplace、Toolbar 测试。

## 验证记录

发布前执行：

```text
pnpm --dir frontend type-check
pnpm --dir frontend build-only
pnpm exec vitest run
cargo test --manifest-path frontend/src-tauri/Cargo.toml
git diff --check
```

GitHub Actions `Desktop Build` 负责 macOS Universal/aarch64、Windows x64、Linux amd64 安装包构建，并在发布前校验完整资产集合：两个 DMG、DEB、AppImage、RPM、MSI 和 EXE。

## 已知限制

- macOS 安装包沿用 ad-hoc 签名；未配置 Developer ID 公证时，首次打开仍需在系统设置中允许。
- 构建输出可能包含既有动态导入和大 chunk 警告，不影响构建门禁；以 CI job 结果和资产校验为准。
