## Tau Editor v0.6.27

本次更新聚焦**云文档右键操作闭环**与**编辑器目录跟随**，并对配套的栗子云端文档预览与分享页渲染做了增强。

### 云文档

- **分类右键「新建文件」**：在云文档分类上右键即可新建空文档，创建后直接在编辑器中打开，编辑与保存沿用既有云同步链路。
- **分类右键「上传文件…」**：一次多选批量上传，逐条显示进度与结果；文本类走云文档保存，pdf/office 走二进制上传；云端已有同名且内容不同的文档默认不覆盖，并标注「已存在未覆盖」。
- **工作区文件夹右键「上传该文件夹到云端」**：递归收集文件夹内容（自动跳过 `node_modules`/`dist` 等构建依赖目录与隐藏项，深度 8 层、最多 500 个文件、文本 12MB / 二进制 50MB），以文件夹名作为云端分类，确认 → 进度 → 汇总三段式完成上传。
- 上传白名单与后端对齐：无扩展名（如 `Makefile`）与非白名单扩展名改为「跳过并说明原因」，不再误报为失败；补充 `potm`/`xlam` 宏格式拦截；区分「用户主动中止」与「配额不足/登录失效」提示。

### 文档大纲（目录）

- 文档大纲随编辑器滚动**实时高亮**当前标题，并自动跟随保持可见；用户手动滚动大纲后 3 秒内不自动抢回。
- 打开 Markdown 预览并滚动预览时，同一高亮跟随预览当前章节。
- 点击大纲项立即高亮并跳转；代码文件的结构大纲（类/函数/键）同样跟随当前视口。

### 配套服务端（栗子云端文档）

- 个人中心「我的云文档」新增**在线预览**：Markdown / 代码 / 纯文本 / 图片 / PDF / Office 均可直接预览，Office 由服务端转 PDF 渲染。
- 分享页与预览的 Markdown 渲染增强：**流程图（Mermaid）**、**表格**、**折叠块**（`::: details 标题`）、代码高亮；mermaid 语法错误自动降级为原代码块并给出提示，公开分享页使用 `securityLevel: strict`。

### 验证

- 单元测试：121 个测试文件 / 1631 个用例全部通过。
- 类型检查：前端 `vue-tsc --build` 0 error。
- 安装包由 GitHub Actions 按 `v0.6.27` tag 构建：macOS（universal / Apple Silicon）、Windows、Linux。

### 升级说明

- 覆盖安装即可，无需手动迁移数据；云端文档为纯增量能力，回滚到 v0.6.26 不影响已有文档。
- 需要配套的栗子云端服务（我的云文档在线预览、分享页增强）已同步上线。
