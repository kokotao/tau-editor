# Tau Editor v0.6.7 语言服务无痛发布记录

## 发布目标

将 TypeScript、Python、Go、Rust、Java、C# 的语言服务改为应用内按需托管：普通用户不需要预先安装 Node.js、Python、Go、Rust、Java、.NET 或任何语言服务器，也不需要修改系统 `PATH`。

首次打开对应语言文件时，Tau Editor 在后台准备所需资产；资产下载后写入当前用户的应用私有数据目录，经过 SHA-256 校验、原子解压和 manifest 记录后启动。已准备的版本在后续启动中复用，失败时保留编辑器和轻量导航能力。

## 用户可见行为

- 打开代码文件后后台预热对应语言服务，不等待用户第一次悬浮或定义跳转时才开始下载。
- 只下载当前使用语言及其运行时，不默认下载全部语言，控制首次安装体积。
- 语言服务器、运行时和工作区索引均写入应用私有目录，不写入项目目录和系统 PATH。
- 下载失败、网络断开或语言服务启动失败时，编辑器继续工作，并回退到 PATH 探测或轻量导航。
- 设置页仍提供“自动准备”入口，用户可在联网时提前缓存指定语言。

## 启动契约和专项决策

### TypeScript / Python

两者共用应用私有 Node.js 24.21.0。TypeScript Language Server 通过 `initializationOptions.tsserver.fallbackPath` 指向应用私有 TypeScript SDK，不依赖项目是否安装 TypeScript。Pyright 直接使用同一 Node runtime 启动。

### Go

Go 不是只下载 `gopls`。发布包同时包含 Go 1.27.1 SDK、gopls v0.23.0 和 `tau-gopls` wrapper。wrapper 设置私有 `GOROOT`、`GOPATH`、`GOMODCACHE`、`GOCACHE` 和 `GOTOOLCHAIN=local`，因此不依赖用户系统 Go。

### Rust

rust-analyzer 官方资产是 gzip 单文件，provisioner 增加 gzip 安全解压；安装器拒绝绝对路径、路径穿越、符号链接和硬链接。

### Java：否决 JDT LS 1.62 + Java 21

JDT LS `1.62.0-202609302159` 在真实启动时要求 `JavaSE-25`，使用私有 Java 21 会以退出码 13 失败。因此本版本采用 JDT LS `1.55.0-202512042336` + Temurin JRE 21.0.12.1+1。该组合已在私有 workspace 中完成真实 JSON-RPC `initialize`，返回 `JDT Language Server (Standard) 1.55.0-SNAPSHOT`，并声明 hover、definition、references、workspaceSymbol 等能力。

JDT LS 的 `-data` 指向应用的 `lsp-workspaces/<sha256(workspace-root)>`，不向用户项目目录写索引。

### C#：必须托管 .NET SDK

OmniSharp v2.0.0 必须直接执行自身 apphost：

```text
<private OmniSharp>/OmniSharp --languageserver
```

同时注入 `DOTNET_ROOT`、`DOTNET_ROOT_ARM64` 或 `DOTNET_ROOT_X64`，指向应用私有 .NET SDK。仅有 runtime 时 OmniSharp 可以 initialize，但加载 `.csproj` 会报告 `No .NET SDKs were found`；私有 SDK 10.0.100 加入后，最小项目已验证出现 `Successfully loaded project file` 和 `Update project`。

## 安装安全边界

- 下载地址只允许 `http`/`https`，资产来自内置受信任清单。
- 下载包先计算 SHA-256，校验失败不会覆盖既有版本。
- 先写入临时文件和临时目录，再原子替换安装目录和 manifest。
- manifest 中的 server id、版本和相对路径均做严格校验。
- tar、zip 不允许路径穿越；tar 拒绝符号链接和硬链接。
- 应用不把用户输入的 URL 直接当作可执行命令。

## Release 资产

### GitHub Release `v0.6.7`

需要上传：

```text
tau-gopls-v0.23.0-darwin-arm64.tar.gz
tau-gopls-v0.23.0-darwin-x64.tar.gz
```

GitHub Actions 的桌面安装包由 tag workflow 生成。发布后必须从 GitHub 重新下载 Go 两个归档，重新计算 SHA-256，并与上表和 manifest 一致后，才可将线上发布标记为完成。

## 已知限制与回滚

- 当前完整托管资产只覆盖 macOS arm64/x64；Windows/Linux 资产尚未进入本次 release gate。
- 当前没有 Developer ID 证书，macOS DMG 只能 ad-hoc 签名；用户首次打开可能需要在系统设置中允许。
- 如果 GitHub Release 创建或 CI 失败，保留当前 tag 前的提交，不把未验证资产写入新的 manifest。
- 如果线上 Go 归档 SHA-256 与 manifest 不一致，应删除/替换 Release 资产并修正 manifest，禁止让应用下载未验证包。
