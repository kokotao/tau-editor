# Tau Editor v0.5.0 发布记录（主题模式与主题市场版）

> 发布时间：2026-09-28
> Release 标签：`v0.5.0`
> 基线：`v0.4.3`
> 发布仓库：https://github.com/kokotao/tau-editor

## 1. 版本定位

本版本重构主题模式与配色的关联关系，修复浅色/深色切换时背景和面板颜色不随模式变化的问题。设置页提供浅色和深色色块，用户可以按色块选择主题风格；快速自定义配色只调整前景和状态色，不再锁死应用背景。

## 2. 主要更新

- 浅色、深色各提供 5 组主题色块，点击色块同步切换模式和主题风格。
- 自定义配色移除应用背景、面板背景字段，文字、强调色和状态色按模式独立保存。
- 主题包升级为 v2 双模式格式，支持 `modes.light`、`modes.dark` 和对应 Monaco 配置。
- 保留 v1 单模式主题包和旧 localStorage 配置迁移能力。
- 设置页提供完整主题包与快速配色包 JSON 示例，可复制后直接修改导入。
- 新增 GitHub 主题市场 MVP，支持 catalog、搜索、类型筛选、缓存、安装、应用和源码链接。
- 新增主题包示例、JSON Schema、贡献流程和远程包安全校验说明。

## 4. 兼容性与已知限制

- 不涉及编辑器文件格式、用户文档和用户数据迁移。
- 旧 v1 主题包可以继续导入；导出会使用 v2 双模式结构。
- 旧的 `bgApp`、`panelBase` 快速自定义值不再作为全局覆盖写入，应用会回退到当前主题模式的安全背景。
- 主题市场首期使用 GitHub Raw catalog，网络不可用时回退到 24 小时内缓存或本地主题。
- 需要先创建并维护 `kokotao/tau-editor-themes` 仓库，市场才会显示社区主题。
- macOS 产物使用 ad-hoc 签名，首次打开可能需要在系统设置中手动放行。

## 5. 回滚

- 可回滚到 `v0.4.3`，不影响编辑器文件和用户数据。
- 市场功能不可用时不影响内置主题、本地导入主题和编辑器启动。
