# Tau Editor v0.6.33（GitHub 发布说明，可直接粘贴）

## Tau Editor v0.6.33

云文档图片彻底修复：粘贴/导入图片后，Markdown 里直接写入**云端签名直链**，编辑预览、个人中心、网页、小程序都能直接显示。

### 为什么上一版还裂图

v0.6.32 做到了「粘贴即上传云端附件」，但 Markdown 里仍是**本地相对路径**：

- 编辑器预览加载不到本地相对路径 → 裂图
- 个人中心渲染 Markdown 时没有把相对路径映射成可访问地址 → 裂图
- 只有分享页能显示（分享页有 token 鉴权的图片接口）

### 本版怎么改

- 云文档里粘贴/导入图片 → 上传云端 → **把签名直链写进 Markdown**（如 `https://note.lizipro.cn/lizi/miniProgram/cloud/docs/file/88?sig=t1.…`）
- 直链匿名可读，`<img src>` 直接能加载，因此编辑器预览、个人中心、网页、小程序都不再需要额外替换逻辑
- 直链带 HMAC 签名与 10 年有效期：猜到 assetId 也取不到图；文档删除后直链自动失效（404）
- 旧后端未返回直链时自动回退相对路径，不阻断插入；本地文档行为完全不变

### 服务端（已部署）

- 上传/列表接口新增 `url` 字段（图片签名直链）
- 新增匿名读图接口 `GET /miniProgram/cloud/docs/file/{assetId}?sig=...`（只验签名，只允许图片，ETag/304）

### 验证

- 桌面端：全量单测 2239 通过、类型检查通过、`cargo check` 通过
- 服务端线上实测：无签名/错签名 → 404「图片不存在」；真实附件签名直链 → 200 + `image/png` + 1,788,522 字节（PNG 魔数正确）

### 升级说明

- 覆盖安装即可。**存量文档**里旧的相对路径图片不会自动变直链，重新粘贴即可；后续会做批量替换。
