# Tau Editor v0.6.0 发布记录（主题市场与外观自定义版）

> 发布日期：2026-09-29
> Release 标签：`v0.6.0`
> 项目地址：https://github.com/kokotao/tau-editor

## 发布摘要

v0.6.0 将主题市场从设置流程中独立出来，并补齐主题包、源码查看、自定义配色、标签状态和圆角配置能力。主题切换会同步工作台顶部栏、编辑器和标签状态，官网同步新增历史更新日志展示。

## 主要变更

- 主题市场独立为左侧菜单栏目，支持搜索、筛选、安装、应用和缓存。
- 主题卡片提供仓库图标跳转，源码箭头打开对应主题的原始 JSON 弹窗。
- 主题包与自定义配色支持选择项颜色、标签高亮、状态色等 UI token 配置。
- 新增全局圆角配置，支持在设置中调整工作台控件和浮层的圆角级别。
- 主题切换同步顶部栏、标签栏、编辑器和状态栏，降低视觉割裂。
- 设置页重复的“设置”文本已收口，保持完整工作区与抽屉模式的一致性。
- 官网新增 v0.1.0 至 v0.6.0 历史更新日志时间线、分类筛选和展开详情。

## 验证

- 单元测试：`pnpm test:unit`
- 前端类型检查：`pnpm --dir frontend type-check`
- 前端生产构建：`pnpm --dir frontend build-only`
- 官网生产构建：`pnpm --dir website build`
- 差异检查：`git diff --check`

## 兼容性与回滚

- 不改变用户文档内容、主题包 JSON 兼容格式和已有工作区文件。
- 从 `v0.6.0` 回滚到 `v0.5.0` 不影响已保存文件；新增外观配置字段会被旧版本忽略。
- macOS 构建沿用现有签名策略，未配置 Developer ID 时首次启动可能需要系统手动放行。
