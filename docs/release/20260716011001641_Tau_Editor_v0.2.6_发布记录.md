# Tau Editor v0.2.6 发布记录

发布日期：2026-07-16

## 本次更新

- 新增扁平化左/中/右工作台：以细线分隔区域，移除工作区卡片阴影与大圆角。
- 新增右侧 Context Rail：Markdown 标题、代码符号、JSON/YAML 关键结构可直接跳转到编辑器对应行。
- 新增 Context Rail 快捷操作：查找、跳转行、保存及 Markdown 预览模式。
- 支持 Markdown 预览按源行同步定位，并处理围栏代码、HTML 块和 Mermaid 异步渲染。
- 响应式优化：窄屏左右栏均为按需覆盖式抽屉，移动宽度默认收起。
- 右栏宽度和折叠偏好可持久化，并对异常本地设置值进行安全归一化。
- 修复并恢复全量单元测试门禁。

## 验证

- 单元测试：30 个测试文件、610 项测试通过。
- 前端类型检查与生产构建通过。
- Rust `cargo check` 通过。

## 已知提示
