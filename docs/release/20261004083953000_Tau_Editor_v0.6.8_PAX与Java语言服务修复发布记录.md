# Tau Editor v0.6.8 PAX 与 Java 语言服务修复发布记录

## 发布摘要

版本：`v0.6.8`

发布日期：`2026-10-04`
发布范围：macOS Universal（arm64 + x86_64）

本版本修复托管语言服务在真实下载包上的兼容性问题，重点解决 Java JDT LS / Temurin JRE 下载后因 tar PAX 扩展头导致的解包失败，并增强网络不稳定时的自动恢复能力。

## 用户可见修复

- 支持 POSIX PAX `x` / `g` 扩展头，以及 GNU `L` / `K` 长路径扩展。
- tar 解包继续拒绝绝对路径、路径穿越和未识别的危险条目类型。
- 符号链接和硬链接不直接写入用户磁盘，按安全策略物化为普通文件；循环链接、目录目标和不存在目标会明确报错。
- Java 安装拆分为 JRE runtime 与 JDT LS 两个阶段；JRE 已缓存时，后续失败只重试 JDT LS，不重复下载 JRE。
- 下载器增加连接超时、总超时、指数退避和可重试 HTTP 状态处理：连接超时 `20s`、总下载超时 `600s`、最多 `4` 次尝试，退避序列为 `1s → 3s → 8s`。
- Java 准备失败会显示具体阶段（运行时或 jdtls）、URL、尝试次数、HTTP 状态和底层错误原因，便于用户定位网络或资产问题。

## 代码变更

- `frontend/src-tauri/src/lsp/provisioner.rs`
  - 完善 tar PAX/GNU 扩展头解析和安全条目处理。
  - 增加下载超时、重试、退避及错误上下文。
  - 增加 Java runtime 缓存复用和分阶段错误提示。
- `frontend/src/services/lsp/languageServerStatus.ts`
  - 更新语言服务状态展示，区分 Java runtime 与 JDT LS 准备阶段。
- 版本文件统一升级到 `0.6.8`：
  - `frontend/package.json`
  - `frontend/src-tauri/Cargo.toml`
  - `frontend/src-tauri/Cargo.lock`
  - `frontend/src-tauri/tauri.conf.json`
