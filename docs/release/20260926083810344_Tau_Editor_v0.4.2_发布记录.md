## 1. 版本定位

在 `v0.4.1` 工作台视觉基础上，增加克制的微圆角体系，并修复 macOS 产物因仅有 linker 签名而可能被 Gatekeeper 判定为「已损坏」的问题。CI 同时接入 Developer ID 签名、公证与 staple 开关。

## 2. 亮点

- **微圆角体系**：统一为 `0 / 2 / 4 / 6 / 8px`，结构平角、交互微圆、浮层小圆。
- **视觉一致性**：工具栏、标签、状态栏、设置页、菜单、对话框和 Markdown 预览统一收口。
- **macOS 签名修复**：构建期对整个 `.app` 执行 ad-hoc 完整签名，修复旧产物「已损坏」问题。
- **Developer ID 开关**：配置 Apple Secrets 后自动签名、公证、staple 并校验。
- **回归保护**：视觉基线、前端测试、Rust 测试和 CI 构建继续作为发布门禁。

## 6. 签名说明

- 当前仓库未配置 Apple Developer ID Secrets，本次 macOS 包使用完整 ad-hoc 签名。
- ad-hoc 签名可以避免旧产物「已损坏」错误，但首次打开仍需在「系统设置 → 隐私与安全性」放行一次。
- 后续配置以下 Secrets 后不需要修改代码，CI 会自动切换为 Developer ID 签名和公证：
  - `APPLE_CERTIFICATE`
  - `APPLE_CERTIFICATE_PASSWORD`
  - `APPLE_SIGNING_IDENTITY`
  - `APPLE_ID`
  - `APPLE_PASSWORD`
  - `APPLE_TEAM_ID`

## 7. 升级与回滚

- 升级：直接覆盖安装即可，本次不涉及设置结构、用户数据和存储格式迁移。
- 回滚：回到 `v0.4.1` 不影响配置文件和用户数据；如出现阻断问题以 `v0.4.3` 修复，不覆盖既有 tag。
