## 本次更新

### 云文档 Markdown 图片：粘贴/导入即上传云端

- 问题：在云端文档里粘贴/导入图片后，Markdown 内是**本地路径**（如 macOS `/var/folders/.../assets/x.png`），云同步只上传 `.md` 文本、不传图片，云端阅读时裂图。
- 修复：云文档标签（`tab.cloudFileId` 存在）粘贴或导入图片时，写完本地 assets 后**立即上传到云端附件**（绑定该云文档），无需再手动点「同步至云端」。
  - 成功：提示「图片已插入并同步到云端」。
  - 上传失败或预检跳过：**不阻断插入**（图片已在本地可预览），提示可稍后「同步至云端」重试。
  - 本地文档（无云文档标识）行为完全不变。
- 上传前预检复用云端同步同一套口径：png/jpg/jpeg/gif/webp、单张 ≤20MB、相对路径规范化；云端不支持的格式（svg/bmp/avif 等）直接跳过并给原因。
- 新增 `services/markdownImagePasteService.ts`（决策 + 可注入上传，便于单测）；`App.vue` 两处图片链路接入；i18n 新增中英提示。
- 同一云文档 + 同一相对路径做并发互斥，避免连点重复请求（后端本已按内容哈希幂等）。

## 已知限制

- 本次仍让 Markdown 保留**相对路径**（本地预览与云端渲染均正常）。
- 「Markdown 里直接写云端 URL」需要后端提供匿名或签名可访问的图片 URL：当前 `GET {base}{CLOUD_DOCS_PATH}/{fileId}/assets/{assetId}` 需登录态 `Authorization`，`<img src>` 无法携带；且上传接口不返回 URL。该方案涉及后端接口与鉴权模型调整及部署，属后续工作。
