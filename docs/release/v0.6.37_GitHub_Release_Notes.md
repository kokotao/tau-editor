## Tau Editor v0.6.37

本次版本集中完善云文档历史预览、思维导图画布交互与云端协作入口。

### 云文档历史预览

- 历史版本支持按文件格式只读预览：Markdown、思维导图、JSON、XML、YAML、SQL 与常见代码/配置文本。
- `.taumap` / `.mm` / `.opml` 历史版本可直接以导图查看，支持适应面板、原始尺寸和源码切换。
- 历史预览弹窗改为宽屏双栏，版本列表与正文独立滚动；Markdown 链接统一交给系统默认浏览器打开。
- 修复历史版本文件缺失时返回路径 404 的问题，预览失败不再覆盖版本列表。

### 思维导图

- 画布右上角新增 mini 快捷绘图工具，支持两点创建关系线、添加主题、边界与概要。
- 节点支持同级拖拽排序；修复全屏模式与右侧属性/样式面板、缩略图和 HUD 的布局冲突。
- 节点属性、画布样式与节点样式合并为同一侧栏的三个同级页签，点击画布或节点自动切换目标页签。
- 思维导图右键菜单新增“同步至云端”和“一键分享”，复用现有云端分类选择与分享流程。

### 验证

- Tau Editor 前端单元测试：158 个测试文件、2360 项全部通过。
- Vue 类型检查通过。
- lizi 后端使用 WSL + JDK 17 构建成功并部署；线上 OpenAPI 已确认历史预览 GET 路由。
