# Tau Editor v0.6.28 发布记录

## 发布概要

- 版本号：`v0.6.28`
- 发布日期：2026-10-28
- 发布类型：云文档文件夹上传体验补强 + 云端文件夹一键分享（配套服务端与公开页同日上线）
- 发布分支：`feature/cloud-doc-sync`

## 本次更新

### 云文档文件夹上传

- 上传弹窗新增「后台进行」：只隐藏窗口、不中断队列；状态栏出现可点击进度徽标；后台中重新打开保留进度；后台完成也给出汇总提示并刷新云端树。
- 上传中再次右键文件夹：提示「已有上传任务进行中」并直接打开进度窗口，不启动重复队列。
- Markdown 图片附件同步可见：确认页展示规则与开关状态；结束页展示已同步/失败/跳过张数，并单独统计未同步引用（跨目录 `../`、绝对路径、外链、非白名单格式）。
- 独立图片文件跳过原因改为「随引用的 Markdown 作为附件上传」。

### 云端文件夹一键分享

- 分类右键「一键分享文件夹」→ 生成公共目录页 `…/s/f/{token}`，可设密码/有效期/含子分类，支持复制、重新生成、撤销。
- 公开页免登录阅读文件夹内 Markdown/代码/文本（流程图、表格、折叠块、代码高亮、图片附件），PDF/Office 提示在 Tau 打开。
- 后端新增 `user_document_folder_share` 表与 7 个接口；文件夹票据使用独立 HMAC 域，密码错误限流，撤销/过期/越权统一 404。
