# Tau Editor v0.4.0 发布记录（体验增强版）

> 发布时间：2026-09-22
> Release 标签：`v0.4.0`
> 基线：`v0.3.3`
> 发布仓库：https://github.com/kokotao/tau-editor

## 1. 版本定位

在 v0.3.3 数据安全闭环（revision 事务、三方冲突、恢复库 v2）之上，补齐「可定制 + 可比对 + 可扩展」的体验层能力，并完成启动性能分包。

## 2. 亮点

- **主题包**：导入 / 导出 JSON 主题包，UI 与 Monaco 同步切换。
- **快捷键自定义**：录制改键、冲突覆盖确认、单条 / 全部重置，命令面板展示生效绑定。
- **文件对比**：只读 Monaco Diff，支持并排 / 内联切换，覆盖命令面板、文件树、Git 变更三个入口。
- **多窗口迁移**：把标签在新窗口打开或迁移到新窗口，保留未保存内容。
- **Provider 扩展点**：主题 / 命令 / 文件动作三类注册表，错误隔离且可见。
- **启动性能**：入口 chunk 1,115 KB → 313 KB，Monaco 与 Markdown 渲染依赖按需加载。
