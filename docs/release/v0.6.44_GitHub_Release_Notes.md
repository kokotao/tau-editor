# Tau Editor v0.6.44

## Markdown 预览

- 首次打开 Markdown 文档默认双栏，已保存的标签预览模式与全局设置继续保留。
- 新增宽/中/窄预览宽度档位；鼠标、键盘和数值输入缩放会同步更新倍率，并保持内容居中。

## Mermaid 流程图

- 默认缩放为 75%，支持手动输入倍率。
- 全屏查看改为居中弹窗；打开时默认 100%，即使在 100% 缩放下也能滚动画布。
- PNG 与 SVG 导出支持选择保存位置；修复 PNG 导出及复制图片失败的问题。
- 全屏查看按钮改为图标按钮，并保留可访问标签。
- 导图文字菜单复制会保留最近一次非空文本选区。
