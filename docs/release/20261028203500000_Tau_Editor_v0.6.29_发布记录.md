# Tau Editor v0.6.29 发布记录

## 发布概要

- 版本号：`v0.6.29`
- 发布日期：2026-10-28
- 发布类型：安全/数据隔离修复（云文档分类跨用户可见）
- 发布分支：`feature/cloud-doc-sync`

## 本次修复

- 根因：云文档分类复用博客全局 `category` 表，`tree()` 无用户过滤，创建分类也写入全局表，
  导致任何用户都能看到并选中他人创建的分类，同时污染博客分类。
- 服务端：`category.owner_id`（NULL=全局博客/题库分类，非空=云文档私有分类）；云文档分类
  tree/create/rename/delete/移动文档/文件夹分享全部按 owner 校验；唯一索引改为
  `(owner_id, parent_id, name)`；博客分类查询限定 `owner_id IS NULL`。
- 客户端：`fetchManagedCategories` 不再回退博客公开分类；浏览弹窗/侧栏/同步弹窗统一调用管理端接口。
- 数据迁移 `sql/20261028_category_owner.sql`：拆分混合分类、回填归属、清理空分类、替换索引，
  含快照、断言与回滚说明；执行前已做全量数据库备份（G 盘，4 份 446M）。

## 验证

- 迁移断言：无归属缺失 0、跨用户文档引用 0、重名冲突 0；云文档分类 5 个、全局博客分类 44 个。
- 公开接口 `GET /lizi/blog/pages/categories` 不含任何私有分类。
- 后端 jar 已热替换（备份 `/usr/local/runtime/lizi-learning-1.0.0.jar.bak-20261028-202102`），
  `/lizi/v3/api-docs` 200。
- Tau：`npx vitest run` 全绿、`vue-tsc --build` 0 error。
