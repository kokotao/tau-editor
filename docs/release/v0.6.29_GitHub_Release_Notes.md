# Tau Editor v0.6.29 Release Notes（可直接粘贴）

## Tau Editor v0.6.29

这是一次**安全与数据隔离修复**：云文档分类变为每个用户私有，彻底修复「能看到别人创建的分类」的问题。

### 修复内容

- 云文档分类不再复用博客全局分类：`category` 增加归属用户，分类的读取 / 创建 / 重命名 / 删除 / 移动文档 / 文件夹分享全部按当前登录用户隔离；访问他人的分类一律 404，不暴露存在性。
- 不同用户可以各自创建**同名**分类（唯一索引改为「归属用户 + 父级 + 名称」）。
- 博客 / 题库分类保持全局，私有云文档分类不再混入博客分类列表。
- 客户端不再回退「博客公开分类」：云文档浏览弹窗、侧栏分类树、同步弹窗统一使用按用户隔离的接口。
- 线上历史数据已完成迁移：混合归属分类按用户拆分、历史分类回填归属、无引用的空分类清理，迁移脚本与校验断言一并入库。

### 验证

- 迁移断言全绿：无归属缺失、无跨用户文档引用、无重名冲突。
- 公开博客分类接口不再包含任何私有分类。
- 客户端 1689+ 单测与类型检查通过；服务端相关测试类全绿并已热部署。

### 升级说明

- 覆盖安装即可。升级后「同步至云端」分类列表只显示你自己的分类；如果升级前把文档放在了别人的分类下，
  服务端已按归属拆分/回填，不会丢文档（显示在正确的归属下）。
- 该修复需要服务端同步升级，云端服务已同步上线。
