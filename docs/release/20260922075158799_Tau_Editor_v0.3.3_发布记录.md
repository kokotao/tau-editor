# Tau Editor v0.3.3 发布记录

> 类型：发布记录（发布准备中）

## 发布目标

v0.3.3 是「安全收口版」：把恢复、外部变更、大文件、搜索替换、Markdown 资产五条数据安全链路补齐，并让关键路径有 E2E 兜底。

## 用户可见变化

### 恢复与退出（W1/W2）

- 会话与未保存草稿迁移到 Tauri `app-data/recovery-v2`，不再依赖浏览器 `localStorage`。
- 启动为异步恢复流程，可恢复工作区、标签、活动文件、光标、滚动位置和未保存草稿。
- v1 会话/草稿自动迁移；损坏或超大记录不会阻塞启动。

### 外部变更与冲突（W3）

- 工作区监听改为 `notify` 递归监听并通过 `workspace:file-changed` 推送事件；监听不可用时自动退回 1.5 秒轮询。
- dirty 文件被外部修改时只标记冲突，不覆盖内存内容；可查看三方 Diff 并选择重载、保留或另存为。
- clean 文件自动重载，重命名跟随已打开标签。

### 大文件与保存事务（W4）

- 打开、分段加载、取消、失败重试、完成、保存全部进入明确状态机；加载中只读。
- 大文件保存走「写临时文件 → 提交前复核 revision → 原子替换」，超过 4 MiB 也能安全提交。
- revision 基线在打开时捕获，保存前不再重新采样磁盘版本；外部改动一律以 `FILE_CONFLICT` 拦截，不静默覆盖。

### 搜索与替换（W5）

- 搜索升级为带 `searchId` 的可取消会话，失效 `searchId` 不会重新触发搜索。
- 替换先展示不可重叠预览，再按文件独立提交，成功/跳过/失败/撤销逐项可见。

### Markdown 资产与上下文（W6）

- 图片经原生选择器导入到文档同级 `assets/`，同名同内容自动复用并插入光标处。
- 相对链接状态 600ms 去抖校验，工作区任务可聚合、可跳转，HTML 导出可直接选择目标目录。

### 编辑器稳定性（W7）

- 修复标签切换竞态导致的内容串写：输入去抖未落盘时切换标签，内容会先按模型对应的标签 id 回写，再切换模型，不再丢失或写进相邻标签。
- E2E 用例改为确定性断言（保存/编码/自动保存/字数/标签计数），粘贴覆盖应用自身右键菜单粘贴实现。

### 发布前审查修复（R1-R3）

- **R1（P1）**：`git.rs` 的 Git 子进程补上 `CREATE_NO_WINDOW`，Windows 下 git status/diff/add/reset 不再弹控制台黑框，与 v0.3.2 的修复范围对齐。
- **R2（P2）**：CI 新增 `frontend-e2e` job（chromium 51 用例，失败上传 playwright 报告），与 typecheck/build、unit、Rust 门禁组成四道 CI 卡口。
- **R3（P2）**：安装包 `Source Code` 文件关联移除 `sh/bash/zsh/ps1`，与 v0.3.1「脚本类扩展名默认不关联」决策一致；已用构建产物的 `Info.plist` 复核。

## 已知限制

- 不包含远程同步、协作编辑、完整 LSP、插件市场与云存储。
- 替换按文件独立提交，不提供跨文件原子事务。
- 无头浏览器无法脚本化系统剪切板触发的 `Ctrl+V`，E2E 改为覆盖应用自身的右键菜单粘贴路径。
