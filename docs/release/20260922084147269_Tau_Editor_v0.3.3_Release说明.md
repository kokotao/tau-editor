# Tau Editor v0.3.3 · 安全收口版

v0.3.3 把「恢复、外部变更、大文件、搜索替换、Markdown 资产」五条数据安全链路补齐，并让关键路径有自动化门禁兜底。

## 本版亮点

### 崩溃/退出不再丢稿

- 会话与未保存草稿迁移到应用数据目录的 `recovery-v2`，不再依赖浏览器 `localStorage`。
- 启动为异步恢复：自动还原工作区、标签、活动文件、光标、滚动位置与未保存草稿。
- 旧版（v1）记录自动迁移，损坏或超大记录不会阻塞启动。

### 外部修改不再静默覆盖

- 工作区改为 `notify` 递归监听并推送变更事件，监听不可用时自动退回 1.5 秒轮询。
- 已修改未保存的文件被外部改动时只标记冲突，提供三方 Diff，可选择重载 / 保留当前内容 / 另存为。
- 未修改的文件自动重载，外部重命名会跟随已打开标签。

### 大文件保存走事务

- 打开、分段加载、取消、重试、完成、保存都有明确状态机，加载中只读。
- 保存流程为「写临时文件 → 提交前复核 revision → 原子替换」，被外部改动一律拦截，不静默覆盖。
- 超过 4 MiB 的文件也能安全提交。

### 搜索与替换

- 搜索升级为可取消会话，过期的搜索请求不会再把旧结果写回界面。
- 替换先展示不可重叠的命中预览，再按文件独立提交，成功 / 跳过 / 失败 / 撤销逐项可见。

### Markdown 写作

- 图片经原生选择器导入到文档同级 `assets/`，同名同内容自动复用并插入光标处。
- 相对链接状态做去抖校验，工作区任务可聚合、可跳转，可直接导出为独立 HTML。

### 稳定性修复

- **修复标签切换内容串写（P1）**：输入去抖尚未落盘时切换标签，内容会先按模型对应的标签 id 回写，再切换模型，不再丢失或写进相邻标签。
- **修复 Windows 控制台闪窗（P1）**：Git 子进程补上 `CREATE_NO_WINDOW`，GUI 进程下执行 git status/diff/add/reset 不再弹出黑框。

## 安装包

| 平台 | 产物 |
| --- | --- |
| macOS（Apple Silicon / aarch64） | `.dmg`（本版 CI 矩阵只在 arm64 runner 构建，Intel 机器请等 x64 包或自行从源码构建） |

## 已知限制

- macOS 产物目前只提供 aarch64（Apple Silicon）；Intel Mac 需要额外一轮 `macos-13` 构建才能覆盖。

- 不含远程同步、协作编辑、完整 LSP、插件市场与云存储。
- 替换按文件独立提交，不提供跨文件原子事务。
- 无头浏览器无法脚本化系统剪切板触发的粘贴快捷键，E2E 改为覆盖应用自身的右键菜单粘贴路径。

## 回滚

- 应用层：回退安装 `v0.3.2`。
- 数据层：`recovery-v2` 之外仍保留 v1 记录，可回退读取；如出现阻断问题，以 `v0.3.4` 修复而不是覆盖既有 tag。
