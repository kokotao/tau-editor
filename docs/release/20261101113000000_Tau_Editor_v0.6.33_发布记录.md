- 版本号：`v0.6.33`
- 发布日期：2026-11-01
- 发布类型：云文档 Markdown 图片改为「签名直链」（体验修复 + 后端能力）

## 本次更新

### 云文档图片：粘贴即写「云端签名直链」

上一版（v0.6.32）只做到「粘贴即上传云端附件 + Markdown 保留相对路径」，实测仍有裂图：

- **编辑预览裂图**：Markdown 里是本地相对/临时路径，编辑器预览加载不到；
- **个人中心预览裂图**：渲染 Markdown 时没有把相对路径映射成可访问地址；
- 云端分享页能显示（分享页有 token 鉴权的图片接口）。

本版改为：**粘贴/导入图片 → 上传云端 → 把签名直链写进 Markdown**，任何端都能直接 `<img src>` 加载。

### 后端新增能力（已部署到 note.lizipro.cn）

- `AssetVO` 新增 `url` 字段：上传/列表接口下发图片**签名直链**
  - 形如 `https://note.lizipro.cn/lizi/miniProgram/cloud/docs/file/{assetId}?sig=t1.<exp>.<hmac>`
  - HMAC-SHA256 签名，域前缀 `cloud-doc-asset-url-v1`（与 JWT、分享票据隔离，互不通用）
  - 有效期 10 年（直链会长期写进用户 Markdown，短有效期会让旧文档裂图）
- 新增**匿名**读图接口 `GET /miniProgram/cloud/docs/file/{assetId}?sig=...`
  - 只校验签名与过期，不要求登录态（`<img>` 无法携带 Authorization 头）
  - 只允许图片（`image/*`）；所属文档已删除时附件级联清理 → 404
  - ETag + 304、公开缓存 7 天
  - `SecurityConfig` 公开路径新增 `/miniProgram/cloud/docs/file/**`
- 安全口径：签名覆盖 `assetId + 过期时间`，猜到 assetId 并不能取图；文档删除后旧直链失效。

### 桌面端

- Rust `CloudAssetInfo` 新增 `url` 字段（透传后端下发的直链）。
- `markdownImagePasteService`：
  - 上传结果透出 `url`；新增 `buildMarkdownImageSnippet`（生成 `![alt](url)`）与 `resolveCloudAssetUrls`（`relPath → url` 映射）。
- `App.vue` 两处图片入口（粘贴剪贴板图片、工具栏「插入图片」）：
  - 云文档：先上传拿直链，再把直链写进 Markdown；
  - 旧后端未返回 `url` 时回退相对路径（不阻断插入）；
  - 本地文档行为不变。

### 顺带修复

- `ShareStatsDialog` 单测写死了 `2026-10-25` 的 daily 日期，时间走过 7 天窗口后必然失败（日期敏感的过期测试）→ 改为相对今天生成。

## 已知限制

- **存量文档**里已有的相对路径图片（`assets/x.png`）不会自动变成直链，需要重新粘贴或等待后续「打开时按 assetsList 批量替换」的增量方案。
- 个人中心/网页端若要显示存量相对路径图片，仍需要渲染前做 `relPath → 直链` 替换（本版新粘贴的内容不受影响）。

## 回滚

- 桌面端：安装 `v0.6.32` 覆盖即可。
- 后端：`docker exec -u root lizi-learning-management cp /app/backups/lizi-learning-1.0.0.jar.cloud-asset-url-<TS> /app/lizi-learning-1.0.0.jar && docker restart lizi-learning-management`
