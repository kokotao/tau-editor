# Tau Editor v0.6.13 发布记录

## 发布概要

- 版本号：`v0.6.13`
- 发布日期：2026-10-17
- 发布类型：Markdown 预览编辑与桌面安装包修复版本

## 本次更新

- Markdown 预览支持正文、标题、引用、列表、链接、代码块和折叠块双击编辑。
- 选中文字后可通过浮动工具栏和快捷键进行加粗、斜体、删除线、标题、引用、列表、链接和删除。
- 修复选区工具栏边缘遮挡、失焦未隐藏和点击工具栏选区丢失。
- 表格支持新增/删除行列、整表删除确认和局部 DOM 更新。
- 修复表格删除后的预览滚动位置跳回顶部和闪烁。
- 修复预览编辑后的 `Ctrl/Cmd + Z` 撤销，直接使用 Monaco model undo/redo。
- Mermaid 流程图支持放大和缩小，并同步画布尺寸。
