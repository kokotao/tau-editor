# Tau Editor v0.3.0 发布记录

## 发布目标

将 Tau Editor 升级为本地优先的写作与代码一体工作台，并发布 macOS 安装包与 GitHub Release。

## 用户可见功能

- 工作区安全 Runtime：受限 `workspaceId`、文件 revision 与条件原子写入。
- 会话/未保存草稿恢复：启动时可恢复或丢弃草稿。
- 外部文件修改：右侧上下文提供重新加载或保留当前内容。
- 大文件：沿用现有分块加载、加载期只读和安全保存限制。
- 快速打开：`⌘P` 检索当前工作区已索引文件。
- 项目搜索：`⌘⇧F` 支持工作区文本/正则搜索与源行定位；后端具备 revision 校验替换接口。
- Git 上下文：状态、Diff、暂存、取消暂存与恢复工作区文件。
- Markdown：右侧任务与链接导航、独立 HTML 导出。
- 代码上下文：继续使用现有代码符号大纲与精确跳转能力。

## 验证门槛

- `pnpm test:unit`
- `pnpm typecheck`
- `pnpm build`
- `cargo test --manifest-path frontend/src-tauri/Cargo.toml`
- `cargo check --manifest-path frontend/src-tauri/Cargo.toml`
- `pnpm tauri build`

## 回滚

若 v0.3.0 出现阻断问题，用户可继续使用 GitHub 的 v0.2.6 Release；不会覆盖已有 tag 或安装包。
