# Tau Editor v0.6.5 图片预览发布记录

## 1. 发布范围

- Markdown 预览内容区跟随所在工作区宽度铺满，不再使用固定 `900px` 最大宽度。
- Markdown 中的图片、SVG、视频和 Canvas 限制在内容边界内，避免大图撑破渲染区域。
- 超宽 Markdown 表格放入独立横向滚动容器，表格内容不会改变外层布局宽度。
- Markdown 图片双击打开统一图片查看器；普通图片文件标签页双击使用同一查看器。
- 图片查看器支持关闭按钮、遮罩点击、Escape、双击/滚轮/按钮缩放、拖拽平移、顺逆时针旋转和重置。

## 3. 交互验收

通过 Chromium 真实浏览器验证：

1. Markdown 分栏预览列宽为 `473px`，与所在预览列一致；内容区无固定最大宽度。
2. 图片实际尺寸为 `1x1` 数据图时仍保持在内容边界内。
3. 超宽表格滚动容器 `clientWidth=425`、`scrollWidth=2052`，横向滚动未撑破外层。
4. 双击图片打开 `role=dialog` 图片查看器。
5. 点击放大后变换为 `scale(1.25)`，顺时针旋转后为 `rotate(90deg)`。
6. `Escape` 关闭查看器，当前编辑标签仍保持打开。

## 6. 风险、限制与回滚

- 本机构建使用 Tauri ad-hoc 签名，未配置 Apple notarization 凭据；用户首次打开 macOS 应用时可能需要在“隐私与安全性”中允许。
- GitHub Actions 负责 Linux/Windows 交叉平台构建，Actions 未完成前不能宣称跨平台 Release 已完整。
- 回滚方式：撤销 `v0.6.5` Release/tag，并恢复到 `v0.6.4`；代码回滚只涉及本记录列出的文件。
