## Tau Editor v0.6.38

本次版本继续完善思维导图工作流、云端分享和官网展示。

### 思维导图

- 思维导图工具栏支持鼠标滚轮、触控板双指横向滑动和触屏查看。
- 普通滚轮用于画布平移，`Ctrl/Cmd + 滚轮`用于缩放；修复画布点击、空白拖拽和节点拖拽。
- 修复设置面板全屏布局，作者信息、工作表和快捷键统一为状态栏同行布局。
- 官网展示全新的自研思维导图能力：彩虹主题、节点级样式、四种布局、大纲联动和大型知识结构。

### 云端协作

- 新增分享链接剪贴板识别、密码分享预览和分享转存客户端流程；分享转存服务端接口需单独部署后才可在线使用。
- 修复分享附件空值、相对图片 URL、分享票据和异步请求竞态。
- 云同步适配浅色主题，非设置页增加云端文档入口，并支持新版本更新提示。

### 会员视觉

- PLUS / PRO 会员显示金色立方体标识、到期信息和金色应用图标。

### 官网

- 更新 2026 年 11 月实拍截图，覆盖思维导图、Markdown 分栏预览、文档大纲和云端文档浏览。
- 更新官网创新文案，突出 Tau 自研思维导图引擎与本地优先的云端协作能力。
