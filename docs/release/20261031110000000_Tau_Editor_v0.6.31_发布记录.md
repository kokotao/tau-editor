# Tau Editor v0.6.31 发布记录

## 发布概要

- 版本号：`v0.6.31`
- 发布日期：2026-10-31
- 发布类型：UX-3 右键新建二级菜单、云端导图多格式、右侧双栏面板、全局工具栏布局（功能版本）
- 发布分支：`feature/cloud-doc-sync`

## 本次更新

### 右键「新建文件」二级菜单（本地 + 云端）

- 统一类型目录 `newFileTypeOptions`：Markdown / Tau 思维导图 / FreeMind / OPML / 纯文本 / JSON，每项含中英文名、扩展名、默认名与初始正文种子。
- 本地文件树右键「新建文件」展开二级类型菜单，选中后按类型补扩展名并写入合法种子内容（`.taumap` 空导图 JSON、`.mm` 空 FreeMind 地图、`.opml` 含根 outline 的 OPML）。
- 云端分类右键同样二级类型菜单，只展示云白名单内类型；进入内联卡片后预填默认名与类型提示。
- **自定义格式**：本地与云端二级菜单均新增「自定义格式…」项，用户输入任意文件后缀（如 doc / yaml / ts），经扩展名校验后按 `未命名.<后缀>` 创建；本地不限制白名单，云端仍受文本白名单约束。

### 云端思维导图多格式

- 三端白名单新增 `.mm` / `.opml`（52→54）：前端 `cloudUploadPolicy`、Rust `is_openable_text_path`、Java `CloudDocPathValidator`。
- 云端新建 `.mm` / `.opml` 会写入可被既有适配器解析的空文档，不再只能新建 `.taumap`。
- `.xmind` 为二进制 ZIP，不属于云端文本同步范围，保留本地/导出链路。

### 右侧双栏面板（大纲 / 属性）

- 大纲列与属性列移到编辑器外壳右侧，**两列独立**：各自折叠、各自 resizer（`mm-outline-resizer` / `mm-props-resizer`）、各自调宽（180–420px）。
- 右面板顶部不再自带 tab/收起条，开合由全局 Toolbar 的「大纲 / 属性」按钮或 `Ctrl+Alt+O / Ctrl+Alt+P` 控制。

### 全局工具栏布局

- 思维导图工具组并入全局 Toolbar 并**居中**，内容过宽可横向滚动（上限 80vw）；不再被右侧状态区遮挡。
- Tau 原始工具（新建/打开/文件夹/保存/另存/撤销/重做）移到**最左** start zone。
- 移除 Toolbar 中三个重复按钮（左栏开关、定位、右栏开关）——Tauri 标题栏与文件树 header 已有等价入口；保留 Markdown 预览切换按钮。
