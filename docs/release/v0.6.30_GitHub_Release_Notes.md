# Tau Editor v0.6.30（GitHub 发布说明，可直接粘贴）

## Tau Editor v0.6.30

思维导图交互体验打磨 + 云端 `.taumap` 支持（继续自研，无第三方导图库）。

### 思维导图

- **主题对比度修复**：修复暗色主题下「白底 + 浅色字」导致按钮/文字看不清的问题，组件全部改用真实主题 token，并加守卫测试防回退。
- **画布平移**：空白处拖动画布即可平移（此前绑定在容器上的事件被 SVG 遮挡而失效）。
- **节点拖拽**：按住节点拖到另一节点可改变父级，拖拽时有半透明 + 目标高亮反馈。
- **右键菜单**：画布节点/空白、大纲行右键均可打开快捷菜单（新增子主题、同级、重命名、复制、删除、折叠、属性面板等）。
- **边界与概要**：节点可添加「边界」（虚线圆角框 + 标签，包住主题与后代）与「概要」（子节点括线 + 文本），可撤销、可持久化。
- 大纲 / 属性面板宽度可拖拽调整（180–420px）。

### 云端 `.taumap`

- 云端新建 `.taumap` 自动写入合法空思维导图，打开即可开始创作；损坏文件提供「新建空白导图并覆盖」恢复入口。
- `taumap` 加入桌面与后端的文本白名单，可同步到云端并正常回显分类。
- 修复云端新建空分类不可见、编辑器内同步分类不回显；Markdown 加粗恢复渲染。

### 验证

- 全量单测 2156 通过、类型检查通过、真实 Chromium E2E 73 条全绿。

### 升级说明

- 覆盖安装即可。云端 `.taumap` 新建/同步需配套服务端白名单更新，桌面端本就可用。
