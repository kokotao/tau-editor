# Tau Editor v0.6.3 发布记录

发布日期：2026-10-02

## 修复内容

- 移除单文件模式下资源管理区的空状态提示；没有工作区时不再显示“资源管理器目前为空”。
- 修复 Markdown 编辑器右键分类二级菜单的运行态触发，支持鼠标悬浮、键盘聚焦和点击打开工具面板。
- 保留 v0.6.2 已交付的图片直接预览、图片只读保护、代码定义跳转、悬浮信息和资源区文件信息能力。

## 验证结果

- 全量单元测试：通过。
- Vue TypeScript 类型检查：通过。
- Vite 生产构建：通过。
- Playwright 真实浏览器：资源区空白状态与 Markdown 二级菜单可视化检查通过。
- Apple Silicon DMG：hdiutil、codesign、只读挂载、arm64 架构检查通过。

## 已知限制

代码导航仍为轻量符号索引，跨文件范围限于已打开的 Monaco 模型，尚未接入完整项目级 LSP。
