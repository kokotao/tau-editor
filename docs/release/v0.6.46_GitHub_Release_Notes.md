# Tau Editor v0.6.46

## Markdown and media

- Markdown preview images default to 75% width. Adjust the image width from Settings.
- Cache remote preview images locally, clean expired entries, and transcode eligible images to WebP when it reduces size.
- Add draggable, keyboard-operable horizontal scrollbars to code blocks and tables.

## Language services and updates

- Download managed language-server assets from the Tau Editor mirror, with Windows command-shim support and clearer detection states.
- Improve update discovery from the release manifest and fix stale manifest cache behavior.
- Add release-mirror cache validation, integrity checks, and a historical release backfill script.

## Cloud documents and workspace

- Add a filtered grid view and connect the cloud storage settings entry to cloud quota and upgrade options.
- Replace native file-delete confirmation with an accessible in-app dialog.
- Refine folder-upload and status-bar settings interactions.

## Website

- Improve release snapshot loading and restore release-anchor navigation after rendering.
- Correct mirrored macOS ZIP classification and keep mirror download links same-origin.

GitHub Actions builds and validates macOS universal, macOS arm64, Linux, and Windows installers for this release.
