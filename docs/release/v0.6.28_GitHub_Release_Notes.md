# Tau Editor v0.6.28 Release Notes（GitHub 发布说明，可直接粘贴）

## Tau Editor v0.6.28

本次更新补强云文档「文件夹上传」的使用体验，并新增「云端文件夹一键分享」——一个链接即可把整个分类作为公开目录分享出去。

### 云文档文件夹上传

- **后台进行**：上传时点「后台进行」只隐藏窗口、不中断队列；状态栏出现可点击进度徽标，随时重开查看进度，后台完成也会汇总提示。
- 上传中的文件夹再次右键时会提示「已有上传任务进行中」并直接打开进度窗口，不会重复启动。
- **Markdown 图片附件同步可见**：确认页说明图片同步规则（png/jpg/jpeg/gif/webp、单张 ≤20MB、仅同目录或子目录相对路径）与设置开关；结束页展示已同步/失败/跳过张数，并单独提示未同步的图片引用（跨目录 `../`、绝对路径、外链、不支持的格式）。

### 云端文件夹一键分享

- 云端文档树分类右键新增「一键分享文件夹」：生成公共目录页链接，可设置访问密码、有效期、是否包含子分类，支持复制链接、重新生成（旧链接立即失效）与撤销。
- 公开目录页 `…/s/f/{token}`：免登录浏览文件夹内文档列表，直接在线阅读 Markdown / 代码 / 文本（支持流程图、表格、折叠块、代码高亮与图片附件）；PDF / Office 提示在 Tau 桌面端打开。
- 安全：文件夹分享使用独立访问票据，密码 PBKDF2 校验并对连续错误限流；撤销、过期、越权文档统一 404，公开页不暴露路径等私有信息。

### 验证

- 123 个测试文件 / 1689 个用例全部通过；`vue-tsc --build` 与 `cargo check` 均 0 error。
- 配套后端 124 个单测通过并已热部署；公开页已上线，目录/正文/越权 404 均实测通过。

### 升级说明

- 覆盖安装即可，无需数据迁移；云端文件夹分享为增量能力，回滚到 v0.6.27 不影响已有文档与分享。
- 配套云端服务（文件夹分享接口与公开目录页）已同步上线。
