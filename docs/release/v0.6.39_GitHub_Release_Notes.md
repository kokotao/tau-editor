## Tau Editor v0.6.39

本版本沿用 v0.6.38 的全部编辑器、思维导图、云端分享、会员视觉和自动更新改动，并完成官网创新能力文案收口。

### 自研思维导图

- TauMap 自研数据模型、布局算法、SVG 画布、撤销与持久化由同一套引擎驱动。
- 支持四种布局、节点级视觉样式、彩虹分支、边界、概要、图片节点、属性面板和大纲联动。
- 普通滚轮平移，`Ctrl/Cmd + 滚轮`缩放；触控板双指滑动查看长画布和工具栏。

### 云端协作与分享

- 保留分享链接识别、密码预览、分享转存和云同步浅色主题能力。
- 保留非设置页云端文档入口与新版本更新提示。
