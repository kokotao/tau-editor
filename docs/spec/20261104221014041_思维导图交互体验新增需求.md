# 思维导图交互体验新增需求

> 创建日期：2026-11-04 22:10（Asia/Shanghai）  
> 来源：用户提供的两张思维导图界面截图  
> 状态：已实施（2026-11-04；新增专项 Chromium E2E 通过）

## 1. 目标

改善思维导图中节点文本编辑时的浮动工具栏可用性，补充选中文本的应用内右键菜单；同时让右侧样式面板顶部贴合可用视口，避免面板上方出现无效空白。

## 2. 需求一：选中文本工具栏与右键菜单

### 2.1 选中文本浮动工具栏

- 在节点文本编辑状态选中一段文本时，显示紧邻选区、且不遮挡选区的浮动格式工具栏。
- 工具栏控件尺寸与间距应便于鼠标及触控板操作，调色按钮需有足够大的点击区域；工具栏在窗口边缘处应调整位置，不能被画布边界裁掉。
- 点击文字颜色、背景色等格式控件后，保留文本编辑状态和原选区；应用格式后选区不应丢失，允许连续调整多种格式。
- 工具栏在选区清空、退出节点编辑、点击无关区域或按 Escape 后按预期关闭；打开颜色选择器时点击选择器不得被误判为点击外部。
- 无有效选区时不显示会造成误操作的格式动作。

### 2.2 选中文本右键菜单

- 节点文本编辑状态下，对非空选中文本右键时显示 TauEditor 应用内上下文菜单，不依赖浏览器/系统默认菜单。
- 菜单至少提供：剪切、复制、粘贴、粘贴为纯文本、全选；按宿主能力提供拼写检查/文字方向等次级操作，不得显示不可用的空操作。
- 剪切、复制、粘贴遵循系统剪贴板权限与快捷键语义；操作后选区、编辑焦点和节点内容状态正确同步。
- 菜单位置贴近指针但限制在窗口可视范围内；点击菜单项后关闭菜单，点击外部或按 Escape 关闭菜单。
- 右键未选中文本、非编辑状态及画布节点/连线的现有上下文交互保持各自既有语义。

## 3. 需求二：样式侧栏顶部吸附

- 右侧样式面板顶部应吸附到思维导图编辑器的可用视口顶部；面板上方不得保留截图所示的大块空白。
- 顶部工具栏、工作表栏若属于面板所在布局，应以其实际容器边界为吸附基准，不能覆盖这些固定操作区。
- 面板高度填满从吸附位置到编辑器底部的可用区域；内容超出时仅面板内部滚动，标题/标签导航在滚动时保持可见。
- 画布、工作表切换、窗口缩放、面板显隐和不同主题下，面板不应跳动、遮挡画布交互或产生双重滚动条。

## 4. 验收标准

- [x] 节点文本有选区时显示浮动工具栏，增大调色热区并按画布边界定位；格式提交后恢复原文本选区。
- [x] 文本选区右键显示应用内菜单，支持剪切、复制、粘贴、纯文本粘贴和全选；剪贴板失败提供反馈。
- [x] 右键菜单与浮动工具栏限制在画布可视区域内；菜单支持 Escape 与点击外部关闭。
- [x] 样式面板顶部与编辑器有效内容区对齐；内容内部滚动，面板标题/标签固定可见。
- [x] 既有节点右键菜单与画布关键路径在专项 E2E 中通过；完整 21 条思维导图 E2E 有 7 条既有失败（旧 tab 定位、适配倍率预期、导出数量、搜索/主题/工作表和列宽拖动），与本次新增交互无关，需另行修复。

## 5. 实施边界

- 不替换系统剪贴板实现；优先复用现有浏览器 Clipboard API/编辑器已有能力，并对权限拒绝提供可理解反馈。
- 不改变思维导图数据模型和导出格式；选区保留、菜单显隐和浮层定位属于编辑器交互状态。
- 样式面板吸附优先通过现有工作台布局容器实现，不以全局 fixed 浮层遮盖工作表栏或工具栏。
