# Tau Editor v0.3.0 自适应一体工作台规格

## 1. 目标与范围

v0.3.0 将 Tau Editor 升级为本地优先的写作与代码工作台。产品保留左侧项目区、中间内容区、右侧上下文区的扁平三栏布局；右侧能力由当前文件类型和用户任务驱动，而不是要求用户在“写作模式”和“开发模式”之间切换。

本版本一次性交付八项能力：

1. 工作区、标签页、光标与未保存草稿恢复。
2. 外部文件变更检测、对比和安全处理。
3. 大文件分块读取、追加加载和截断保护。
4. 工作区全局搜索与安全替换。
5. 快速打开、命令面板、最近工作区。
6. Git 变更列表、行级 Diff 与基础暂存操作。
7. 代码上下文：文件符号、问题与测试入口。
8. 写作增强：图片资源、链接关系、任务聚合、HTML 导出。

非目标：不在本版本实现远程同步、协作编辑、完整调试器、通用插件市场或全语言 LSP。代码上下文应采用可替换的 Provider 接口，为后续 LSP 保留入口。

## 2. 核心交互

### 2.1 固定框架

- 左侧：文件树、全局搜索结果、Git Changes、最近工作区和工作区任务。
- 中间：当前文件、搜索结果定位、Markdown 预览或 Diff。
- 右侧：按上下文显示 Markdown 大纲/任务/链接、代码符号/问题/测试、项目搜索/变更，或恢复/冲突处理。
- 顶部：`⌘P` 快速打开，`⌘⇧P` 命令面板，`⌘⇧F` 全局搜索。

现有小屏抽屉规则保持不变；新增面板只能复用左侧或右侧抽屉，不可为单独功能创建容器式页面。

### 2.2 上下文优先级

1. 未解决的恢复或外部修改冲突优先显示内容安全提示。
2. 正在执行的搜索或替换显示项目上下文。
3. 代码文件显示符号、问题、测试入口。
4. Markdown 文件显示大纲、任务、链接和资源。
5. 其他文本文件保留现有大纲或基础文件信息。

用户可以手动折叠右侧栏，但不会永久失去未解决冲突的入口。

## 3. 模块与契约

### 3.1 会话与草稿恢复

新增 `workspaceSession` Store，持久化最小会话快照：工作区根目录、打开文件、活动标签、分屏、视图状态、最近工作区。草稿独立保存为以路径哈希命名的恢复记录，包含原始文件指纹、内容、更新时间和恢复状态。

- 正常保存后删除对应草稿。
- 应用启动时对比草稿与磁盘指纹；仅显示仍有价值的恢复项。
- 用户可逐项“恢复”“丢弃”或批量处理。
- 路径与内容不写入浏览器云端；仅保存至本机应用数据目录或本地持久化存储。

### 3.2 文件变更保护

文件元数据使用 `mtime + size` 指纹，必要时回退到内容哈希。对打开文件建立观察；文件变更事件去抖后分为：

- 当前无本地改动：可自动提示重新加载。
- 当前有本地改动：禁止自动覆盖，显示“保留当前 / 重新加载 / 查看 Diff”。
- 文件被删除或移动：保留内存内容，明确显示路径状态并提供另存为。

### 3.3 大文件能力

后端已有 `read_file_chunked`、行范围读取和大文件配置命令；本版本把前端服务接入真实命令，消除仅预留调用的降级路径。

- 第一屏加载固定安全块，用户可追加前后内容。
- 超出高亮阈值时关闭高成本特性，状态栏说明原因。
- 任何只加载部分内容的文件均不得覆盖保存；必须使用“另存为”或完成内容加载后再保存。
- 分块边界不得产生 UTF-8 截断或 offset 死循环。

### 3.4 全局搜索与替换

新增可取消的项目搜索服务。优先使用受控 Rust 遍历与正则实现，支持路径过滤、大小写、全词、正则；搜索结果返回文件、行号、列号、预览和匹配范围。

替换流程始终是：预览命中 -> 选择范围 -> 写入前再次验证文件指纹 -> 原子写入 -> 汇总结果。发生外部变更、无效正则或权限异常时，不写入任何未确认文件。

### 3.5 快速工作流

`QuickOpen` 索引工作区文件和最近文件；命令面板注册命令、快捷键和可见性条件。最近工作区最多保存 12 项，支持固定和移除。

### 3.6 Git 上下文

新增受限 Git 服务，只允许在已选择工作区根目录中执行：状态、文件 Diff、暂存、取消暂存、丢弃单文件改动。丢弃操作必须先二次确认且不允许影响未跟踪文件；不存在 Git 或命令失败时显示可恢复错误。

### 3.7 代码上下文

新增 `ContextProvider` 接口：`supports(document)`、`getSections(document)`、`getActions(document)`。Markdown、JSON/YAML、代码文件分别实现 Provider。

代码 Provider 第一阶段使用 Monaco 文档符号与现有语言服务能力；显示符号、语法/模型诊断和项目中测试文件快捷入口。LSP 仅作为后续 Provider，不改变 UI 契约。

### 3.8 写作增强

- 图片资源：拖入图片复制到同级 `assets/`（用户确认后），插入相对 Markdown 链接；复制失败不修改文档。
- 链接关系：解析当前工作区 Markdown 相对链接，区分有效、失效、外链并提供跳转。
- 任务聚合：识别 `- [ ]` 与 `- [x]`，右侧展示当前文档和工作区任务并可精确跳转。
- HTML 导出：使用现有 Markdown 渲染与净化规则导出单一 HTML 文件；导出前校验目标路径。

## 4. 错误、数据和安全边界

- 所有 Tauri 文件/Git 命令先验证输入路径在当前工作区内，拒绝空路径、目录穿越和 NUL 字符。
- 搜索、分块读取、Git 和导出命令返回结构化错误码与用户可读消息。
- 会话恢复、草稿、最近记录均提供清理入口。
- 异步搜索、文件监听和右侧 Context Provider 都需使用请求序号或 AbortController，旧结果不得覆盖新文件状态。
- 所有写入使用原子写入；批量替换中单文件失败需保留已完成列表并说明失败文件。

## 5. 测试与验收

### 功能验收

1. 关闭并重启应用可恢复工作区、标签、活动文件和草稿；恢复与丢弃均可完成。
2. 外部修改已打开文件时，未保存内容不会被覆盖，并可进入 Diff 或重新加载。
3. 100MB UTF-8 文本可首屏打开并继续追加；partial 文件不可直接覆盖保存。
4. 搜索能定位跨文件命中；替换预览、取消、异常和原子写入路径可验证。
5. `⌘P`、`⌘⇧P`、`⌘⇧F` 在 macOS 可用，且不与编辑器快捷键冲突。
6. Git 工作区能查看状态和单文件 Diff；危险操作有确认。
7. Markdown 与 TypeScript 打开后右侧均提供相应上下文，切换文件时不出现过期内容。
8. 图片、链接、任务和 HTML 导出均可在真实工作区完成；失败时原文保持不变。

### 质量门槛

- 新增服务具备单元测试，Tauri 命令具备 Rust 测试。
- 补充至少一条 Playwright/Tauri 关键路径：恢复、搜索替换、外部修改或 Git Diff。
- `pnpm typecheck`、`pnpm test:unit`、`pnpm build`、`cargo test`、`cargo check` 和 `pnpm tauri build` 必须通过。
- 版本号统一升级到 `0.3.0`，生成 macOS 安装包，推送分支、合并主分支、创建 `v0.3.0` GitHub Release 并上传产物。

## 6. 迁移与回滚

旧版本的设置与布局键保持兼容；新增持久化数据带版本号，读取失败时回退默认工作区而非阻塞启动。GitHub Release 保留 v0.2.6；如 v0.3.0 发现阻断问题，用户可下载旧版或发布修复 tag，绝不覆盖已发布的 tag 与安装包。
