# 思维导图功能需求规格

> 创建日期：2026-10-16 16:15（Asia/Shanghai）  
> 最后更新：2026-10-16 17:26（Asia/Shanghai）  
> 状态：规划稿，待按阶段实施与验收

## 1. 背景与目标

Tau Editor 已有文件标签、保存/另存为、工作区外部修改检测、会话恢复和 Markdown 预览；Markdown 中的 Mermaid `mindmap` 目前属于只读渲染，不能提供节点拖放、层级编辑、主题样式和导图文件生命周期。本需求新增一个原生可编辑的思维导图文档类型，不改变 Monaco 文本编辑器及既有 Mermaid 预览行为。

目标是在桌面编辑器内完成从新建、编辑、保存、恢复到导入导出的本地闭环，并逐步覆盖常用的 XMind 类编辑能力：树结构编辑、画布操作、多种布局、主题样式、标注/关系、主流格式互通与分享输出。格式承诺按“具体格式 + 版本 + 读写能力”定义，不把“支持某个扩展名”直接等同于完整兼容。

## 2. 范围与产品决策

- 思维导图是独立标签页和独立文件类型；默认使用 `.taumap` 扩展名，文件正文采用 UTF-8、带 `schemaVersion` 的 JSON。`.taumap` 是 Tau 的原生无损格式。
- 外部格式统一经过格式注册表、文件探测器和适配器转换为 Canonical MindMap Model；适配器必须声明格式版本、读写能力、可逆字段、可能丢失的字段和安全限制。
- 支持等级分为：Native lossless（原生无损读写）、Compatible with warnings（可编辑但可能有损，保存/导出时提示）、Read-only/unsupported（只读查看或明确不支持）。
- 外部格式默认导入为新的 `.taumap` 文档，不原地覆盖源文件；回写外部格式必须显式“另存为”并显示有损警告。
- `.map` 是高歧义扩展名，不能按后缀直接判断为思维导图；必须结合文件头、ZIP 内部条目、XML/JSON 结构探测，无法判定时要求用户选择具体格式或明确不支持。
- 复用现有文件打开/保存/另存为、标签 dirty 状态、外部修改检测和未保存草稿恢复机制。正式文件是持久化主来源，会话恢复只负责未保存内容，不替代正式保存。
- MVP 单文件、单工作表、树结构、自动布局、本地使用；先让常见导图编辑可靠，再添加复杂结构和互通。
- 画布建议使用独立 SVG 组件和布局服务；节点坐标由布局计算，不把自动布局坐标当作正文持久化。若可用性/性能验证不满足验收，再评估画布方案或依赖。
- 不将 Mermaid 文本模式扩展成编辑器，也不将 `.json` 普通文件误识别成导图；不把所有 `.map` 文件静默识别为思维导图。

### 2.1 格式兼容矩阵（规划基线）

| 格式 | 首要定位 | 计划读写能力 | 主要限制 |
|---|---|---|---|
| `.taumap` | Tau 原生格式 | 无损读写 | 仅 Tau 原生 schema；通过版本迁移保持兼容 |
| `.xmind` | 主流交换格式 | P1 先导入，验证后支持基础子集导出 | XMind 8、Zen/Workbook 等版本结构不同；主题、概要、关系、附件等可能有损 |
| `.mm` | FreeMind/Freeplane XML | P1 双向交换 | 树、文本、链接较易映射；插件属性、布局和部分样式可能有损 |
| `.mmap` | MindManager 专有包 | P1 导入优先，导出后置 | 版本、专有对象、附件、加密和高级样式存在兼容差异 |
| `.mindnode` | MindNode 私有/包格式 | P2 实验性只读或通过中间格式导入 | 文件结构不稳定，不承诺原生无损回写 |
| `.map` | 歧义扩展名 | 内容探测后按具体厂商/格式适配 | 不能建立通用 `.map` 读写器；无法识别时只读或不支持 |
| `.opml` / Markdown | 开放桥接格式 | P0/P1 导入导出 | 主要保留层级和文本，样式、关系、附件等字段通常不在格式中 |

正式发布支持的格式必须补齐版本范围、真实样本、字段映射、损失说明和自动化测试；未达到矩阵门槛的格式只能显示为实验性或不支持。

## 3. 用户与核心场景

1. 用户从“文件 > 新建思维导图”或命令面板创建导图，输入中心主题并另存为 `.taumap`。
2. 用户用键盘快速添加子主题、同级主题、改名、删除、折叠/展开，并能用鼠标拖放重排或改变父级。
3. 用户在大画布上平移、缩放、适配内容、定位选中节点，并在画布和大纲视图之间切换。
4. 用户撤销/重做编辑，保存关闭后重新打开，或在异常退出后恢复未保存草稿。
5. 用户将 Markdown 大纲导入为节点树，并导出 Markdown、PNG 等可分享结果。
6. 用户打开 `.xmind`、`.mm`、`.mmap` 或可识别的 `.map` 文件，查看探测到的格式与版本，预览字段映射和可能损失，再导入为可编辑地图。
7. 用户将当前地图另存为外部格式；系统在覆盖/有损/不支持时明确提示，并提供安全回退到 `.taumap`。
8. 用户以后可在节点上添加备注、标记、链接、概要、关系线，使用组织结构/逻辑图等结构，并扩展更多格式适配器。

## 4. 功能分期

### P0：可用 MVP

**文档与编辑**

- 创建、打开、保存、另存为 `.taumap`；新建文档包含一个可编辑中心主题。
- 节点支持添加子节点、添加同级节点、改名、删除、复制/粘贴、调整顺序。
- 支持拖放移动节点、改变父节点；拒绝把节点移动到自身或其后代之下。
- 删除有子节点的主题时提示受影响的子树；删除中心主题需显式确认。
- 折叠/展开分支；长文本自动换行并完整呈现中文及 Unicode。

**画布与导航**

- 中心主题布局；画布支持选择、平移、滚轮缩放、适配内容、回到中心。
- 显示选中态和清晰的父子连线；提供基础浅/深色主题及层级配色。
- 提供大纲视图作为键盘导航、快速编辑及辅助访问的补充。

**编辑历史与快捷键**

- 支持撤销/重做；节点增删、改名、重排、拖放和折叠状态按明确的历史规则处理。
- 默认键位建议：Tab 添加子节点，Enter 添加同级节点，F2 改名，Delete 删除，方向键移动焦点，Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做。
- 思维导图激活时才接管地图快捷键，避免拦截 Monaco、输入框和系统快捷键。

**保存、恢复与交换**

- 标签显示未保存状态；编辑内容经现有保存管线写入正式文件，保留外部修改冲突保护。
- 未保存草稿可走现有 session/recovery 服务；解析失败或不支持的 schema 不自动覆盖源文件。
- 从常见 Markdown 标题/项目符号大纲导入层级；导出 Markdown 大纲与完整 PNG。
- 导入失败必须保留当前地图不变；导出图片应包括完整地图内容而非当前视口裁切。

### P1：覆盖多数日常导图功能

- 结构：思维导图、逻辑图、组织结构图、树形图等布局；一个文档多个工作表/中心主题。
- 主题：更多布局方向、主题模板、节点形状/填充/文字样式、分支线样式和层级色彩。
- 语义标注：备注、超链接、标签、图标/优先级标记、边界/概要、主题之间的独立关系线。
- 搜索和筛选节点；搜索结果可定位并展开隐藏分支。
- 导出 SVG、PDF/打印；按实际需求定义 PNG 分辨率和背景选项。
- 对地图文件 schema 增加向前兼容的迁移机制；未知字段在可编辑往返时不得被无意丢弃。

### P2：独立评估后实施

- `.mindnode` 实验性读取、具体厂商 `.map` 适配器及其他专有/二进制格式。
- 富文本、图片与附件、自由布局/手动坐标、演示/汇报模式。
- 云同步、多人实时协作和 AI 辅助分别立项，需另行定义服务端、权限、冲突和成本边界。

## 5. 数据模型建议

首期单工作表；关系、概要等扩展数据采用独立集合，避免将它们错误混入父子树。

```ts
interface MindMapDocument {
  format: 'tau-mindmap';
  schemaVersion: number;
  id: string;
  title: string;
  sourceFormat?: string; // 例如 xmind-zen、freemind-mm、mindmanager-mmap
  sourceVersion?: string;
  saveMode?: 'native' | 'imported' | 'exported';
  rootTopicId: string;
  layoutMode: 'mindmap';
  themeId: string;
  viewport?: { x: number; y: number; zoom: number };
  topics: Record<string, MindMapTopic>;
  relations?: MindMapRelation[];
  opaqueExtensions?: Record<string, unknown>;
  assets?: MindMapAssetRef[];
  sheets?: MindMapSheet[]; // P1
}

interface MindMapTopic {
  id: string;
  parentId: string | null;
  childIds: string[]; // 作为同级顺序的唯一来源
  text: string;
  collapsed?: boolean;
  style?: { color?: string; fill?: string; shape?: string };
  notes?: string; // P1
  labels?: string[]; // P1
  markers?: string[]; // P1
  link?: string; // P1
}

interface MindMapRelation {
  id: string;
  sourceTopicId: string;
  targetTopicId: string;
  label?: string;
  style?: string;
}

interface MindMapAssetRef {
  id: string;
  originalPath?: string;
  mimeType?: string;
  sizeBytes?: number;
}
```

数据校验必须保证 root 存在且 parentId 为空、父子引用互相一致、无重复/悬空 ID、无循环、关系端点存在。迁移按 `schemaVersion` 显式逐版执行；未知主版本以安全失败方式打开，不做静默降级写回。自动布局坐标不持久化；未来自由布局需要单独 `layoutMode` 及坐标字段迁移。`sourceFormat`、`sourceVersion` 和 `opaqueExtensions` 用于记录外部来源与暂未映射的数据，不得在原生 `.taumap` 往返时无意丢弃。

## 6. 主要界面与交互

- 新建入口：工具栏/文件菜单/命令面板；打开 `.taumap` 后作为独立 tab 进入地图编辑模式。
- 工作区：顶部地图工具栏；中心画布；可切换的大纲/属性侧栏；底部显示缩放比例或节点统计。
- 节点：单击选择、双击或 F2 编辑；Enter/Tab 快速创建；上下文菜单提供新增、删除、复制、折叠和样式；拖放时清楚展示目标位置。
- 画布：空白处拖动平移；滚轮缩放；适配内容后完整可见；支持键盘焦点与选中态，不依赖颜色单独表达状态。
- 删除、移动到其他父级、导入替换当前内容等会影响整支结构的动作提供确认/撤销保障。
- 外部文件打开后先显示“格式、版本、支持等级、可能损失”的导入预览；用户确认后再替换当前文档或创建新的 `.taumap` 标签。
- 保存外部格式时使用“导出/另存为”流程，不默认覆盖源文件；导出报告列出不支持或有损字段。

## 7. 非功能要求与安全边界

- 可访问性：所有基础编辑可用键盘完成；节点名称、层级和折叠状态具有可读的语义；焦点/选中/拖放目标有可见提示；支持窄窗口与高对比主题。
- 性能：首期验收至少覆盖 200 节点地图的打开、编辑和导航；另以 1k/5k/10k 合成数据测布局与交互，基于目标机器结果设定正式 SLA。暂定讨论门槛：1k 节点冷打开 ≤2 秒、常用操作 P95 ≤100ms，若测试设备或渲染策略使目标不现实，应在进入实现前修订。
- 稳定性：编辑不能丢节点；文件保存沿用现有 revision/冲突检查；恢复草稿容量限制不可成为正式文档存储上限。
- 导入安全：仅解析支持的文本/数据结构，不执行导入内容；ZIP/包格式必须设置压缩包大小、条目数、嵌套深度和解压后总量限制，拒绝绝对路径、`..`、符号链接、加密包和压缩炸弹；XML 禁用 DTD、外部实体和网络访问；临时目录必须清理。
- 兼容：普通文本、代码、Markdown 及 Mermaid mindmap 预览路径保持原状；普通 `.json` 行为不变。

## 8. MVP 验收清单

- [ ] 新建导图，添加中心主题、子节点、同级节点；编辑、复制、删除和重排均正确。
- [ ] 拖放能改变顺序/父级；不能成环或丢失分支；删整支前显示影响。
- [ ] Tab/Enter/F2/Delete/方向键及撤销重做可完成常用编辑，并且文本输入时不误触发。
- [ ] 折叠展开、平移、缩放、适配画布在不同窗口尺寸下有效，长标题和 Unicode 不裁切。
- [ ] 保存、关闭、重开后结构、顺序、样式和折叠状态一致；未保存关闭提示与恢复可用。
- [ ] Markdown 大纲导入/导出保留文本、顺序与层级；PNG 导出完整且可打开。
- [ ] `.taumap` 原生文件完整无损往返；每个正式支持的外部格式都有版本范围、读写能力、字段映射、损失项、真实样本和自动化测试。
- [ ] 打开 `.xmind`、`.mm`、`.mmap` 或可识别 `.map` 时显示格式探测结果和损失报告；无法识别的 `.map` 不得静默改写。
- [ ] 外部格式默认导入新 `.taumap`；回写源格式必须显式另存为并确认可能有损。
- [ ] 损坏文件、未知版本和失败导入不会静默覆盖源文件或污染当前文档。
- [ ] 200 节点示例可正常浏览编辑；普通文本/代码/Markdown 与 Mermaid mindmap 预览回归通过。

## 9. 已核对的项目依据

- 主工作台在 `frontend/src/App.vue`；编辑区域包含标签、Monaco 与各类预览分支，应以独立地图分支接入。
- 标签数据在 `frontend/src/stores/tabs.ts`；新建/打开与保存路径在 `frontend/src/services/workspaceService.ts`、`frontend/src/services/tabService.ts`。
- 会话恢复在 `frontend/src/services/sessionService.ts`；适合未保存草稿，不应替代 `.taumap` 正式文件。
- 命令、快捷键与双语文案扩展点为 `frontend/src/services/commandRegistry.ts`、`frontend/src/services/keybindingService.ts`、`frontend/src/i18n/ui.ts`。
- `frontend/src/services/markdownRenderService.ts` 中 Mermaid mindmap 为预览能力，需保持兼容但不可视为本需求的编辑器。
