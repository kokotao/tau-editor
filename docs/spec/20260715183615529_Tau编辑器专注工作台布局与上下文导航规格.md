# Tau 编辑器「专注工作台」布局与上下文导航规格

> 状态：已确认视觉方向，待规格审阅
>
> 日期：2026-07-15

## 目标

将 Tau 编辑器调整为自然的扁平三栏工作台：左侧管理工作区文件，中部专注编辑与预览，右侧持续呈现与当前文件类型匹配的结构导航和快捷操作。所有区域以细线分隔，消除浮层卡片、阴影和大圆角造成的容器感。

## 非目标

- 本期不重做文件树、标签拖拽、命令面板和设置页的业务逻辑。
- 本期不承诺覆盖所有编程语言的精准 AST 解析。
- 不改变现有主题和皮肤体系的颜色 Token。

## 布局与视觉规范

桌面端（`>= 1280px`）使用：顶部工具栏 `56px`、左栏默认 `248px`（范围 `220–360px`）、中栏自适应且最小 `520px`、右栏默认 `280px`（范围 `240–360px`）、底部状态栏 `40px`。

左/中、 中/右通过 `1px solid var(--border-soft)` 分隔。拖拽区域有 `8px` 命中范围，默认只显示 1px 细线，hover 或拖拽时转为 `var(--accent-brand)`。工作区内不保留外部 gap、`box-shadow`、`backdrop-filter` 或大圆角；按钮默认透明，hover 使用低对比背景，圆角不超过 `6px`。

栏标题高度 `40px`，标签栏高度收紧为 `40px`。激活标签使用文字强调和底部 `2px` 品牌色线；激活目录项使用左侧 `2px` 色线和弱背景，不使用独立卡片。

## 右侧上下文栏

新增 `ContextRail` 组件，只负责展示与事件分发；内容解析放在无 UI 副作用的 `documentOutlineService`。右栏由标题、结构/快捷操作切换、当前文件摘要、可滚动主体和固定底部快捷操作组成。

```ts
type OutlineItem = {
  id: string
  label: string
  kind: 'heading' | 'class' | 'function' | 'key' | 'selector'
  level: number
  line: number
  endLine?: number
  children?: OutlineItem[]
}
```

`ContextRail` 的最小输入为 `tabId`、`language`、`content`、`cursorLine`、`isLargeFile`、`isLoadingContent` 与 `previewMode`；只触发 `navigate(line)`、`find`、`go-to-line`、`save`、`update:collapsed`、`update:preview-mode` 事件。`documentOutlineService` 只能返回解析数据，不读取 Store，也不操作 Monaco。

| 文件类型 | 识别条件 | 结构内容 | 点击行为 |
| --- | --- | --- | --- |
| Markdown | `language === 'markdown'` | H1–H6 标题目录、行号与当前项 | 编辑器精确跳转到标题行；预览同步定位 |
| TypeScript/JavaScript/Vue/Python/Java/Go/Rust | 当前 Tab 的语言 | 类、接口、函数、方法 | 跳转至声明行 |
| JSON/YAML | `json` / `yaml` | 顶层及二层关键节点 | 跳转至键所在行 |
| 其他/无结构 | 兜底 | 文档统计与高频操作 | 查找、转到行、保存 |

右栏的通用操作为“查找”“转到行”“保存”；Markdown 额外提供编辑/分屏/预览模式切换。结构项超过 12 条时显示紧凑搜索框。大文件或未加载完成时不执行全量解析，显示解释性空状态且保持快捷操作可用。

## 交互与状态

- 当前结构项根据 `editorStore.cursorPosition.line` 同步，选择当前光标之前且层级最深的最后一个项。
- 点击目录项调用 `EditorCore.revealLine(line, column?)`，定位后将编辑器聚焦；行号必须 clamp 到实际模型范围。
- 目录折叠状态以 `tab.id` 维度保存，切换文件互不影响。
- 右栏有显式收起入口，并增加工具栏恢复入口；宽度与折叠状态持久化。
- Markdown 目录数据从源文本解析，不依赖预览 DOM 的默认锚点。`MarkdownPreview` 新增 `scrollToSourceLine(line)` 暴露方法；渲染标题写入稳定的 `data-source-line`。预览未就绪、无对应标题或 Mermaid 异步渲染期间，仍完成编辑器跳转并静默跳过预览同步。
- 普通文件在内容变化后以 `200ms` 防抖更新大纲，并在 `requestIdleCallback` 中解析；不支持时回退为 `setTimeout`。缓存键为 `tab.id + contentVersion`，右栏搜索仅过滤已有大纲。
- 大文件或分段加载文件不进行全量解析；最多扫描前 `5,000` 行并显示“结构已截断”，加载未完成时显示说明性空状态。
- 覆盖式抽屉使用统一状态 `OverlayPanel = 'settings' | 'context-rail' | 'explorer' | null`。同一时间仅一个覆盖层可见；打开任一抽屉会关闭其他抽屉，`Escape` 优先关闭当前覆盖层，关闭后恢复触发按钮焦点。

## 响应式策略

| 宽度 | 左栏 | 右栏 |
| --- | --- | --- |
| `>= 1280px` | 常驻、可调宽 | 常驻、可调宽 |
| `1024–1279px` | 常驻（默认 220px） | 默认收起，按需抽屉打开 |
| `800–1023px` | 覆盖式抽屉 | 覆盖式抽屉，不能与左栏同时常驻 |
| `< 800px` | 默认收起 | 默认收起，全高抽屉 |

当 Markdown 分屏与右栏会使中栏可用宽度小于 `760px` 时，编辑优先：自动将分屏降为编辑模式，预览继续由工具栏按需打开。

## 实现边界

- `App.vue`：三栏骨架、右栏状态/宽度、响应式切换、事件编排和去容器化样式。
- `ContextRail.vue`：目录、筛选、折叠和快捷操作展示。
- `documentOutlineService.ts`：统一输出 `OutlineItem` 的纯函数解析服务。
- `EditorCore.vue`：暴露精确跳行方法。
- `EditorTabs.vue`、`FileTree.vue`、`Toolbar.vue`：仅做扁平化视觉调整与右栏入口。
- `settings.ts`：持久化 `contextRailWidth` 与 `contextRailCollapsed`。

## 验收标准

1. 1440px 桌面端左/中/右三栏由细线自然隔开，工作区无独立容器阴影和大圆角。
2. Markdown 文件右栏可展示 H1–H6 目录，点击项可准确跳至对应编辑器行。
3. 第一阶段支持 TypeScript/JavaScript/Vue/Python/Java/Go/Rust 与 JSON/YAML 的轻量结构；无法解析时有可用兜底状态。
4. 查找、转到行、保存和 Markdown 预览模式可从右栏触发。
5. 宽度、折叠和窄屏退化符合本规格，且不破坏既有文件树、编辑、预览与主题行为。
6. 大文件不在每次输入时全量解析；普通文件目录更新为 `200ms` 防抖，扫描上限为 `5,000` 行。
7. 单元测试覆盖 Markdown 层级、重复标题、代码块内 `#`、JSON/YAML 解析失败、代码类型兜底，以及 `revealLine` 的行号 clamp 与聚焦。
8. 端到端测试覆盖 1440px 三栏显示、1100px ContextRail 抽屉、窄屏左右抽屉互斥，以及右栏宽度/折叠在重启后保留。
9. 视觉检查确认工作区三栏外层无 `box-shadow`、`backdrop-filter`、大于 `6px` 的圆角和外部 `gap`。

## 风险与处理

- 代码结构不宜以复杂正则覆盖所有语言：第一阶段限定语言与兜底态，后续再评估 Monaco Document Symbol Provider。
- Markdown 预览锚点不稳定：目录以源文本行号作为真源，预览同步另行建立稳定锚点。
- 三栏与 Markdown 分屏存在宽度竞争：以中栏最低宽度和自动降级保证编辑优先。
