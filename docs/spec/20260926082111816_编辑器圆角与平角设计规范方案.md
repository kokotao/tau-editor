# Tau Editor 编辑器圆角与平角设计规范方案

- 时间：2026-09-26 08:21
- 状态：已实施（2026-09-26 08:35）
- 目标版本：`v0.4.2`
- 范围：编辑器工作台及浮层 UI，不改变 Monaco、Markdown 和业务行为

## 实施结果

- 全局 token 已调整为 `0 / 2 / 4 / 6 / 8px`，圆形例外保留 `50% / 999px`。
- 工作台结构继续使用 `0` 圆角，未引入悬浮卡片化布局。
- 工具栏、标签、状态栏、菜单、输入框和按钮已应用微圆角。
- Command Palette、设置页、搜索、替换、通知、对话框及 Markdown 内容已按层级收口。
- 扫描确认不再存在 `9px` 以上的硬编码圆角。
- 浅色和深色主题均已完成视觉复核。

## 1. 设计结论

采用“结构平角、交互微圆、浮层小圆、语义圆形”的混合策略：

- 大面积结构继续使用 `0` 圆角，保留编辑器工具感和稳定边界。
- 按钮、输入框、标签、菜单项统一使用 `4px` 微圆角。
- 悬浮菜单、通知、Tooltip 使用 `4-6px` 小圆角。
- 对话框和 Command Palette 最高使用 `8px`，不再出现 `14-28px` 大圆角。
- 仅圆形状态点、加载环、头像、开关滑块使用 `50%` 或 `999px`。
- 文字按钮不使用胶囊形圆角，避免界面“卡片化、移动端化”。

## 2. 圆角 Token

现有 token 名称保持不变，便于局部替换：

```css
:root {
  --radius-none: 0;
  --radius-xs: 2px;
  --radius-sm: 4px;
  --radius-md: 6px;
  --radius-lg: 8px;

  /* 兼容现有命名 */
  --radius-pill: 999px;
  --radius-round: var(--radius-pill);
  --radius-round: var(--radius-pill);
  --panel-radius: var(--radius-none);
}
```

说明：

- `2px` 只用于极小图标按钮、徽标内部块和非常紧凑的元数据。
- `4px` 是默认交互圆角，约 80% 的可交互控件使用该值。
- `6px` 只用于浮层、菜单和内容卡片。
- `8px` 只用于对话框、Command Palette 和少量大浮层。
- 除圆形控件外，不增加 `10px` 以上圆角。

## 3. 平角与圆角边界

### 3.1 必须保持平角：`0`

这些区域负责定义编辑器结构，不参与“卡片化”：

| 区域 | 组件 |
|---|---|
| 应用骨架 | `.app-shell`、`.main-layout` |
| 顶层工作区 | 主导航栏、工具栏底边、状态栏 |
| 三栏布局 | 左侧栏、编辑器面板、上下文栏外框 |
| 全高边界 | 编辑器与预览分界线、左右 resizer |
| 标签栏容器 | `.tabs-container`、标签底部连接边 |
| 全宽列表行 | 文件树行、上下文全宽 hover 区域 |
| Monaco 区域 | 编辑器容器、滚动区域、代码内容 |
| 结构性分隔 | divider、section border、底部操作条 |

判断标准：元素贴边、跨栏或承载完整工作区时，保持平角。

### 3.2 建议轻微圆角：`2px`

| 区域 | 建议值 | 原因 |
|---|---:|---|
| 状态点内部块 | `2px` | 比完全直角更精致，但强度极低 |
| 极小加载标签 | `2px` | 避免文字与边界过紧 |
| 颜色色块 | `2px` | 只改善视觉边缘，不改变色块属性 |
| 列表内极紧凑操作 | `2px` | 保持高密度场景下的工具感 |

### 3.3 默认交互圆角：`4px`

| 区域 | 建议值 | 说明 |
|---|---:|---|
| 工具栏图标按钮 | `4px` | hover 时圆角轮廓更自然 |
| 标签主体 | `4px 4px 0 0` | 仅顶部圆角，底部连接编辑区 |
| 状态栏选择器 | `4px` | 替代当前完全平角 |
| 未保存徽标 | `4px` | 保持单行紧凑，不改成胶囊 |
| 输入框、下拉框 | `4px` | 与键盘操作和表单语义一致 |
| 普通按钮 | `4px` | 默认控件半径 |
| 菜单项 | `4px` | 悬浮背景更柔和 |
| 文件树操作按钮 | `4px` | 图标按钮可圆，行容器仍平角 |
| Tooltip | `4px` | 小浮层不宜过圆 |
| 通知操作按钮 | `4px` | 保持工具界面克制 |

### 3.4 内容与浮层：`6px`

| 区域 | 建议值 | 说明 |
|---|---:|---|
| 右键菜单外框 | `6px` | 与页面边界区分 |
| 系统菜单外框 | `6px` | 浮层层级明确 |
| 工作区搜索面板 | `6px` | 小范围浮层 |
| 替换预览面板 | `6px` | 高密度内容，不使用大圆角 |
| 通知卡片 | `6px` | 独立反馈单元 |
| 设置字段卡片 | `6px` | 比当前 `10-16px` 明显收敛 |
| Markdown 代码块 / 图片 | `6px` | 内容内部允许轻微圆角 |
| 表格容器 | `6px` | 比单元格直角更柔和 |

### 3.5 最高圆角：`8px`

仅限以下元素：

- Command Palette 外框。
- 居中确认对话框、外部变更对话框。
- 空状态主操作卡片。
- 需要明显脱离底层的模态浮层。

超过 `8px` 的圆角默认视为不符合规范。

### 3.6 圆形例外：`50%` / `999px`

允许圆形或胶囊的区域仅包括：

- 未保存状态点。
- 连接状态点。
- 加载环。
- 用户头像。
- 开关滑块。
- 滚动条滑块。
- 原生 check/radio 图形。

不能使用胶囊圆角的区域：

- 普通文字按钮。
- 标签页。
- 输入框。
- 状态栏选择器。
- 设置项操作按钮。

## 4. 组件落地映射

### 4.1 顶部工具栏

- 系统菜单外框：`6px`。

保留当前紧凑尺寸与单行状态，不恢复胶囊形态。

### 4.2 标签栏

- 标签悬浮详情：`4px`。
- 标签底部继续与编辑区对齐，不产生悬浮卡片感。

### 4.3 状态栏

- 状态栏外框：`0`。
- 状态项点击区域：`4px`。
- 编码 / 主题 / 语言选择器：`4px`。
- 自动保存状态：`4px`，不使用胶囊。
- 作者信息按钮：`4px`。

### 4.4 文件树与上下文栏

- 侧栏和上下文栏外框：`0`。
- 文件树搜索框：`4px`。
- 刷新 / 菜单图标按钮：`4px`。
- 文件树全宽行：`0`。
- 文件树选中态：保留左侧强调线，不增加卡片圆角。
- 上下文栏操作按钮：`4px`。
- 上下文全宽列表项：`0` 或 `2px`，优先保持连续阅读。

### 4.5 设置工作区

- 设置工作区外框：`0`。
- 导航项：`4px`。
- 设置字段容器：`6px`。

- 主题切换按钮、字号按钮、更新按钮：`4px`。
- 快捷键行：`4px`。
- 二维码卡片：`6px`，二维码图片内部 `4px`。
- 不使用当前 `10-16px` 的卡片圆角。

### 4.6 浮层与对话框

- Command Palette 外框：`8px`。
- 搜索输入框：`4px`。
- 菜单项：`4px`。
- 快捷键标签：`2px` 或 `4px`。
- 普通弹窗：`8px`。
- 弹窗内按钮和输入框：`4px`。
- 外部变更提示中的状态块：`4px`。

### 4.7 Markdown 预览

- 正文表格：`6px`。
- 表格单元格：`0`。
- 代码块：`6px`。
- 引用块：`4px`。
- 图片：`6px`。
- 提示条：`4px`。
- Mermaid 图表容器：`6px`。

## 5. 嵌套圆角规则

父容器与子控件不能使用相同的大圆角：

```text
父容器 8px -> 子控件 4px
父容器 6px -> 子控件 4px
父容器 4px -> 子控件 2px
父容器 0px  -> 子控件 0-4px
```

原因：父级圆角大于子级时，视觉边界更稳定，不会出现“圆角套圆角”的臃肿感。

## 6. 交互状态规则

- hover、active、focus 不得改变圆角尺寸，避免元素跳动。
- focus-visible 使用 `1px` 外轮廓，保留当前圆角。
- hover 主要通过背景色和边框表达，不通过放大圆角。
- 禁用态保持原圆角，只降低透明度。
- 选择态使用左侧强调线、上边强调线或边框，不新增胶囊背景。

## 7. 建议替换表

| 当前值 | 建议值 | 适用场景 |
|---:|---:|---|
| `0` | `0` | 结构面板、全宽行、分隔区 |
| `0` | `4px` | 按钮、输入框、状态项、标签顶部 |
| `6-7px` | `4px` | 小按钮、紧凑输入框 |
| `8-10px` | `4px` | 设置按钮、菜单项、快捷键行 |
| `12-14px` | `6px` | 卡片、弹窗内分组、预览内容 |
| `16px` | `6px` | 设置字段卡片 |
| `18-26px` | `6-8px` | Command Palette、对话框 |
| `28px` | `8px` | 空状态主容器 |
| `999px` | `4px` | 文字按钮、徽标、选择器 |
| `999px` | `999px` | 仅状态点、滑块、滚动条、头像 |

## 9. 验收标准

1. 结构区域圆角必须为 `0`。
2. 普通交互控件默认圆角为 `4px`。
3. 内容卡片圆角不超过 `6px`。
4. 浮层和对话框圆角不超过 `8px`。
5. 除圆形例外，不再出现 `10px` 以上圆角。
6. 文字按钮和标签不再使用 `999px` 胶囊圆角。
7. 标签只允许顶部圆角，底部与编辑区平齐。
8. 所有 hover、active、focus 状态保持稳定尺寸。
9. 1280×720 与 1680×1050 下无明显视觉跳变。
10. 浅色、深色和主题包下边框、背景与圆角对比一致。

## 10. 非目标

- 不改成卡片式工作台。
- 不增加大面积留白。
- 不把工具栏、状态栏和侧栏做成独立悬浮面板。
- 不修改业务结构、路由、状态管理或数据模型。
- 不影响当前未提交的 macOS 签名与公证工作。

## 11. 推荐结论

建议采用以下最终边界：

```text
结构 0px
微元素 2px
交互 4px
内容/菜单 6px
大浮层 8px
圆形例外 50% / 999px
```

该方案只增加“一点点”圆角，但通过明确的结构平角规则，仍保持 Tau Editor 的工具型桌面产品特征。
