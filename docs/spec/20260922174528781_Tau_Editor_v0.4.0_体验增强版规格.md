# Tau Editor v0.4.0 体验增强版规格（Spec）

> 规格时间：2026-09-22 17:45
> 基线版本：`v0.3.3`（`cdbca32`，已发布）
> 目标版本：`v0.4.0`
> 定位：在 v0.3.3 数据安全闭环之上，补齐「可定制 + 可比对 + 可扩展」的体验层能力

## 1. 目标与非目标

### 1.1 目标

1. **主题可定制**：内置皮肤之外，用户可导入/导出自定义主题包，Web UI 与 Monaco 编辑器配色保持一致。
2. **快捷键可定制**：命令的按键绑定由用户覆盖，支持冲突检测、单条重置与全部重置，命令面板显示当前绑定。
3. **文件可比对**：提供 Monaco Diff 视图，支持「用当前文件对比工作区文件」与「查看 Git 变更差异」，并排/内联布局可切换。
4. **标签可迁移**：支持把当前标签在新窗口打开、迁移到新窗口，保留未保存内容。
5. **扩展点预留**：提供稳定的 Provider 注册接口（主题 / 命令 / 文件动作），内置示例实现，为后续插件体系留出边界。
6. **启动性能可度量**：Monaco 语言按需注册，渲染类重依赖（mermaid 等）延后加载，构建产物分包明确。

### 1.2 非目标

- 不做远程同步、协作编辑、云存储。
- 不做完整插件运行时（沙箱、权限、市场）；本版只做进程内 Provider 接口与文档。
- 不做跨文件事务、不做目录级 Diff 引擎重写；目录对比仅在文件树中标记差异状态。
- 不改写 v0.3.3 建立的数据安全链路（revision 事务、三方冲突、恢复库 v2）。

## 3. 数据模型

### 3.1 主题包 `ThemePackage`

```ts
interface ThemePackage {
  id: string;            // 小写字母/数字/连字符，3-64 字符
  name: string;          // 展示名，1-64 字符
  version: string;       // 语义化版本字符串
  mode: 'light' | 'dark';
  colors: Partial<Record<CustomThemeColorKey, string>>; // #rrggbb
  monaco?: {
    base: 'vs' | 'vs-dark' | 'hc-black';
    rules?: Array<{ token: string; foreground?: string; fontStyle?: string }>;
    colors?: Record<string, string>;
  };
}
```

约束：

- `colors` 至少包含 `bgApp` 与 `textPrimary`，否则视为不可用主题。
- 颜色统一归一化为小写 `#rrggbb`；非法值丢弃而不是整包拒绝（`bgApp`/`textPrimary` 非法则整包拒绝）。
- 导入体积上限 256 KB，`id` 与内置皮肤冲突时以 `user:` 前缀区分。

### 3.2 快捷键覆盖 `KeybindingOverrides`

```ts
interface KeybindingOverride {
  commandId: string;              // 与 AppCommand.id 一致
  keys: string;                   // 归一化后的 'ctrl+shift+p' 形式，空串表示解绑
}
type KeybindingOverrides = Record<string, KeybindingOverride['keys']>;
```

约束：

- 归一化顺序固定为 `ctrl → alt → shift → meta → key`，字母小写，`cmd`/`command` 归一化为 `meta`。
- 冲突判定：同一平台语义（`ctrl` 与 `meta` 视为同一修饰）下解析结果相同即为冲突。
- 冲突时保存被拒绝，返回冲突的命令 id 列表；用户可选择覆盖（自动解绑旧命令）或取消。

### 3.3 窗口迁移负载 `WindowTransferPayload`

```ts
interface WindowTransferPayload {
  tabs: Array<{
    filePath: string | null;
    fileName: string;
    content: string;
    isDirty: boolean;
    isUntitled: boolean;
    language: string | null;
    cursor?: { line: number; column: number };
  }>;
  activeIndex: number;
  sourceWorkspacePath: string | null;
}
```

约束：

- 单窗口迁移上限：8 个标签、总内容 8 MB；超限返回 `WINDOW_TRANSFER_TOO_LARGE`。
- payload 在 Rust 侧按 `windowLabel` 存储，取出即删除（一次性），10 分钟后过期清理。
- 新窗口消费 payload 后不再走「恢复上次会话」路径，避免两份状态互相覆盖。

### 3.4 Diff 会话 `DiffSession`

```ts
interface DiffSession {
  id: string;
  left: DiffSide;   // { label, filePath?, content }
  right: DiffSide;
  layout: 'side-by-side' | 'inline';
  readOnly: boolean;
  language: string;
}
```

约束：

- 单侧内容上限 2 MB，超出拒绝并提示；二进制/无权限/缺失文件给出明确错误码。
- Diff 会话只读，不允许在 Diff 视图中写回（避免绕过 revision 事务）。

### 3.5 Provider 接口

```ts
interface ThemeProvider { id: string; load(): ThemePackage[] | Promise<ThemePackage[]> }
interface CommandProvider { id: string; commands(): AppCommand[] }
interface FileActionProvider { id: string; actions(): FileAction[] }
```

约束：

- 注册表按 `id` 去重，重复注册覆盖并记录告警。
- provider 抛错被隔离，记录到 `providerRegistry.errors` 并在设置面板可见，不影响启动。

## 4. 关键流程

### 4.1 主题导入 / 导出

1. 用户在设置面板点击「导入主题」，走 Tauri 原生文件对话框选择 `.json`。
2. 读取 → JSON 解析 → 结构校验与归一化 → 生成 `ThemePackage` → 写入设置并立即应用。
3. 应用时把 `colors` 写入 CSS 变量，把 `monaco` 通过 `monaco.editor.defineTheme` 注册为 `tau-<id>` 并切换。
4. 导出：把当前生效主题包序列化为格式化 JSON，走原生保存对话框落盘。
5. 失败路径：解析失败 / 校验失败 / 超限 → 通知错误，保持当前主题不变。

### 4.2 快捷键自定义

1. 设置面板列出全部命令与当前绑定（默认绑定 + 用户覆盖）。
2. 用户录制按键 → 归一化 → 冲突检测 → 保存覆盖或提示冲突。
3. `keyboardStore` 每次启动按「默认绑定 + 覆盖」重建注册表，命令 id 为唯一键。
4. 命令面板与设置面板展示生效绑定；重置单条/全部恢复到默认。

### 4.3 文件对比

1. 入口：命令面板「比较当前文件与…」、文件树右键「与当前文件对比」、Git 变更项「查看差异」。
2. `diffService` 读取两侧内容并做大小/类型守卫，构建 `DiffSession`。
3. `DiffView` 使用 Monaco `createDiffEditor` 渲染，切换布局只重建 diff 编辑器，不重读文件。
4. 关闭 Diff 回到编辑器标签，Diff 不进入标签列表。

### 4.4 标签迁移到新窗口

1. 源窗口组装 payload → 调用 `open_editor_window`（Rust 创建带唯一 label 的窗口并暂存 payload）。
2. 新窗口启动：若是非 main 窗口且能取到 payload，则以 payload 初始化标签；否则退回常规会话恢复。
3. 源窗口按策略移除已迁移标签（「移动」移除、「在新窗口打开」保留）。
4. 浏览器（非 Tauri）环境：命令不可用并提示「仅桌面端支持」。

### 4.5 Provider 装配

1. 应用启动早期创建注册表，注册内置 provider（内置主题包、默认命令、文件动作）。
2. 主题 provider 的产物进入设置面板「可用主题」列表。
3. 命令 provider 的产物与内置命令合并，冲突以内置优先。

### 4.6 Monaco 按需加载

1. 编辑器初始化只 import 核心 + 基础语言 contribution；其余语言在标签首次使用该语言时动态 import。
2. `mermaid`、`marked`、`dompurify` 等渲染依赖只在 Markdown 预览真正打开时加载。
3. 构建分包：monaco 核心 / monaco 语言 / markdown 渲染 / vue vendor / tauri。

## 5. 错误与边界条件

| 场景 | 错误码/提示 | 处理 |
|---|---|---|
| 主题 JSON 解析失败 | `THEME_PARSE_FAILED` | 保持当前主题，提示文件不是合法 JSON |
| 主题结构不合法 | `THEME_INVALID` | 提示缺失必需字段，不落盘 |
| 主题文件超限 | `THEME_TOO_LARGE` | 提示上限 256 KB |
| 快捷键冲突 | `KEYBINDING_CONFLICT` | 返回冲突命令，用户选择覆盖或取消 |
| 快捷键不可用（仅修饰键） | 提示「需要包含主键」 | 拒绝保存 |
| Diff 内容超限 | `DIFF_TOO_LARGE` | 提示上限 2 MB |
| Diff 文件读取失败 | `DIFF_READ_FAILED` | 展示失败原因，允许重试 |
| 窗口迁移超限 | `WINDOW_TRANSFER_TOO_LARGE` | 提示拆分迁移 |
| 非桌面端迁移 | `WINDOW_UNSUPPORTED` | 提示仅桌面端支持 |
| Provider 抛错 | `PROVIDER_FAILED` | 隔离并在设置面板展示 |

## 6. 迁移与回滚

- 设置持久化沿用现有 `localStorage` 键 `text-editor-settings`，新增字段全部可选，旧数据读取时补齐默认值。
- 主题包与快捷键覆盖均为增量字段，回退到 v0.3.3 不会破坏既有设置（多余字段被忽略）。
- 新窗口 payload 为内存态，进程退出即失效，无磁盘迁移。
- 出现阻断问题时回滚到 `v0.3.3`，修复以 `v0.4.1` 发布，不覆盖既有 tag。

## 7. 验收标准

1. 主题：内置 5 套皮肤仍可用；导入自定义主题包后 UI 与 Monaco 同步；导出后可再次导入（round-trip）；非法文件不改变当前主题。
2. 快捷键：可为任一命令改键并立即生效；冲突被检测并给出明确选择；重置单条/全部可用；刷新后保持。
3. Diff：三种入口都能打开 Diff；并排/内联切换不丢内容；超大文件与读取失败有明确提示；Diff 视图只读。
4. 多窗口：桌面端可把标签移到新窗口且内容（含未保存修改）一致；源窗口策略正确；浏览器端给出「仅桌面端支持」。
5. Provider：内置 provider 装配成功；重复注册与抛错被隔离且可见。
6. 性能：入口 chunk 体积下降（记录前后对比）；Markdown 渲染依赖不在首屏加载。
7. 质量门槛：`pnpm typecheck`、`pnpm test:unit`、`pnpm build`、`RUSTFLAGS=-D warnings cargo check --all-targets`、`cargo test --all-targets`、`playwright test --project=chromium` 全绿，CI 四道门禁通过。
8. 发布：`v0.4.0` tag 触发三平台构建，GitHub Release 附带 DMG / MSI / EXE / deb / RPM / AppImage。
