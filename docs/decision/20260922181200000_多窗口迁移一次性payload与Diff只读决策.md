# 决策记录：多窗口迁移一次性 payload 与 Diff 只读模型

> 决策时间：2026-09-22 18:12
> 版本：v0.4.0
> 关联规格：`docs/spec/20260922174528781_Tau_Editor_v0.4.0_体验增强版规格.md`

## 1. 背景

v0.4.0 需要支持「把标签迁移到新窗口」与「文件对比」两类新交互。两者都涉及跨窗口/跨视图的状态传递，若不约束边界，容易破坏 v0.3.3 建立的 revision 事务与三方冲突策略。

## 2. 决策

### 2.1 多窗口迁移：Rust 侧按 window label 暂存，一次性消费

- payload 由前端组装，Rust 侧 `validate_window_transfer` 二次校验（空/超量/超大/activeIndex 越界）。
- payload 在窗口创建前写入注册表，与目标窗口 label 绑定；新窗口启动时 `consume_window_transfer` 取出即删。
- 10 分钟未被消费自动过期，避免异常退出导致的常驻内存。
- 新窗口消费 payload 后不再走会话恢复，避免两份状态互相覆盖。

**理由**：不落盘、不跨进程、不引入外部协议，迁移失败天然回退到「源窗口标签不变」。

### 2.2 Diff 视图：只读，不写回

- `DiffSession.readOnly` 恒为 `true`，Diff 编辑器禁用 `originalEditable`。
- 单侧内容上限 2 MB，二进制内容直接拒绝。
- Git 变更对比以 `HEAD:path` 为左侧基准，右侧取工作区内容（优先内存中未保存内容）。

**理由**：写回必须经过 revision 事务与三方冲突链路，Diff 视图只做展示可避免绕过安全边界。

## 3. 影响

- 多窗口迁移上限：单次 8 个标签 / 8 MB；超限返回 `WINDOW_TRANSFER_TOO_LARGE`，前端提示拆分迁移。
- 非桌面端（浏览器/E2E）调用迁移命令返回 `WINDOW_UNSUPPORTED`，提示仅桌面端支持。
- Diff 不进入标签列表，关闭即回到编辑器视图，不产生额外会话状态。

## 4. 回滚

- 关闭窗口迁移入口（命令面板移除对应命令）即可回退，Rust 侧注册表为内存态，重启即清空。
- Diff 为独立 store 与组件，回退只需移除入口，不影响既有编辑器链路。
