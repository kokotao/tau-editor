## 真实语言服务器边界

本机当前探测结果：

- 可用：`clangd`（Apple clangd 21.0.0）。
- 不可用：`typescript-language-server`、`pyright-langserver`、`gopls`、`jdtls`、`omnisharp`；`rust-analyzer` 命令当前解析到 rustup，但对应官方 toolchain 没有可执行组件，因此也需先修复/安装。

因此，本轮已验证协议层、Provider 层、UI 导航层和自动化测试；TypeScript、Python、Go、Java、C# 的真实端到端效果需要安装相应语言服务器后在 DMG 中验收，不能用单测替代真实 E2E。


## 实地验收步骤

1. 打开 DMG 并将 `Tau Editor.app` 拖入 Applications。
2. 安装要验收语言对应的服务器，例如 TypeScript：`npm i -g typescript typescript-language-server`；Python：`pipx install pyright`；Go：`go install golang.org/x/tools/gopls@latest`。
3. 在 Tau Editor 打开一个真实项目，确认 LSP Settings 能探测到服务器。
4. 在符号上验证悬浮、定义跳转、查找引用、重命名和诊断；再验证 `Ctrl/Cmd+Alt+H` 调用层级、`Ctrl/Cmd+Alt+T` 类型层级以及 Workspace Symbols。

## 风险

- 不同语言服务器对调用层级、类型层级、语义 token 和代码操作的支持程度不同；服务端不支持时 UI 会显示无结果或回退提示。
- 大型项目的索引速度和引用完整性由语言服务器决定，Tau Editor 侧已提供会话复用、文档同步和工作区变更通知。
- 当前工作区仍有前序用户改动，未执行 reset、checkout 或删除无关文件。
