## 1. 结论

W1-W7 全部落地：主题包、快捷键自定义、Diff 视图、多窗口迁移、Provider 扩展点、启动性能分包六项能力均已完成，本地六道门禁全绿，进入 GitHub Release 发布阶段。

## 2. 交付内容

### W1 主题包（导入 / 导出 / 切换）

- 新增 `frontend/src/utils/themePackage.ts`：主题包模型、颜色归一化、Monaco theme 定义、JSON 体积与结构校验（256 KB 上限、`bgApp`/`textPrimary` 必需）。
- `frontend/src/stores/settings.ts`：新增 `themePackages` / `activeThemePackageId` 持久化字段与 `importThemePackage` / `exportThemePackage` / `removeThemePackage` / `applyThemePackage`。
- `frontend/src/components/editor/SettingsPanel.vue`：主题包列表、从文件导入（Tauri 对话框 / 浏览器文件选择）、粘贴导入、导出、删除、回退内置主题。
- `frontend/src/components/editor/EditorCore.vue`：`defineTheme` 注册当前主题包并在切换时热更新，注册失败回退内置主题。

### W2 快捷键自定义

- 新增 `frontend/src/services/keybindingService.ts`：归一化（固定 `ctrl→alt→shift→meta→key` 顺序）、事件解析、冲突检测（ctrl / meta 同语义）、格式化、覆盖表归一化。
- `frontend/src/stores/settings.ts`：`keybindingOverrides` 持久化 + 单条重置 / 全部重置。
- `frontend/src/App.vue`：快捷键注册改为「默认绑定 + 用户覆盖」解析，覆盖变化时重建注册表并刷新命令面板。
- `frontend/src/components/editor/SettingsPanel.vue`：快捷键录制、冲突覆盖确认、单条/全部重置；F1 固定保留为命令面板入口。

### W3 文件对比（Diff）

- 新增 `frontend/src/services/diffService.ts`：会话构造、2 MB 单侧上限、二进制守卫、语言推断、工作区对比与 Git HEAD 对比。
- 新增 `frontend/src/stores/diff.ts` 与 `frontend/src/components/editor/DiffView.vue`：只读 Monaco Diff，并排 / 内联切换。
- 入口：命令面板「比较当前文件与…」、文件树右键「与当前文件对比」、上下文栏 Git 变更项。
- 新增 Rust 命令 `git_show_file`（`frontend/src-tauri/src/commands/git.rs`）用于读取 HEAD 基准内容。

### W4 多窗口标签迁移

- 新增 `frontend/src-tauri/src/commands/window.rs`：`open_editor_window` / `consume_window_transfer`，payload 与窗口 label 绑定、取出即删、10 分钟过期、8 标签 / 8 MB 上限，含 3 个单测。
- 新增 `frontend/src/services/windowTransferService.ts`：前端同规则校验、payload 组装/还原、一次性消费。
- `frontend/src/App.vue`：新窗口启动优先消费迁移 payload，不走会话恢复；新增「在新窗口打开」「移动到新窗口」命令。
- `frontend/src-tauri/capabilities/default.json`：窗口能力扩展到 `editor-*`。

### W5 Provider 扩展点

- 新增 `frontend/src/services/providerRegistry.ts`：主题 / 命令 / 文件动作三类注册表，重复注册覆盖并告警，provider 抛错隔离到 `errors`。
- 新增 `frontend/src/services/providers/builtinProviders.ts` 与 `frontend/src/stores/providers.ts`。
- 设置面板展示 Provider 数量与错误；文件树右键接入 Provider 文件动作（复制路径、在文件管理器中显示）。

### W6 启动性能与分包

- `frontend/src/components/editor/LazyEditorCore.ts`：修正懒加载路径并保留组件名，`App.vue` 改用异步组件，Monaco 移出首屏依赖。
- 新增 `frontend/src/services/markdownRenderService.ts`：marked / DOMPurify / mermaid 迁出 `markdownService`，仅在预览或导出时动态加载。
- `frontend/vite.config.ts`：新增 `markdown-renderer` / `mermaid` / `ui-vendor` 分包。

## 4. 风险与回滚

| 风险 | 处置 |
|---|---|
| 自定义主题注册异常导致编辑器配色异常 | `defineTheme` try/catch 回退内置主题；导出/导入可 round-trip |
| 改键导致命令不可用 | 冲突检测 + 覆盖确认 + 单条/全部重置；F1 固定保留 |
| Diff 大文件卡顿 | 单侧 2 MB 上限 + 二进制拦截 + 只读视图 |
| 多窗口 payload 泄漏或串窗口 | 与 label 绑定、取出即删、10 分钟过期、容量上限；超限返回错误码 |
| 分包导致 Monaco 语言能力缺失 | 保留原有 `setupMonaco` 全量语言注册，仅改变加载时机 |
| 整体阻断 | 回滚到 `v0.3.3`，修复以 `v0.4.1` 发布，不覆盖既有 tag |

## 5. 遗留事项

1. Diff 视图当前以「文件 vs 文件」为主，未提供目录级对比。
2. Provider 体系为进程内注册表，尚未实现沙箱与插件市场。
3. 多窗口迁移暂不支持跨工作区标签批量迁移（单窗口上限 8 标签）。
