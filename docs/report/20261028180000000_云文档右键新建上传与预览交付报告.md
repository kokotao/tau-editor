## 二、需求 → 实现映射（含关键决策）

### R1 分类右键「新建文件」

- 菜单：目录节点右键「新建文件」，位置在「上传文件…」之前；`cat:<id>`、`group:uncategorized` 可用，`custom:<名称>` 聚合分组禁用（该类节点来自文档的分类自由文本，没有分类主键，写入 `categoryId` 会污染数据）。
- 卡片：复用既有内联卡片，新增 `mode: 'create-file'`，标题「新建文件 · <分类名>」，默认占位 `接口设计.md`。
- 创建：文件名净化（禁 `\ / : * ? " < > |`、`..`、空名，无扩展名自动补 `.md`，上限 120）→ `tau/<工作区名>/<文件名>`（无工作区退回分类名 → `未分类`）→ `findCloudDocByPath` 预检重名 → `saveCloudDoc({ content: '', baseVersion: null, categoryId, category })`。
- 打开：成功后只发 `emit('changed')` + `emit('edit-cloud-doc', 合成节点)`，由 `App.vue#handleCloudDocEditOpen` → `materializeCloudDocForEdit` 落位到临时工作区并绑定云端身份。**树内不写本地盘**，避免出现两份不同步的副本。
- 数据一致性：雪花 `categoryId` 全程按字符串透传（`cloudCategoryService` 既有约定），不经过 JS number。

### R2 分类右键「批量上传」

- 菜单：目录节点右键「上传文件…」→ 系统多选对话框（不限扩展名，不支持的类型在弹窗里逐条给原因，而不是被对话框藏起来）。
- 计划：`planBatchUpload` 纯函数把文件分成 `text | binary | skipped`（含原因）；`collectBatchUploadPlan` 用 `fileCommands.getFileInfo` 补大小（单文件信息读取失败不阻断队列）。
- 执行：串行 1 路，文本走 `syncDocumentByPath({ filePath, cloudPath, category, categoryId })`，二进制走 `uploadBinaryDocument({ cloudPath, localPath, title, category })`。
  - `conflict`（云端已存在且内容不同）= 默认**不覆盖**，行状态记「已跳过 · 云端已存在同名文档，未覆盖」；
  - `quota` / `unauthorized` / 用户点「中止上传」→ 队列中止，弹窗保留逐条结果；
  - 上限 100 个文件（超出先提示再截断）。
- 目标分类：`cat:<id>` → categoryId + category；`group:uncategorized` → 两者都 null（避免云端造出假的「未分类」分组）；`custom:<名称>` → 仅自由文本 category。

### R3 文件夹右键「上传该文件夹到云端」

- 入口：工作区文件树**文件夹行**右键；未登录 → 引导登录（`openCloudSyncSettings`），无工作区 → 提示不弹窗。
- 收集（`collectFolderFiles`）：`fileCommands.listFiles` 递归；深度 ≤ 8、文件 ≤ 500（截断并提示）、文本 ≤ 12MB、二进制 ≤ 50MB；跳过 11 类构建/依赖目录（node_modules/.git/dist/build/target/.idea/.vscode/__pycache__/.next/coverage/out/.turbo）与全部 `.` 开头隐藏项；图片不传（图片在云文档模型里是文档附件）；宏格式与未知扩展名进跳过清单并给原因。
- 分类（D7）：`createCategory(文件夹名)` 成功即用 → 失败/重名则 `fetchManagedCategories` 复用同名 → 再失败退化为自由文本 category。
- 执行：同 R2 的串行队列；结束页按 `ok / failed / skipped` 汇总，`emit('uploaded')` → `App.vue` 令 `cloudTreeRefreshToken += 1`，云文档侧栏立即重拉出新分类与文件。

### R4 我的云文档在线预览

- 入口：`/blog/public/me?tab=docs` → 「我的云文档」列表操作列新增「预览」（操作列 300 → 400px），行双击同样触发（点在按钮上不触发）。
- 弹窗 `CloudDocPreviewDialog.vue`：`min(960px, 92vw)`、`append-to-body`、`destroy-on-close`，六类分支：
  - markdown → `GET /blog/pages/cloud/{docId}` 取正文 → `renderMarkdownResult`（markdown-it `html:false`，XSS 面与分享页一致）；
  - code → `renderCodeBlock`（highlight.js + 行号）；text → `renderPlainTextBlock`；
  - pdf / office → `GET /miniProgram/cloud/docs/{fileId}/preview.pdf`（blob）→ objectURL → 复用分享页 `PdfPreview.vue`（PDF.js 逐页渲染，不落盘、无下载入口）；
  - image → `GET /miniProgram/cloud/docs/{fileId}/download`（blob）→ objectURL → `<img>`；
  - other → 文件卡片降级。
- 状态与错误：loading 骨架 / error + 重试 / 空正文三态；401→登录失效、403→无权限、422→「该文件暂时无法预览（可能仍在转换中）」；请求带序号（`loadSeq`）丢弃过期回包；objectURL 在切换/关闭/卸载三条路径统一 `revokeObjectURL`。
- 关键契约细节（评审记录）：后端统一异常处理是 **HTTP 200 + body `{code, message}`**，而下载走 `responseType=blob`，axios 既不抛错也不解包。实现里用 `assertNotJsonBlob` 识别「JSON 内容的 Blob」并还原成 `HttpError(message, code)`，否则 422 会被 PDF.js 报成「格式异常」。
- 已知限制：markdown 内的相对图片没有 owner 侧附件通道，显示「图片未同步」占位；office 依赖后端转换，前端只能重试。

## 五、已知限制与后续建议

1. **R1 入口只在分类右键**：云文档库为空（没有任何分类）时没有入口。后续可在云文档浏览弹窗工具栏加「新建文件」（需要一个"未分类/默认分类"概念）。
2. **批量上传一次共用同一目标分类**：不按本地目录在云端重建层级（云端没有目录实体）；不同目录的同名文件靠相对路径区分，同一目录同名会被判 conflict 不覆盖。
3. **默认不覆盖**：R2/R3 遇到「云端已有且内容不同」都记「未覆盖」，没有「全部覆盖」批量开关（符合风险表；如需要应做成逐条确认）。
4. **二进制文档的分类只有自由文本**：后端 `binary upload` 请求体没有 `categoryId`，若分类创建与同名查询都失败，二进制文件只能靠名字匹配归位。
5. **R4 markdown 相对图片不取图**：owner 侧附件需要新增鉴权接口；当前占位提示。
6. **R4 操作列宽度 400px 为推算值**，未在真实浏览器实测；如换行只需微调这一个数字。
7. **未做 Tauri 实机端到端验证**（本环境无法启动桌面端）：建议在桌面端各做一次验收——分类右键新建并保存、批量上传含图片/超限文件的混合列表、含 `node_modules` 的目录上传（应 0 文件被推上去）、个人中心预览 pdf/office/md。
8. **e2e 未覆盖**：目前用 vitest 单测 + 类型检查覆盖；建议后续补 `tests/e2e/specs/cloud-doc-menu.spec.ts`（右键菜单结构 + 弹窗开合），需要稳定的 mock 云服务夹具。

## 七、复现与验收步骤

1. 依赖与测试：
   ```
   cd tau-editor && npx vitest run
   cd tau-editor/frontend && npx vue-tsc --build
   cd lizi-project/lizi-learning-admin-pro && npx vue-tsc --noEmit
   ```
2. 桌面端（需登录 lizi 账号）：
   - 左侧栏切到「云端文档」→ 右键任一分类 →「新建文件」→ 输入 `验收-新建.md` → 应新建、树内出现、编辑器打开且能保存回云端；
   - 同一分类右键 →「上传文件…」→ 选 1 个 md + 1 个 pdf + 1 张图片 → 弹窗应显示 2 成功/1 跳过（图片不支持）+ 汇总 toast；
   - 工作区文件树 → 右键一个含 `node_modules` 的目录 →「上传该文件夹到云端」→ 确认页显示将上传数量与跳过清单 → 上传完成后云文档侧栏出现同名分类；
   - 浏览器打开 `/blog/public/me?tab=docs` → 对 md / pdf / 图片各点一次「预览」→ 弹窗渲染正确，关闭后无内存泄漏警告。
