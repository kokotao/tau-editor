## 结果

已完成 Command Palette、设置工作区、工作区搜索、替换预览、外部变更对话框和通知组件的平角与字体统一，并新增可重复执行的编辑器视觉基线采集脚本。

## 主要改动

### Command Palette

- 面板、搜索框、菜单项和快捷键标签统一为平角。
- 移除面板径向渐变，改为稳定的面板底色。
- 搜索框聚焦改为底部强调线，移除大范围圆角光晕。
- 活动项增加左侧蓝色定位线，标题提升至更清晰的 13px 字号。

### 设置工作区

- 设置主面板移除装饰性径向渐变。
- 导航、字段卡片、主题按钮、字号控件、快捷键行、更新卡片和作者二维码区域统一为平角。
- 设置标题、导航项和控件焦点态统一字号与轮廓。
- 保留轻量 hover 动效，但取消对核心尺寸的影响。

### 搜索与对话框

- 工作区搜索、替换预览、外部变更对话框统一为平角面板。
- 输入框、结果项、状态标签和操作按钮统一平角。
- 压缩单行 CSS 为可维护的多行样式。
- 对话框增加统一边界与阴影层次。

### 通知

- 通知卡片、操作按钮和关闭按钮统一为平角。
- 标题提升为 13px / 700，正文使用 12px。
- 阴影改为背景层次更明确的深色投影。

### 视觉基线

- 新增 `scripts/capture-editor-style-baseline.mjs`。
- 新增根命令 `npm run test:visual:baseline`。
- 固定暗色偏好并等待设置面板动画完成，减少截图波动。
