## 二、实现细节

### 2.1 分享页渲染管线（admin-pro）

**`src/utils/share-render.ts`**
- `::: details [标题]` 容器规则（`md.block.ruler.before('fence', 'details', …)`）：
  - 输出 `<details class="md-details"><summary>标题</summary><div class="md-details__body">…</div></details>`；
  - 内部用 `state.md.block.tokenize` 走正常 markdown 解析（列表/代码块/表格/标题均可）；
  - 结束标记扫描跳过围栏内部、支持同名嵌套计数、缩进回退即视为未闭合；
  - 标题只做 `escapeHtml` 纯文本，**不解析 inline markdown**，公开页零注入面；
  - 未闭合 → 返回 false 交回段落规则，后续内容（含标题）不被吞。
- mermaid 代码块单独走 highlight 分支：`<pre class="hljs md-mermaid-source"><code class="language-mermaid">…</code></pre>`（原有 highlight 不输出语言类，后渲染选择器命中不了）。
- 既有安全设置零改动：`html:false`、外链 `target=_blank rel="noopener noreferrer nofollow"`、图片白名单、危险协议拦截。
- 折叠块内标题**不生成锚点、不进 TOC**（见 §四 设计判断）。

**`src/utils/markdown-diagram.ts`**
- `ensureMermaidInitialized` 改为「合并配置 JSON 变化才重新 initialize」→ 同一 SPA 内分享页 `strict` 与博客详情 `loose` 可共存，互不污染；
- 坏语法三重兜底：`try/catch` + 临时 `parseError` 钩子 + 渲染后校验 `<svg>`（排除 mermaid 自带 Syntax-error 占位图）→ 恢复原代码块、打 `data-mermaid-error="1"`、计入 `{rendered, failed, total}`；
- 参数签名不变，仓内 3 处既有调用点（博客新旧详情、MarkdownViewer）无需改动。

**`src/views/lizi/blog/public/share/index.vue`**
- `watch(markdownHtml, …, { flush: 'post' })` + `nextTick` → `renderMarkdownDiagramsFromNode(contentRef, { mermaidConfig: { securityLevel: 'strict', theme: 'default' } })`；序号丢弃过期回调；
- 渲染后 `remeasureTocPositions()` 重测 TOC 锚点（图替换会改变正文高度）；
- CSS：`.md-details`（边框/圆角/自绘三角/`[open]` 间距/首尾 margin 折叠）、`.mermaid`（居中、`max-width:100%`、横向滚动）、`pre[data-mermaid-error]` 失败态、表格窄屏滚动 + 表头/斑马纹、`pre.hljs` 底色。

**`src/views/system/cloudDoc/components/CloudDocPreviewDialog.vue`**
- markdown 分支同样 `ref` + `watch(markdownHtml)` → strict mermaid 渲染；关闭/卸载时 `diagramRenderSeq += 1` 作废过期回调；
- scoped 同套 details/表格/mermaid/失败态样式（用 `--el-*` 变量与弹窗风格一致）。

### 2.2 Tau 目录联动（tau-editor）

**新增 `frontend/src/services/scrollSpyService.ts`（103 行纯函数）**
- `pickActiveOutlineIndex(items, activeLine)`：最后一个 `line <= activeLine`，空 → -1，全大于 → 最小行号项，乱序先稳定排序仍回填原数组下标；
- `pickActiveSourceLine(headings, scrollTop, offsetPx)`：取 `top - offset <= scrollTop` 的最后一个标题行，无命中 → 首个标题，空 → 0。

**`EditorCore.vue`**：`scroll-change` 负载增量 `topLine`（`getVisibleRanges()[0]?.startLineNumber ?? 1`），既有三字段语义不变。

**`MarkdownPreview.vue`**：渲染后 + `ResizeObserver` 重测 `h1..h6[data-source-line]` 锚点（面板不可见时清空不测量）；滚动时 rAF 节流 → `emit('active-line')`；比例同步 `scroll-sync` 逻辑一行未改；程序化滚动有回声判定，不抢高亮。

**`App.vue`**：唯一状态 `activeOutlineLine`（编辑器 `topLine` / 预览 `active-line` / 点击目录 三路写入）；预览驱动 200ms 窗口、点击后 400ms 导航锁避免互相抢；切换标签归 0、内容变化越界才归 1（避免打字时闪回顶部）。

**`ContextRail.vue`**：`activeIndex = pickActiveOutlineIndex(outline, activeLine)`；`.context-outline-item--active`（accent 竖条 + 主色文字，深浅主题取 token）+ `aria-current="true"`；`watch(activeIndex)` → `scrollIntoView({ block: 'nearest' })`，用户手动滚动/悬停后 3s 抑制，面板不可见或环境缺 API 时静默跳过。

## 三、复现与验收步骤

1. **分享页**（需在浏览器打开任一分享链接 `/s/{token}`）：
   - 文档含 ```` ```mermaid flowchart TD A-->B ``` ```` → 应渲染成 SVG 流程图；
   - 故意写坏语法（`graph TD` 后接 `A[` ）→ 应保留代码块 + 虚线告警「图形语法无法渲染」，页面不报错；
   - 表格 → 正常渲染且窄屏可横向滚动；
   - `::: details 点击展开` 块内放列表/代码/表格 → 默认收起，展开后 markdown 正常；
   - 目录（TOC）在流程图渲染后点击/滚动定位仍准确。
2. **个人中心预览弹窗**：`/blog/public/me?tab=docs` → 某 md 文档「预览」→ 折叠块与流程图同样生效。
3. **Tau 编辑器目录**：
   - 打开含多级标题的 md → 滚动编辑器：右栏「文档大纲」当前标题高亮并自动跟随；
   - 打开 Markdown 预览并滚动预览：高亮跟着预览走；
   - 点击大纲项：跳到对应行且立即高亮；
   - 手动滚动大纲列表后 3 秒内不被自动滚回；
   - 打开任意代码文件：大纲（类/函数）同样跟随当前视口高亮。
4. 命令复核：
   ```
   cd tau-editor && npx vitest run
   cd tau-editor/frontend && npx vue-tsc --build
   cd lizi-project/lizi-learning-admin-pro && node node_modules/vue-tsc/bin/vue-tsc.js --noEmit
   ```

## 四、设计判断（已确认）

1. **折叠块内标题不进 TOC/锚点**：闭合的 `<details>` 内元素在布局上不可见（`getBoundingClientRect().top === 0`），会让现有 scroll spy 假定 top 递增的高亮算法整体偏移，且目录点击会跳到不可见位置。标题本身照常渲染。若将来需要支持，需额外做「展开后重测」。
2. **`renderMarkdownDiagramsFromNode` 返回值由 `number` 改为 `{ rendered, failed, total }`**：参数签名不变，仓内 3 处调用均忽略返回值；用于把坏图计入统计。
3. **代码块底色统一 `#f6f8fa`**：highlight.js 的 github 主题给纯白底，白卡片上块边界不可见；与表头/斑马纹统一灰阶。

## 五、已知限制

1. 折叠块内若放**流程图**（未展开时）mermaid 无法测量隐藏元素，展开前可能渲染异常；建议避免在默认收起的块内放图，或后续做「展开时重渲染」。
2. 折叠块结束标记用 `:::` 配对 + 围栏跳过，极少见写法（围栏内再嵌裸 `:::`）可能提前收尾；未闭合统一降级为普通段落。
3. mermaid `securityLevel: 'strict'` 下 label 内 HTML 会被转义为文本（预期行为，公开页安全优先）。
4. mermaid 坏语法降级路径为「读 mermaid@8 源码 + 静态推演 + 类型检查」验证，**建议浏览器手测一条坏语法**（本环境无 jsdom 无法跑真实 DOM）。
5. 预览未打开/`display:none` 时不做标题测量；关闭预览后高亮需等编辑器下一次滚动事件重新点亮（不残留旧文档行号，但可能短暂空高亮）。
6. 分享页与弹窗均未做「目录折叠块内标题」的锚点，与 §四.1 一致。
