# 资源区与编辑器体验修复报告

## 结果

完成资源区空提示、Markdown 右键二级菜单、图片文件预览和代码导航体验修复。

## 改动

### 资源区

- 移除空文件树中的“当前工作区暂无文件”和创建提示文案。
- 资源区为空时保持简洁空白状态，仍保留右键创建和刷新能力。

### Markdown 右键菜单

- Markdown 格式、插入、工具改为分类二级菜单。
- 二级菜单独立 Teleport 到 `body`，不再受主菜单 `overflow-y`、`backdrop-filter` 或父级裁剪影响。
- 保留视口边界计算、左右自动避让和鼠标移动延迟关闭。

### 图片文件

- 新增 `ImagePreview`，图片文件直接通过 Tauri asset URL 渲染。
- 支持 png、jpg、jpeg、gif、webp、svg、bmp、ico、avif、tif、tiff。
- 图片打开时不再读取二进制内容到 Monaco，不展示十六进制源码。
- 图片标签按只读预览处理，禁止直接保存或覆盖原始图片。

### 代码导航

- Monaco 增加轻量 Definition Provider 和 Hover Provider。
- 支持常见类、接口、类型、函数、方法声明识别。
- 支持当前文件及其他已打开文件之间的符号跳转。
- 悬浮信息显示符号类型、签名和已打开模型中的引用数量。
- 使用模型版本缓存，超过 1MB 的模型跳过轻量索引。

## 验证

- 全量 Vitest：57 个测试文件、845 个测试通过。
- `pnpm --dir frontend type-check`：通过。
- `pnpm --dir frontend build`：通过。
- `git diff --check`：通过。

构建仅保留既有的 Tauri 动态导入提示和大型 chunk 提示，没有新增错误。

## 能力边界

- 当前代码导航是轻量索引，跨文件跳转范围限定为已打开的 Monaco 模型。
- 复杂语言的完整语义分析、项目级索引和未打开文件跳转仍需要接入语言服务器或项目索引服务。
