### 2.1 前端接入细节

- 链接状态：监听 `markdownContext.links` 签名 + 工作区 ID + 标签身份，600ms 去抖后调用 `check_markdown_links`；请求用自增序号丢弃过期结果；无站内链接、大文件、工作区外文件、非 Tauri 环境直接清空状态并跳过调用。
- 工作区任务：进入 Markdown 文档且工作区就绪时惰性扫描一次（同一工作区不重复扫描），手动刷新按钮与 Markdown 保存后重扫；失败走警告通知，不阻塞编辑。
- 任务导航：`relativePath` 拼接工作区根目录打开文件，`nextTick` 后 `revealLine(line)`。
- 图片导入：仅 Markdown 文档、非大文件、必须位于已打开工作区内；`10 MiB` / 扩展名限制由后端兜底校验。
- HTML 导出：默认路径为源文档同目录下的同名 `.html`；写入使用 `fileCommands.writeFile`（Tauri）或 Blob 下载（浏览器）。
