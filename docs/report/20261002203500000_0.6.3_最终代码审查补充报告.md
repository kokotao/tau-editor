# Tau Editor v0.6.3 最终代码审查补充报告

审查日期：2026-10-02

## 审查范围

- 资源管理区空状态渲染。
- Markdown 编辑器右键分类二级菜单。
- 图片文件预览与只读保护。
- 代码文件符号索引、定义跳转和悬浮信息。
- v0.6.3 发布前的测试、构建和打包链路。

## 审查结论

本轮发现并修复了单文件模式下 App 外层仍显示“资源管理器目前为空”的问题；资源区无工作区时现在保持空白，不再显示多余提示。Markdown 右键二级菜单通过 Teleport 渲染到 `body`，并补充鼠标悬浮、`mouseover`、键盘聚焦和点击触发，真实浏览器截图确认二级工具面板可见。

图片预览和代码导航能力沿用 v0.6.2 的实现，本轮未发现新的高优先级问题。图片标签页不再把二进制内容加载为源码，代码导航使用轻量符号索引并提供定义跳转、签名和引用数量悬浮信息。

## 验证证据

- `pnpm exec vitest run`：57 个测试文件、848 个测试通过。
- `pnpm --dir frontend type-check`：通过。
- `pnpm --dir frontend build`：通过；仅保留既有动态导入和大 chunk 警告。
- `git diff --check`：通过。
- Playwright 真实浏览器：资源区空白状态通过；Markdown 二级菜单截图运行态可见。

## 已知限制与风险

- 代码导航是轻量级符号索引，跨文件跳转范围限于已打开的 Monaco 模型，尚未接入完整项目级 LSP。
- 代码索引对复杂宏、动态语言运行时解析和跨依赖包语义不作保证；遇到无法解析的符号时保持编辑器默认行为。
- Apple Silicon DMG 使用 ad-hoc 签名，未配置 Apple notarization；首次打开可能需要用户在 macOS 安全设置中手动放行。

## 回滚建议

如需回滚，使用 `v0.6.2` 标签及其对应 Release；本轮变更不涉及数据库迁移，回滚不会修改已有文档、图片资源和用户设置。
