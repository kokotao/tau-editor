## 1. P4 在线编辑（博客侧，lizi）

| 接口 | 行为 |
|---|---|
| `GET /blog/pages/cloud/{docId}` | owner 返回完整字段（含 content）；非 owner 且 `visibility=PUBLIC` 返回只读掩码（隐藏 path/category/tags/visibility/publishedArticleId）；其余 404（不暴露存在性） |
| `PUT /blog/pages/cloud/{docId}` | owner 专属；`path` 强制沿用云端路径；复用 P0 `CloudDocService.save` → 409 版本冲突原样透传、413 配额、400 参数 |

实现：`BlogCloudDocController` + `BlogCloudDocService/Impl`（Controller 只做鉴权装配；`/blog/pages/**` 在公开路径，鉴权全部在 Controller 内完成）。

## 2. P6 分享公开 / 撤回（博客侧，lizi）

| 接口 | 行为 |
|---|---|
| `GET /blog/pages/my` | 我的云文档（私有+已公开）分页列表，返回 `CloudDocItemVO` 结构，支持 `keyword` 与 `category` 过滤 |
| `POST /blog/pages/cloud/{docId}/publish` | 需 owner + 「Tau 作者」角色（否则 403）；写 `article`：`status=1`、`source=TAU`、`publish_channels=BLOG,MINI`、`authorId/author` 取当前用户、`cloud_doc_id` 回填；同事务回填 `user_document.published_article_id` 与 `visibility=PUBLIC`；已发布过则更新同一篇文章（保留 id/createTime） |
| `POST /blog/pages/cloud/{docId}/withdraw` | owner；`article.status=0` + `visibility=PRIVATE`，保留 `published_article_id` 便于再次发布 |

补充：空内容发布拒绝（400「云文档内容为空，无法发布」）；发布复用 `ArticleService.saveArticle/updateArticle`（保留写 .md、知识图谱抽取、RAG 索引/移除等既有链路）。

## 3. P7 小程序「我的文章」（lizi）

`GET /miniProgram/article/mine`：Controller 内强制登录（401），按 `author_id=当前用户` + `status in (0,1)` 查询，返回 `id/title/category/tags/status/source/publishChannels/createTime`；公开列表接口保持不变（只返回 `status=1`）。

## 4. P3 分类/标签数据源（Tau Rust）

- 新增 `cloud_blog_categories` / `cloud_blog_tags` 两个只读命令：GET `/blog/pages/categories|tags`，**不带 token**（公开接口；避免过期 token 被 JWT filter 判 401）。
- 分类接口存在两种真实形态：多级树（分类表有数据）与分类名字符串数组（降级），Rust 侧统一归一化为 `{id, name, parentId, children}`（雪花 ID 为字符串，根 `parentId="0"` → null，`children:null` → `[]`）。
- 标签统一 trim + 去重 + 字典序（服务端 `HashSet` 无序）。
- 前端封装：`cloudBlogService.fetchCloudCategories()/fetchCloudTags()` → `CloudOutcome`。

## 5. P8 Tau 版本历史与冲突处理（tau）

- 设置页云同步区块新增「版本历史」：`cloudCommands.versions(fileId)` 列表（版本号/时间/大小/备注），每行「恢复」调 `restore(fileId, versionId)`，成功后刷新配额与列表。
- 冲突处理：最近结果 `conflict`（或 fileConflicts 命中当前文件）时显示「用本地覆盖云端 / 用云端覆盖本地」：
  - `forcePushCurrentDocument(tabId?)`：先取云端当前 version 作为 `baseVersion` 强制推送；无云端文档按新建；
  - 用云端覆盖本地复用 `pullCloudDocumentIntoLocal`。
- Web 构建隐藏上述入口；文案全部 i18n（新增 13 个 key）。

## 6. 博客前端（lizi-learning-vue-admin）

- 首页新版分段「全部公开 / 我的文章」：登录态调 `/blog/pages/my`，卡片展示 visibility/version/updatedAt/category/tags，操作：编辑 / 分享公开 / 撤回公开。
- 新增在线编辑页 `/blog/cloud/:docId`：owner 可编辑保存（`baseVersion` 冲突时二选一：拉取最新 / 用本地覆盖），PUBLIC 匿名只读（路由白名单）。
- 新增 `api/blog/cloudDoc.js` 5 个接口封装；业务错误按 `body.code` 判断（409/403/404/401/413）。
