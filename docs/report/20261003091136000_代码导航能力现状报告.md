# 代码导航能力现状报告

核对日期：2026-10-03
核对范围：类、方法等代码符号的鼠标悬浮查看、定义跳转、引用查看与引用跳转。

## 结论

当前已完成轻量版“符号悬浮查看”和“跳转到定义”，尚未实现“查找所有引用、引用列表、逐个跳转引用”。

## 已完成能力

- `frontend/src/lib/monaco/setupMonaco.ts:196-227` 注册 `DefinitionProvider`。
  - 当前文件优先，再扫描其他已打开且未销毁的 Monaco 模型。
  - 返回目标文件 URI 和声明行列范围，因此 Monaco 原生 F12、Ctrl/Cmd+点击等定义跳转动作可使用。
  - 单个模型超过 1MB 时跳过轻量导航。
- `frontend/src/lib/monaco/setupMonaco.ts:230-259` 注册 `HoverProvider`。
  - 悬浮显示符号类型、名称、签名和已打开模型中的粗略 usages 数量。
- `frontend/src/services/codeNavigationService.ts:7-73` 提供轻量符号索引。
  - 支持常见 class/struct/trait、interface、type/enum、function/def/fn、箭头函数和方法声明。

## 尚未完成能力

- 全仓未发现 `ReferenceProvider`、`provideReferences`、`findReferences`、引用列表面板或引用跳转命令。
- `countReferences()` 只是全文正则计数，不返回引用位置，不能点击后逐个跳转。
- 当前自定义右键菜单和快捷键没有“查找所有引用/跳转引用”入口。

## 当前限制与风险

- 符号解析使用逐行正则，不是 AST/LSP 语义解析。
- `findSymbol()` 按名称取首个匹配，同名符号、作用域、重载和复杂语法可能误跳。
- 引用数量会包含声明本身，并可能把注释、字符串和同名变量计入。
- 跨文件范围仅限已打开的 Monaco 模型；未打开文件、项目级依赖和复杂动态语义不保证。
