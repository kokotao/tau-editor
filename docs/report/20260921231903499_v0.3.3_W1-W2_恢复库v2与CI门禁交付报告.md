## 4. 风险与回滚

- 关闭前落盘只在 Tauri 的 `onCloseRequested` 路径生效；进程被强杀时仍可能丢失最后一个防抖窗口（600 ms）内的改动。
- app-data 恢复库首次运行会重写会话与草稿；若 v2 写入失败，v1 旧键会保留，可回退到旧逻辑读取。
- 回滚方式：还原 `sessionService.ts`、`App.vue`、`windowService.ts` 与 `lib.rs` 中的恢复命令注册，恢复库目录 `app-data/recovery-v2` 可整体删除，v1 数据不受影响。
