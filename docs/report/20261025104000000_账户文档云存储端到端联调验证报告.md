## 3. DB 侧证据（冒烟后实际查询）

```
article:
  2114180133521719298  User Doc  status=1  source=TAU  publish_channels=BLOG,MINI  cloud_doc_id=2  author_id=2
  2114180130795421697  hello     status=0  source=TAU  publish_channels=BLOG,MINI  cloud_doc_id=1  author_id=1   (已撤回)

user_document:
  id=1 user=1 path='tau/smoke/hello.md #deleted:1' version=4 visibility=PRIVATE published_article_id=…  is_deleted=1
  id=2 user=2 path='tau/smoke/user-doc.md'         version=1 visibility=PUBLIC  published_article_id=…  is_deleted=0

user_document_version:
  1/v1, 1/v2, 1/v3, 1/v4 (remark='restore from v1')

user_document_sync_log:
  UPLOAD SUCCESS ×4；UPLOAD FAIL ×2（冲突与未授权场景）；RESTORE SUCCESS ×1；DELETE SUCCESS ×1
```

验证点：
- 发布写 `source=TAU`、`publish_channels=BLOG,MINI`、`cloud_doc_id` 正确，`author_id` 为发布者；
- 撤回后 `article.status=0`、`user_document.visibility=PRIVATE` 且 `published_article_id` 保留；
- 软删除后 `path` 改写为 `原路径 #deleted:{id}`（唯一键可重建）、`is_deleted=1`、版本行保留；
- 同步失败日志按动作与状态记录（含冲突与鉴权失败）。
