## 1. P2 Tau 自动同步（§11 P2：自动同步、队列、进度、离线重试）

### 1.1 交付
| 文件 | 说明 |
|---|---|
| `frontend/src/services/cloudSyncQueue.ts`（新增） | 队列核心：串行执行、指数退避（1s/2s/4s/8s/16s，封顶 30s）、最多 5 次后放弃、`localStorage`（`tau-cloud-sync-queue`）断点续传、损坏数据静默丢弃、到期自动 flush、`dispose()` 清定时器 |
| `frontend/src/stores/cloudSync.ts`（扩展） | `autoSyncEnabled` / `syncDebounceMs`（持久化白名单，仍无 token）、队列快照与 `pendingSyncCount` / `failedSyncCount` / `queueSummaryLabel`、`initializeQueue` / `scheduleAutoSync`（防抖）/ `flushQueue` / `retryQueue`；监听 `window online` 自动重试 |

| `frontend/src/App.vue` | 自动保存成功后按标签 `scheduleAutoSync`；启动时 `initializeQueue()` 恢复断点 |
| `tests/unit/services/cloudSyncQueue.test.ts`（新增） | 12 例：退避序列、次数上限、按时间执行、持久化往返、损坏数据、冲突不重试、自动定时 flush、dispose、clear |

### 1.2 设计要点
- 结果处理：`synced`/`skipped`/`conflict` 移出队列（冲突交给用户处理）；`failed` 才退避重试。
- 离线：失败分类为 `network` 时不特殊处理——统一进队列退避；网络恢复事件触发立即 flush。
- 并发 1，同一项执行中不重复入队；队列项按 `tabId:filePath` 去重。
- 自动同步默认关闭，用户手动开启后生效；未登录时 `scheduleAutoSync` 为空操作。

### 2.1 交付
| 文件 | 说明 |
|---|---|

| `lizi-server/.../dto/TauAuthorVO.java`（新增） | 作者列表项 |
| `lizi-server/.../test/.../TauAuthorServiceImplTest.java`（新增） | 17 例：CSV 解析去重、角色缓存、管理员/角色判定、授权追加、幂等、撤销保留其它角色、404/400 |

### 2.2 关键决策
- 管理员判定依据取自 `SysUserServiceImpl.UserRole.ADMIN(1, "管理员")`，不新增假设。
- 角色未初始化（未执行 DDL）时，`hasTauAuthorRole` 返回 false 而不是抛 500，避免发布链路整体报错；`tauAuthorRoleId()` 仍抛 500 提示先执行脚本。
- 角色绑定只改 `sys_user.roles_id` 一列，空集合写空串而非 NULL。
