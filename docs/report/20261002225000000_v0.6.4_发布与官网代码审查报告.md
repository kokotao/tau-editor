# Tau Editor v0.6.4 发布与官网代码审查报告

审查日期：2026-10-02（Asia/Shanghai）

## 审查范围

- GitHub Actions 三平台构建与资产完整性门禁。
- `Array.prototype.at()` CI 兼容性修复。
- 官网 GitHub Releases 动态同步、版本排序、内容转义和失败回退。
- v0.6.4 GitHub Release 与 GitHub Pages 真实运行态。

## 代码审查结论

### 已修复问题

- 路径规范化逻辑改用数组索引访问，兼容 GitHub Actions 使用的 TypeScript DOM lib 目标，消除 TS2550 并恢复 Linux/Windows 构建。
- Release workflow 在构建前校验 tag 与应用版本一致，在各平台构建后校验对应安装包集合，并在上传前再次校验六类资产齐全。
- 官网 Release 数据不再依赖手工维护的单一时间线：首屏使用 fallback，随后分页读取 GitHub API，过滤草稿/预发布版本并按 SemVer 排序。
- GitHub Release 标题、正文和资产名称统一 HTML 转义，避免远程发布文本直接注入页面。
- API 超时、网络错误和返回格式异常时保留 fallback，并显示明确同步状态，不阻塞官网首屏。

### 风险与限制

- GitHub API 受浏览器网络、跨域策略和速率限制影响；fallback 只保证官网可用，不替代 GitHub Release 的完整正文。
- 旧标签 `v0.6.2`、`v0.6.3` 的历史资产保持不变；完整六类平台安装包从 `v0.6.4` 起作为发布门禁。
- macOS 未配置 Developer ID 公证时仍使用 ad-hoc 签名，首次打开可能需要系统放行。
