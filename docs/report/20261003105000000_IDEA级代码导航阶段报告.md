# IDEA 级代码导航阶段报告

## 结果

本轮已把 Tau Editor 的代码导航从“单文件正则提示”推进到“LSP 优先、正则降级”的可运行架构。工作区启动时会创建语言服务器会话，Monaco 模型使用真实文件 URI，并已接入定义、Peek 定义、Hover、引用、重命名和诊断标记入口。

## 已完成

- Rust/Tauri LSP Supervisor：stdio JSON-RPC、Content-Length framing、请求关联、通知、会话状态、进程退出检测、最多 2 次崩溃重启。
- 前端 LSP 基础层：JSON-RPC、超时、取消、文档生命周期、UTF-16 位置转换、file/untitled URI、workspace + language 会话复用。
- 语言服务器注册：TypeScript、Python、Rust、Go、C/C++、Java、C#，优先使用系统 PATH 中的 server。
- Monaco Provider：Definition、Hover、References、Rename、publishDiagnostics；LSP 不可用时回退现有轻量导航。
- EditorCore：F12、Shift+F12、F2，右键定义/Peek/引用/重命名，编辑内容同步到 LSP。
- App 生命周期：启动、工作区切换和卸载时注入/关闭 ApplicationLspService；旧工作区会话不会残留。
- 命令面板和全局快捷键：跳转定义、查看定义、查找引用、重命名符号。

## 能力边界

### 已可用

- 已打开文件之间的 LSP 定义、Hover、引用和重命名请求链路。
- Rust 在当前机器上可优先使用 `/Users/albertluo/.cargo/bin/rust-analyzer`。
- LSP server 不存在、启动失败或请求异常时，编辑器仍可使用正则 fallback。

### 有条件可用

- TypeScript、Python、Go、Java、C/C++、C# 取决于本机是否安装对应语言服务器。
- 语言服务器可能要求项目级配置文件、依赖索引或编译数据库；当前只完成通用初始化和文档同步。

### 尚未闭环

- LSP 返回未打开文件时，尚未完全复用 App 的文件打开流程并定位到行列。
- Problems 面板、诊断聚合和点击诊断定位尚未完成；当前诊断已写入 Monaco markers。
- Go to Implementation、Type Definition、Call Hierarchy、Symbol Outline 的 LSP 专用请求尚未补齐。
- Server registry 的版本检查、安装引导和 sidecar 打包尚未完成。
- Java/C# 等语言服务器的高级初始化参数、workspace/configuration 等服务端请求仍是后续增强项。
