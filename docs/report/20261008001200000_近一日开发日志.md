## 功能与体验调整

### Markdown 预览

- 新增“林间薄荷”“雾紫信笺”“深海蓝调”三种预览风格，并将其接入设置页和预览右键菜单。
- 补齐新增风格的中英文名称、预览配色、右键菜单配色及设置持久化白名单。
- 修复切换预览风格后预览区域和 Teleport 到 `body` 的右键菜单未同步更新主题的问题。
- 调整浅色主题下预览右键菜单的配色，提升文字与背景的可读性。

### 设置页与主题配色

- 统一浅色主题下设置面板、输入框、按钮和下拉选项的表面颜色，使选项展开背景与面板协调，并保证文字对比度。
- 调整主题市场的搜索、筛选和交互控件，使其跟随设置面板主题。
- 整理主题风格与明暗表现，减少设置页中相互割裂的颜色和模式控件。

### 状态栏与工具栏

- 优化底部功能菜单的布局、选中状态和滚动表现；菜单改为浮层定位，避免打开时短暂撑高状态栏，并加入 Animate.css 淡入效果。
- 简化“未保存”状态提示：去除边框和底色，仅保留较小文字及状态圆点。
- 移除“系统”按钮及相关菜单操作。
- 收敛工具栏左上角品牌区域，仅保留图标，并按明暗主题调整图标颜色；同步简化界面身份信息。
