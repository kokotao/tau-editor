# Tau Editor 近期修改日志

**统计区间：** 2026-10-08 00:12 至 2026-10-08 11:43（UTC+8）  
**范围说明：** 汇总本区间的编辑器标题栏、更新流程和本地 macOS 安装包改动；工作区改动尚未全部提交，不代表已发布版本。

## 编辑器布局与 macOS 标题栏

- 调整编辑器顶部结构，让标签栏与编辑区衔接，并增加可点击的工作区路径导航。
- 配置 macOS Overlay 标题栏，在原生标题栏区域提供位置后退/前进、快速打开、命令面板和视图折叠操作。
- 补齐编辑器当前位置读取及标签切换历史记录，让普通文件切换也能参与位置导航。
- 更新主题市场中的界面预览，使其展示新的标题栏、标签栏和路径导航布局。

## 更新检测与升级流程

- 标题栏不再常驻显示“检查更新”按钮；有可用新版本时才显示升级图标。
- 更新图标提示包含版本和发布说明；当前设备没有匹配安装包时，点击会打开对应 Release 页面。
- 点击有匹配安装包的升级图标后，直接开始下载并启动安装。
- Tauri 下载流程改为分块写入，并将下载字节数、总大小和百分比发送给前端；标题栏显示进度条与百分比，下载完成后短暂提示安装程序已启动。
- 为未知下载总大小的场景保留不确定进度动画；升级失败时通过通知明确提示错误。
