# 云文档零工作区落位 · 真机冒烟清单

- 日期：2026-10-26
- 目的：本轮全部验证都是单测 / 类型检查 / 编译，**没有一次真机端到端**。本清单用来把"链路真能跑"这件事确认掉。
- 为什么不用 e2e 自动化：仓库的 Playwright 跑的是浏览器构建（`tests/e2e/fixtures/app.ts` 用 localStorage 初始化，走非 Tauri 降级路径），而落位链路依赖三个真实 Tauri 命令（`cloud_dir_exists` / `cloud_scratch_workspace` / `copy_file`），浏览器里没有对应实现。自动化覆盖已由 112 条 Rust 测试 + 1388 条前端单测承担，**缺的正是"Tauri 接线在真机上对不对"**。

## 0. 准备（两种方式二选一）

**A. 直接跑打包版**（更接近真实用户环境，推荐）

```
D:\WorkSpace\AlbertLuo\lizi-tauEditor-project\tau-editor\frontend\src-tauri\target\release\text-editor.exe
```

安装包：`…\target\release\bundle\nsis\Tau Editor_0.6.25_x64-setup.exe`

**B. dev 模式**（可看 devtools 日志）

```bash
cd tau-editor/frontend
pnpm tauri dev
```

> 构建必须用 MSVC：`RUSTUP_TOOLCHAIN=stable-x86_64-pc-windows-msvc pnpm tauri build --bundles nsis`。默认 GNU 工具链会挂在 `ld.exe: error: export ordinal too large`。

前置：已登录 lizi 账号（左侧云端文档面板能列出文档）。为减少干扰，先清掉 `%TEMP%\\tau-scratch` 与 localStorage 里的 `text-editor-workspace` / `text-editor-cloud-workspace-bindings`。

记录方式：每条记 **PASS / FAIL** + 截图或日志路径。FAIL 时贴 devtools 报错或 `frontend/src-tauri/.tau-logs/` 下的内容。

| 步骤 | 期望 |

| 2.5 看标题栏 | **不应**出现任何 scratch 标识（用户已明确否决） |

## 3. 自动保存三触发点

| 步骤 | 期望 |
| --- | --- |
| 3.1 在 2 打开的文档里改几个字后停手 | 约 2.5s 后自动保存一次（devtools Network 里一条 `POST /cloud-docs`，payload 带 `baseVersion`） |
| 3.2 改字后立刻点编辑器外（失焦） | 立即保存，且**不会**再补发一次（2.5s 窗口被取消） |
| 3.3 改字后立刻 Ctrl+S | 本地文件立刻落盘 **且** 云端保存立即触发；两者都成功 |
| 3.4 不做任何修改，反复失焦/点保存 | **不发请求**（空写抑制，contentHash 未变） |
| 3.5 连续快速改 5 次 | 请求数应远少于 5（单飞 + 合并），且最终云端内容等于最后一次编辑 |

## 4. 另存到工作区（含二进制）

| 步骤 | 期望 |
| --- | --- |
| 4.1 点「另存到工作区…」→ 选一个空目录 `D:\\smoke\\分享` | 提示「已复制 N 个文件到「分享」」；工作区切到该目录；徽标消失（来源变 user） |
| 4.2 检查已打开的标签 | 标签仍在、内容不变、**脏标记保留**（若之前未保存），路径已指向新目录 |
| 4.3 放一个 `.docx` / `.pdf` 进临时工作区后重跑一次另存 | 二进制文件**真的被复制**（原实现会跳过）；提示里不应出现"未复制" |
| 4.4 目标目录里预置一个同名文件后再另存 | 同名被**跳过不覆盖**，提示「跳过 N 个同名文件（不覆盖）」；被跳过的文件对应标签**不迁移** |
| 4.5 把目标选成临时目录本身的子目录 | 拒绝并提示（不能把工作区搬进自己里面） |
