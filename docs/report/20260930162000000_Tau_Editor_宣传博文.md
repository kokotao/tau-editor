# Tau Editor：把写作、编码与 Markdown 工作流放进一个安静的工作台

> 一款面向开发者、技术写作者和日常文本工作者的跨平台桌面编辑器。当前稳定版本：`v0.6.1`。

有些工具打开以后，第一件事是让你配置工具本身。

Tau Editor 想做的事情恰好相反：打开文件，开始编辑；需要 Markdown 时，直接写；需要整理项目时，打开工作区；需要切换主题或命令时，用一个快捷键完成。

它基于 Tauri 2 + Vue 3 构建，支持 Windows、macOS 和 Linux，并以 MIT License 开源。Tau Editor 不是一个只适合演示的编辑器，而是一张可以反复回到其中工作的桌面工作台。

![Tau Editor 主界面](../assets/screenshots/editor.png)

## 写 Markdown，不必在编辑器和预览之间来回切换

在 `v0.6.1` 中，Markdown 工作流被放到了编辑器的中心位置。顶部工具栏、右键菜单和选中文本浮动工具栏，都可以快速插入常用语法：

- 标题、粗体、斜体、删除线和引用
- 无序列表、有序列表和任务列表
- 链接、图片、表格、分割线和折叠块
- 目录、时间戳和 Mermaid 图表
- 行内代码与可选择语言的代码块

常用操作也有对应快捷键：`Ctrl+B` 加粗、`Ctrl+I` 斜体、`Ctrl+Q` 引用、`Ctrl+K` 行内代码、`Ctrl+L` 链接。粗体和斜体可以按任意顺序组合，编辑时不需要停下来找格式按钮。

![Markdown 分栏预览](../assets/screenshots/markdown-preview.png)

当文档需要图表时，Mermaid 围栏代码可以在 Markdown 预览中渲染流程图、时序图、类图、状态图、ER 图、甘特图、思维导图、时间线、Kanban 等常见图表。写设计说明、项目文档或技术方案时，文字与结构图可以留在同一个文件里。

## 图片粘贴后，资产也能保持整洁

截图、流程图和界面标注是技术写作的一部分。Tau Editor 支持把剪贴板图片直接粘贴到 Markdown 文档：图片会保存到文档同级的 `assets/` 目录，正文使用相对路径引用。

这意味着文档移动到另一个目录、提交到 Git 仓库或发布到静态站点时，图片引用仍然清晰可追踪。你不需要手动命名临时文件，也不用把图片上传到一个与文档无关的地方。

## 面向真实项目的编辑能力

Tau Editor 的基础能力足够覆盖日常开发工作：

- 多标签页同时编辑多个文件，并提示未保存状态
- 50+ 编程语言语法高亮，并根据文件类型自动识别
- 多光标、代码折叠、自动缩进、撤销与重做
- 当前文件搜索、全局搜索、正则表达式和批量替换
- 文件树工作区、最近文件和快速打开
- 文件编码自动检测，支持 UTF-8、GBK 等常见编码

命令面板可以通过 `F1` 或 `Ctrl+Shift+P` 打开。文件操作、视图切换、主题切换和编辑命令集中在同一个入口，熟悉之后，很多操作都可以不离开键盘。

![命令面板](../assets/screenshots/command-palette.png)

## 让工作台适应你的习惯

Tau Editor 提供浅色、深色和系统模式，并内置多套主题皮肤。你还可以导入、导出主题 JSON，调整编辑器与界面的颜色，让代码区、Markdown 预览和应用界面保持一致。

从 `v0.6.0` 开始，主题市场支持从 GitHub catalog 搜索、安装、应用主题并查看源码。主题不再只是一个固定的颜色选择，而是可以被分享、修改和贡献的配置包。

快捷键同样可以按个人习惯调整。命令面板会展示当前生效的快捷键，发生冲突时会提示确认，单条重置和全部重置都保留在设置中。

![设置与主题](../assets/screenshots/settings.png)

## 轻量、跨平台，也保留桌面应用的安全边界

Tau Editor 使用 Tauri 2，将文件系统、窗口和原生对话框放在 Rust 后端处理，前端负责编辑器交互与工作台界面。你可以在 Windows、macOS 和 Linux 上使用同一套工作流。

项目也为真实桌面场景准备了恢复库、自动保存、外部文件变更监听和冲突处理。编辑器不仅要“能打开文件”，还要在文件被外部修改、窗口意外关闭或多个标签同时工作时，尽量把内容和上下文保留下来。

## 现在开始使用

当前稳定版本是 `v0.6.1`，GitHub Release 提供以下安装包：

- macOS（Apple Silicon）：DMG
- Windows（x64）：EXE / MSI
- Linux（x64）：DEB / RPM / AppImage

下载地址：[Tau Editor v0.6.1 Releases](https://github.com/kokotao/tau-editor/releases/tag/v0.6.1)

也可以先访问[官方产品主页](https://kokotao.github.io/tau-editor/)了解界面与功能。项目源码和问题反馈入口位于 [GitHub 仓库](https://github.com/kokotao/tau-editor)。

macOS 用户首次打开未配置 Developer ID 公证的安装包时，可能需要在“系统设置 → 隐私与安全性”中手动点击一次“仍要打开”；完整步骤见仓库中的 [INSTALL.md](../../INSTALL.md)。

## 写得更快，整理得更稳

一个好的编辑器不会抢走注意力。它应该在你需要格式、搜索、预览、主题或文件管理时及时出现，在你专注于内容时安静退到背景里。

Tau Editor 目前把这条路径做得足够完整：从一段代码，到一篇 Markdown 文档，再到一个带图片和 Mermaid 图表的项目说明，都可以在同一个桌面工作台中完成。

如果你正在寻找一款开源、跨平台、以文本和 Markdown 为中心的编辑器，Tau Editor 值得成为你的下一张工作台。
