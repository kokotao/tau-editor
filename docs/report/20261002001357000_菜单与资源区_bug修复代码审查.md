## Important

### I-1：Teleport + fixed 菜单仍使用编辑器相对坐标

- 文件：`frontend/src/components/editor/EditorCore.vue:965-980`
- 关联代码：`frontend/src/components/editor/EditorCore.vue:655-684`
- 触发条件：编辑器容器不位于视口左上角时，在编辑器内右键。
- 问题：Monaco 回调拿到的是浏览器视口坐标 `eventX/eventY`，代码却减去编辑器容器的 `bounds.left/top` 后，将 `relativeX/relativeY` 传给 `openContextMenu`。菜单已经通过 `Teleport to="body"` 挂到 `body`，并使用 `position: fixed`，此时应使用视口坐标。
- 影响：菜单会向左上方偏移编辑器容器的位置；边界翻转判断也基于错误坐标。侧栏、顶部工具栏或窗口布局发生偏移时，右键菜单可能出现在错误位置，甚至脱离点击点。
- 建议：直接调用 `openContextMenu(eventX, eventY)`；或者取消 Teleport/fixed，恢复为相对于编辑器容器的定位方式。两者必须统一坐标系。

## Minor

### M-1：二级菜单定位使用估算尺寸，窄窗口下可能越界

- 文件：`frontend/src/components/editor/EditorCore.vue:641-652`
- 问题：二级菜单宽度固定估算为 `220px`，高度估算为 `300px`，没有读取真实面板尺寸，也没有对最终 `left` 做完整的 `[8, viewportWidth - width - 8]` clamp。
- 影响：窗口较窄、触发项靠左或右侧空间不足时，二级菜单可能部分跑出视口；实际内容高度变化时，上下定位也可能不准确。
- 建议：面板显示后使用 `getBoundingClientRect()` 重新定位，并对最终横纵坐标统一 clamp；至少对左侧翻转结果加 `Math.max(CONTEXT_MENU_MARGIN, left)`。

### M-2：新增菜单交互缺少几何和真实递归场景测试

- 文件：`tests/unit/components/EditorCore.test.ts`、`tests/unit/components/FileTree.test.ts`
- 当前情况：EditorCore 测试没有覆盖 Teleport 菜单、二级菜单悬浮保持、视口边界定位；FileTree 测试覆盖了菜单基本操作，但没有断言多级目录快速连续右键时 `document.body.querySelectorAll('.context-menu').length === 1`，也没有真实验证横向溢出时 `scrollWidth > clientWidth`。
- 风险：本轮最容易回归的坐标定位、二级菜单悬浮和多级目录滚动问题目前主要依赖静态代码检查。
- 建议：补充以下测试：
  1. 编辑器容器有非零 `getBoundingClientRect().left/top` 时，菜单位置等于 client 坐标。
  2. 触发二级菜单 `mouseenter` 后移动到 panel，panel 保持显示；离开后按计时器关闭。
  3. 展开至少两级目录，连续右键两个文件，断言 body 中始终只有一个资源菜单且内容对应最后一个文件。
  4. 使用浏览器/E2E 或带布局能力的 DOM 测试验证长文件名和元信息产生底部横向滚动。

### M-3：FileTree 测试对 Teleport DOM 的清理不够明确

- 文件：`tests/unit/components/FileTree.test.ts`
- 问题：测试通过 `document.body.querySelector` 查询 Teleport 菜单，但没有在每个用例后显式 unmount wrapper 或清理 body/window listener。
- 影响：当前单文件测试通过，但测试数量增加后可能出现残留 Teleport 节点、全局事件监听器或跨用例选择器干扰。
- 建议：统一使用 `afterEach(() => { wrapper?.unmount(); document.body.innerHTML = ''; })`，或启用 Vue Test Utils 的自动卸载机制，并增加多实例清理断言。

## 未发现的问题

- FileTree 通过 `v-if="!nested"` 仅让根实例渲染 Teleport 菜单，并由递归子树向上转发右键事件，结构上能够避免每一级目录各渲染一份菜单。
- `FILE_TREE_CONTEXT_MENU_EVENT` 在打开新菜单前关闭旧实例，配合 `contextMenuOpenToken` 可避免同一实例快速右键时旧的 `nextTick` 回调覆盖新菜单。
- 资源列表使用 `overflow-x: auto`、`width: max-content` 和 `min-width: 100%`，主方向上符合“完整显示 + 底部横向查看”的需求。
