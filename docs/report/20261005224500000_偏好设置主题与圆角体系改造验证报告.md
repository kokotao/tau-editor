## 已验证行为

- 偏好设置 workspace 与 drawer 已移除“浅色 / 深色 / 系统”主题模式控件，仅按主题风格切换。

- 设置页、工作区、侧栏、抽屉和主题市场使用 `--bg-app`、`--panel-base` 及分类圆角变量。
- 圆角基础值支持 `0–24px`、`0.5px` 步进；分类值覆盖控件、卡片、面板、标签页、弹窗和徽标，旧数字格式继续兼容。
