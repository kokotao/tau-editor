## 3. 已确认无问题的关键点

- 搜索会话：`begin` 拒绝空/重复 `searchId`，`finish` 在成功与失败路径都会回收；`cancel` 对已结束会话返回 `SEARCH_EXPIRED`，前端按该错误码静默处理。
- 搜索取消可生效：`SearchCancellation` 使用原子标志，目录遍历、文件循环、行循环三层都检查。
- 替换预览：命中计划冻结 `revision`；执行时重新按行计算偏移而不是复用旧偏移；写盘走 `write_file_if_revision`，冲突按文件跳过。
- 撤销：按写入后的 `revision` 回写，冲突计入 `conflicts` 而不是静默覆盖；单文件 >1 MiB 不保留撤销副本并标记 `undoable: false`。
- CRLF 保留：`split_inclusive('\n')` + `split_line_ending` 保证替换后不丢失 `\r\n` 与末行无换行的情况。
- Markdown 资产：拒绝符号链接与非普通文件，限制 10 MiB 与扩展名白名单，写入使用同目录临时文件 + `rename`。
- 链接校验：外部/锚点/`file://`/绝对路径/越界/缺失分类完整，`starts_with` 为路径分量级比较，可防止 `/ws` 与 `/ws2` 误判。
- 工作区任务：跳过代码围栏内伪任务，限制 200 文件 / 500 任务 / 单文件 1 MiB，并在响应中回传 `truncated`。
