## 6. 已知限制（V1 接受）

1. 只同步文本类白名单文件（12MB 以内），二进制/非 UTF-8 拒绝。
2. 历史版本只裁剪版本行，不清理已落盘文件（V2 后台脚本）。
3. `/blog/pages/my` 只认 `page/size`。
4. 旧版博客首页（oldpage）未加「我的文章」分段（默认新版）。
5. 冲突三路 diff 合并留 P8 增强（当前为本地覆盖/云端覆盖二选一）。
