## 1. 结果

已按规范将全局圆角调整为 `0 / 2 / 4 / 6 / 8px + 圆形例外`。编辑器的结构性区域继续保持平角，高频交互控件和浮层获得克制的微圆角，没有引入卡片化或过度圆润效果。

## 2. 实施内容

### 全局 Token

- `--radius-none: 0`
- `--radius-xs: 2px`
- `--radius-sm: 4px`
- `--radius-md: 6px`
- `--radius-lg: 8px`
- `--radius-pill: 999px`
- `--radius-round: var(--radius-pill)`
- `--panel-radius` 继续使用 `0`

### 工作台结构

以下区域保持平角：

- 应用骨架和三栏布局。
- 工具栏和状态栏主体。
- 编辑器与侧栏外框。
- 标签栏容器。
- 文件树和上下文栏全宽行。
- Monaco 编辑区域和 resizer。

### 交互控件

以下区域应用 `4px`：

- 工具栏图标按钮、系统菜单触发器和未保存徽标。
- 标签悬浮及激活顶部圆角。
- 标签关闭按钮、重命名输入框和 Tooltip。
- 状态栏状态项、选择器和作者按钮。
- 文件树搜索框、操作按钮和菜单项。
- 设置页按钮、导航项、快捷键行和输入框。
- Markdown 引用块、提示块和预览菜单项。

### 内容与浮层

- `6px`：菜单外框、通知、设置卡片、预览卡片、表格、代码块、二维码卡片。
- `8px`：Command Palette、外部变更弹窗、替换预览和空状态主容器。
- `50%`：未保存状态点、加载环等语义圆形元素。
