# 主题市场独立栏目与外观可配置实施计划

**目标：**将主题市场从“通用”设置中独立为左侧导航栏目，支持主题源码 JSON 原文预览，并让主题包、自定义配色能够控制设置导航/标签选中态等语义颜色，同时新增可持久化的界面圆角配置。

**架构：**复用现有 `SettingsPanel` 工作区和 Pinia `settings` store，不新增后端接口或独立页面路由。主题市场继续由 `ThemeMarketplaceService` 负责受信任的 GitHub Raw 请求与校验，新增“原始 JSON”读取能力；所有新增颜色和圆角都转换为 CSS 变量，由主题应用入口统一注入，组件只消费语义变量。

**技术栈：**Vue 3 `<script setup>`、Pinia、Naive UI、Vite、TypeScript、Vitest、现有主题包 v2 schema、CSS custom properties。

---

## 1. 范围与非目标

### 本期范围

- 在设置页左侧导航增加“主题市场”独立栏目。
- 将主题市场卡片从“通用”栏目迁移到“主题市场”栏目，保留刷新、安装、应用、发布入口。
- 点击主题卡片源码箭头时，打开弹窗展示对应 raw GitHub JSON 原文；支持加载中、错误、复制、关闭、重试和滚动查看。
- 主题包与自定义配色支持设置页导航选中态、悬浮态、标签选中态、焦点环等语义颜色。
- 新增圆角配置：预设 + 手动数值，实时作用于工作台、设置页、卡片、标签、按钮和弹窗。
- 主题/配色/圆角设置持久化到现有设置存储，并兼容旧版本设置。

### 非目标

- 不新增服务器端主题代理，不执行远程 JSON 中的 CSS、JavaScript 或 HTML。
- 不改变 macOS 原生窗口标题栏装饰。
- 不在本期重做主题包格式；新增颜色字段保持可选，旧主题包继续可导入。
- 不把主题市场改造成独立顶层 Vue Router 页面；第一阶段沿用设置工作区内部栏目切换。

## 4. 主题设置数据契约

### 4.1 设置 store 新增字段

在 `EditorSettings` 中新增：

```ts
type CornerRadiusPreset = 'sharp' | 'subtle' | 'comfortable' | 'custom';

cornerRadiusPreset: CornerRadiusPreset;
cornerRadius: number; // 0-12px，默认 6px
```

归一化规则：

- `cornerRadius` 非数字、超出范围或旧版本不存在时回退到 `6`。
- 选择预设时同步写入数值：`sharp=0`、`subtle=4`、`comfortable=8`。
- 手动调节数值后自动切换到 `custom`。
- `resetToDefaults()` 恢复 `comfortable/6`，主题包资产不删除。

### 4.2 可选主题颜色键

保留现有必需颜色 `bgApp`、`textPrimary`，新增可选语义色：

- `accentSoft`：选中背景、标签背景、轻量提示背景。
- `selectionBackground`：导航/列表/标签选中背景。
- `selectionBorder`：选中边框或指示线。
- `selectionText`：选中项文字。
- `focusRing`：键盘焦点环。

为避免把 UI 配置全部挤入扁平颜色字段，主题包 mode 增加可选 `ui` 分组，现有 `colors` 与 `monaco` 契约不变：

```ts
ui?: {
  sidebar?: { bg?: string; text?: string; activeBg?: string; activeText?: string; activeIndicator?: string };
  panel?: { bg?: string; raisedBg?: string; border?: string; heading?: string };
  tabs?: { bg?: string; text?: string; activeBg?: string; activeText?: string; activeIndicator?: string; hoverBg?: string };
  syntax?: { keyword?: string; string?: string; number?: string; comment?: string; function?: string; type?: string; variable?: string };
  radius?: number;
}
```

校验规则：颜色仅接受 6 位 hex；每个分组只接受白名单键；`radius` 为 0-12 的整数 px。palette 仍禁止覆盖 `bgApp`、`panelBase`，但可覆盖 sidebar/panel/tabs/syntax。旧包没有 `ui` 时视为无覆盖。应用优先级为：内置主题 -> 主题包 mode.colors -> 主题包 mode.ui -> 当前模式自定义覆盖 -> CSS fallback。

### 4.3 CSS 变量

统一由 `settingsStore.applyTheme()` 写入/清理：

```css
--sidebar-bg
--sidebar-text
--sidebar-active-bg
--sidebar-active-text
--sidebar-active-indicator
--panel-raised
--panel-border
--section-heading
--tab-bg
--tab-text
--tab-active-bg
--tab-active-text
--tab-active-indicator
--tab-hover-bg
--syntax-keyword
--syntax-string
--syntax-number
--syntax-comment
--syntax-function
--syntax-type
--syntax-variable
--radius-ui
--radius-ui-sm
--radius-ui-lg
```

在 `workbench-theme.css` 中以现有主题颜色为默认回退，并把现有固定圆角 token 改为基于 `--radius-ui` 的比例：

```css
--radius-ui: 6px;
--radius-ui-sm: max(0px, calc(var(--radius-ui) - 2px));
--radius-ui-lg: min(12px, calc(var(--radius-ui) + 2px));
```

`--radius-pill` 保持胶囊语义，不受数值圆角影响。自定义覆盖设置独立于主题包存储，用户导入/导出主题包时将对应 mode 的 `ui` 一并 round-trip。

## 6. 验收标准

1. 设置页左侧存在独立“主题市场”栏目，点击后只渲染主题相关内容，刷新和安装/应用流程不回归。

3. 主题包和自定义配色可影响设置导航 active、标签 selected、hover、focus 等状态，并在切换后无需刷新立即生效。
4. 圆角配置支持预设和 0-12px 手动值；主题包可带默认半径，用户自定义半径优先；设置持久化，旧用户升级后默认保持当前视觉近似值。
5. 浅色/深色主题下选中态文字与背景保持可读，键盘可访问，窄窗口不溢出。
6. 类型检查、单元测试、差异检查和生产构建全部通过。

## 7. 风险、回滚与交付

- **远程请求风险：**raw 文件不可用、网络失败或内容不合法时只在弹窗展示错误，继续使用缓存 catalog；不自动激活远程内容。
- **主题 schema 兼容风险：**新增颜色全部可选，旧包不迁移字段即可继续工作；若验证逻辑出现问题，可仅回滚新增颜色键而保留栏目/弹窗功能。
- **圆角视觉风险：**部分控件可能需要保持平角或胶囊形，实施时优先替换固定 `border-radius`，逐个保留语义例外，不做全局字符串替换。
- **状态迁移风险：**旧 localStorage 缺失圆角字段时使用默认值，不删除用户主题包和自定义配色。
- **回滚顺序：**先关闭新栏目入口，再回退语义变量和圆角字段，最后移除 raw JSON 弹窗；每一步均不影响已有主题安装数据。

## 8. 交付顺序

1. 先完成 store/schema/CSS token 与单测，建立稳定的数据契约。
2. 再迁移设置栏目并接入 JSON 弹窗，保证主题市场功能可独立使用。
3. 最后接入 active/selected 语义样式、圆角控制、浏览器验收和构建验证。
