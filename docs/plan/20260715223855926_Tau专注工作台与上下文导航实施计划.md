# Tau 专注工作台与上下文导航 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Tau 编辑器交付为细线分隔的扁平三栏工作台，并为当前文件提供可跳转的右侧上下文导航。

**Architecture:** `documentOutlineService` 是不依赖 Vue、Store 或 Monaco 的纯解析层；`ContextRail` 只渲染 Outline 与分派事件；`App.vue` 负责宽度、抽屉互斥、文件上下文与编辑器/预览协调。先完成 Markdown 和通用兜底，再扩展到受限的代码与数据结构。

**Tech Stack:** Vue 3、TypeScript、Pinia、Monaco Editor、Vitest、Vue Test Utils、Playwright。
