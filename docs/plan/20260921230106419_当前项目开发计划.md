# Tau Editor 当前项目开发计划

> 计划时间：2026-09-21  
> 基线版本：`0.3.2`，当前分支 `fix/windows-console-flash`，HEAD 与 `v0.3.2` 代码树一致  
> 计划范围：先完成 v0.3.x 的数据安全闭环，再进入 v0.4.0 工作流增强  
> 目标原则：小步交付、可运行、可验证、可回滚，优先消除静默数据丢失风险

## 1. 当前结论

项目当前可以正常开发、构建和测试，但不建议直接堆叠新功能。v0.3.0 的统一工作台计划只完成了约 60%，主要缺口集中在恢复、文件监听、三方冲突、大文件安全保存和可取消替换预览。

下一阶段固定为两条路线：

1. `v0.3.3`：安全收口版，完成 v0.3.0 未闭环的数据安全能力，补齐 E2E 与 CI 门槛。
2. `v0.4.0`：体验增强版，在安全能力稳定后，再交付自定义主题、快捷键自定义、多窗口、文件对比和插件接口预留。

## 3. 现状审计

### 3.1 已落地能力

- Workspace Runtime：`resolve_workspace`、`get_file_revision`、`write_file_if_revision` 已实现，使用 `workspaceId + relativePath + revision` 边界。
- 安全写入：已实现同目录临时文件、`fsync`、原子替换、写入前 revision 二次校验。
- Git：状态、Diff、暂存、取消暂存、恢复工作区文件已接入，命令通过工作区边界和参数数组执行。
- 内容搜索：`search_workspace` 已支持文本、正则、大小写和整词匹配，默认跳过 `.git`、`node_modules`、`target`、`dist`。
- 条件替换：`apply_workspace_replace` 已按文件读取 revision，并在写入前执行冲突检查。
- 快速打开：已有文件排名和命令入口。
- Markdown：已有大纲、任务、链接解析和独立 HTML 导出。
- 大文件：`workspaceService` 已使用 `read_file_chunked` 打开大文件，并按会话 id 防止旧加载覆盖新标签。
- 外部修改：已有轮询检测、重新加载、保留当前内容和前端提示。
- 测试：Vitest、Rust 单元与集成测试均通过。

### 3.2 未闭环能力

| 缺口 | 当前实现 | 风险 | 目标版本 |
|---|---|---|---|
| 恢复库 | 仍使用 `localStorage` 的 `text-editor-session-v1` 和草稿键 | 大草稿容易超限，缺少 app-data 隔离、迁移和统一清理 | v0.3.3 |
| 文件监听 | `FileWatcherService` 存在但未接入 Tauri 生命周期，前端每 1.5 秒轮询当前标签 | 多文件变更延迟、未监听非活动标签、无法可靠处理重命名 | v0.3.3 |
| 三方冲突 | dirty 时只标记 `externalModifiedAt`，没有基线、内存、磁盘三方 Diff | 用户只能盲目重载或继续编辑，无法判断差异 | v0.3.3 |
| 大文件最终保存 | 最终保存仍走路径式 `write_file_chunked`，没有工作区 revision 提交 | 外部变更可能在保存时被覆盖，partial 状态缺少完整状态机 | v0.3.3 |
| 条件写入上限 | `write_file_if_revision` 单次最多 4 MiB | 大文件无法走 revision 安全保存路径 | v0.3.3 |
| 搜索取消 | 搜索是同步命令，没有 `requestId/searchId/cancel` | 大工作区搜索会阻塞，无法安全复用结果 | v0.3.3 |
| 替换预览 | 没有 `previewId`、matchId、不可重叠操作计划、逐项结果和撤销 | 用户无法确认命中范围，异常时难以定位和回滚 | v0.3.3 |
| Markdown 资产 | 没有原生导入资产授权 token，未复制图片到同级 `assets/` | 外部文件路径不稳定，拖入后容易失效 | v0.3.3 |
| 链接与任务 | 只解析当前文档任务和链接，不校验工作区链接有效性，也不聚合工作区任务 | 右侧上下文信息不完整 | v0.3.3 |
| HTML 导出 | 使用浏览器 Blob + 隐式下载 | 桌面端无法可靠选择目标目录，错误反馈弱 | v0.3.3 |
| E2E 与 CI | CI 只跑前端类型检查和 Web 构建，E2E 没有恢复、搜索、Git、冲突用例 | 关键数据安全回归无法自动拦截 | v0.3.3 |
| 发布记录 | v0.3.1、v0.3.2 没有对应 `docs/release` 文件 | 版本追溯不完整 | v0.3.3 |

## 4. 版本目标

### 4.1 v0.3.3 安全收口版

目标：

- 应用退出或崩溃后，工作区、标签、光标、滚动位置和未保存草稿可恢复。
- 外部文件变化不会静默覆盖本地修改。
- 大文件打开、加载中、取消、失败、完整加载和安全保存均有明确状态。
- 搜索可以取消，替换必须先预览、再按文件提交，并支持结果和回滚。
- Markdown 图片资产、链接、任务和 HTML 导出可闭环。
- 关键数据安全路径有 E2E，CI 自动拦截回归。

非目标：

- 不实现远程同步、协作编辑、完整 LSP、插件市场和云存储。
- 不重写 Monaco、Pinia 或现有编辑器主界面。
- 不在本版本引入跨文件事务承诺，替换仍按文件独立提交。

### 4.2 v0.4.0 体验增强版

只有在 v0.3.3 的质量门槛全部通过后再启动：

- 自定义主题和主题导入导出。
- 快捷键自定义与冲突检测。
- 多窗口和窗口间标签迁移。
- 文件对比与目录对比增强。
- Provider 接口扩展和插件能力预留。
- 大工作区索引性能优化和 Monaco 分包。

## 6. 子 Agent 开工模板

每个子 Agent 开工时必须一次性提交以下信息：

- 目标：本子任务要交付的可运行结果。
- 输入：依赖的代码、契约、测试和已完成工作流。
- 输出：新增或修改的文件、命令、测试和文档路径。
- 验收标准：可执行命令、预期结果和边界条件。
- 负责文件：只写自己独占的文件，不越界修改共享入口。
- 预计耗时：按小时或工作日标注。
- 心跳频率：至少每 60 秒一条进度，连续 120 秒无进展视为空闲回收。

建议的首批开工内容：

| Agent | 目标 | 输入 | 输出 | 验收标准 | 负责文件 | 预计耗时 | 心跳 |
|---|---|---|---|---|---|---|---|

## 7. 子 Agent 交付模板

每个子 Agent 完成后必须按以下格式交付，交付后立即请求关闭：

- 结果摘要：一句话说明交付状态。
- 改动点：文件、命令、配置或迁移脚本。
- 验证：实际执行的命令、结果和未执行项。
- 风险与回滚：影响面、已知限制和回退方式。

Agent-0 收到交付后，在 15 秒内执行关闭；失败任务最多自动重试 1 次，重试前先关闭旧 Agent。超过 30 分钟未完成的任务先中断再关闭，由 Agent-0 接管。

## 9. 验收标准

### 9.1 v0.3.3 功能验收

1. 关闭并重启应用后，可恢复工作区、标签、活动文件、光标、滚动位置和未保存草稿。
2. v1 会话和草稿可迁移到 v2；损坏或超大记录不会阻塞应用启动。
3. 外部修改 dirty 文件时，不自动覆盖内存内容，可查看三方 Diff，并选择重载、保留或另存为。
4. 100 MB UTF-8 文本可首屏打开；加载中只读；取消、失败、重试和完成状态明确。
5. 大文件最终保存使用 revision 提交，外部修改时返回 `FILE_CONFLICT`，不覆盖磁盘文件。
6. 搜索可以取消；失效 searchId 不重新搜索；替换先展示不可重叠预览。
7. 替换按文件独立提交，成功、跳过、失败和撤销结果逐项可见。
8. Markdown 图片可导入同级 `assets/`，相对链接状态可识别，任务可聚合，HTML 可导出到选择的目标目录。
9. `⌘P`、`⌘⇧P`、`⌘⇧F` 与编辑器快捷键无冲突。
10. Git 状态、Diff、暂存、取消暂存和恢复操作不影响未选择文件，危险操作有确认。

## 10. 风险与回滚

| 风险 | 等级 | 应对 | 回滚 |
|---|---|---|---|
| 恢复迁移损坏旧草稿 | 高 | 先读取 v1，再原子写 v2；迁移前保留备份；迁移失败不阻塞启动 | 保留 v1 读取路径，删除 v2 测试数据后重试 |
| watcher 触发自身写入循环 | 高 | 忽略 `.tau-*.tmp`、`.git`、`node_modules`、`target`、`dist`，事件去抖 300 ms | 关闭 watcher feature 开关，回退到轮询 |
| dirty 文件被外部覆盖 | 高 | 三方比较后才允许重载；默认保留内存内容 | 立即从草稿恢复并提示用户另存为 |
| 大文件加载占用过多内存 | 中 | 首屏分块读取；标签内存上限；loading 状态只读 | 关闭标签并释放 chunk 内容 |
| 替换结果不一致 | 高 | 预览、matchId、byte range、原片段 hash、revision 逐层校验 | 使用成功文件前镜像撤销，失败文件不写入 |
| 共享入口文件冲突 | 中 | Agent-0 串行集成；领域 Agent 只提交补丁建议 | 按模块提交逆序 revert |
| Windows 路径和文件锁差异 | 中 | 三平台 CI 与路径边界测试 | 回退 Windows 专属改动，保留通用路径校验 |
| Monaco 包过大影响启动 | 中 | v0.4 做按需语言加载和 manualChunks | 保持现有构建，不阻塞 v0.3.3 |
| 发布产物缺少签名 | 中 | 发布记录标注风险和验证结果 | 保留上一条可用 tag，不覆盖已发布产物 |
