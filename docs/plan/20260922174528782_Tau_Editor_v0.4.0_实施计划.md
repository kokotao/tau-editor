## 3. 风险与应对

| 风险 | 等级 | 应对 | 回滚 |
|---|---|---|---|
| 自定义 Monaco 主题注册失败导致编辑器空白 | 高 | 注册前后 try/catch，失败回退 `vs`/`vs-dark`，并有单测 | 关闭主题包功能开关，回到内置皮肤 |
| 快捷键覆盖导致命令不可用 | 中 | 冲突检测 + 一键重置；默认绑定常量与覆盖分离 | 清空 localStorage 覆盖字段 |
| Diff 载入超大文件导致卡死 | 高 | 2 MB 单侧上限 + 只读 + 明确错误码 | 关闭 Diff 视图 |
| 多窗口 payload 泄漏或串窗口 | 高 | payload 与 window label 绑定、取出即删、10 分钟过期、容量上限 | 禁用迁移命令，仅保留新窗口打开 |
| Monaco 按需加载破坏语言功能 | 中 | 语言注册表映射测试 + 全量 E2E | 回退到全量 language contribution 引入 |
| 分包后出现循环依赖告警 | 中 | 构建后检查 chunk 依赖，必要时调整 manualChunks | 保留原分包配置 |

## 4. 发布门槛

1. `pnpm typecheck`、`pnpm test:unit`、`pnpm build` 全绿。
2. `RUSTFLAGS="-D warnings" cargo check --all-targets --locked`、`cargo test --all-targets --locked` 全绿。
3. `pnpm exec playwright test --project=chromium` 全绿（含 v0.3.x 既有 51 条）。
4. 版本五处统一为 `0.4.0`。
5. `v0.4.0` tag 推送后 `Desktop Build` 三平台成功，Release 六类资产齐全并回填说明。
