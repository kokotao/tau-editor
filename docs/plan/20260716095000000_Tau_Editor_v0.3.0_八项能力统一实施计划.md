# Tau Editor v0.3.0 八项能力统一实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use @subagent-driven-development (recommended) or @executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在一个 v0.3.0 Release 中交付可靠的本地写作与代码工作台：恢复、文件安全、大文件、搜索替换、快速工作流、Git、代码上下文和 Markdown 工作流。

**Architecture:** 先建立 Rust `workspaceId + relativePath + revision` 安全运行时，所有文件、搜索、替换、Git 和资源操作都以它为边界。前端把 App.vue 的编排职责拆到专用 Store、Service 和右侧 ContextRail Provider；每种上下文只提供自身的数据和动作。现有会话、大文件分块、Markdown 大纲和命令面板优先迁移而非重写。

**Tech Stack:** Tauri 2、Rust、Vue 3、Pinia、Monaco Editor、Vitest、Playwright、git2、ignore、regex、serde。
