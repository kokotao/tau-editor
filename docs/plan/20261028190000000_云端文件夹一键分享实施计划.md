# 云端文件夹一键分享（/s/f/{token}）实施方案

> 需求：云端文档树的「文件夹」（= 分类）支持一键分享，外部通过**一个链接**打开文件夹目录页并在线阅读其中的文档。
> 形态：用户已确认走「B. 真正的文件夹分享链接（需后端改造）」。
> 编写：2026-10-28 ｜ 仓库：`lizi-learning-management`（后端）、`lizi-learning-admin-pro`（公开页）、`tau-editor`（发起入口）

---

## 1. 现状与约束

- 「文件夹」在云端没有真实目录实体：云文档树的分组来自 **分类（category，3 级）** 或路径前缀；`cat:<id>` 节点即分类。
- 现有分享是**逐文档**的：`user_document_share(doc_id, user_id, token, password_hash, expires_at, status, visit_count…)`，公开接口 `/blog/share/{token}`（`SecurityConfig.PUBLIC_PATHS` 已放行 `/blog/share/**`），图片走 `/{token}/assets/{assetId}?ticket=`。
- 文档实体 `UserDocument` 有 `userId / categoryId / path / title / content / size / version / isDeleted / status`。
- 分类实体 `Category`（雪花 id，字符串下发）。
- 结论：需要**新增文件夹分享实体 + 公开目录页**，不能复用文档分享表（唯一键 `uk_share_doc` 绑 docId）。

## 2. 目标能力（v1）

1. Tau：云文档树右键 `cat:<id>` 分类 →「一键分享文件夹」→ 弹窗生成/查看链接，可设置访问密码、有效期、是否包含子分类；支持重新生成（换 token）、撤销。
2. 公开页 `/s/f/{token}`：免登录打开，展示分类名、文档数、更新时间、文档列表（标题/类型/大小/更新时间）。
3. 在线预览：**文本类（markdown / code / text）**点击后直接阅读，复用分享页渲染（流程图、表格、折叠块、代码高亮）与图片附件；**二进制（pdf/office）**显示卡片提示「请在 Tau 中打开」（v1 不做服务端转 PDF，避免新增转换链路）。
4. 失效语义：撤销、过期、分类被删、token 不存在统一 404，不区分原因；有密码时先验密。
5. 权限：公开页只能看到分享创建人名下、且属于该分类（含子分类，按分享设置）的文档。

## 3. 数据库

新增表（幂等 DDL，放到 `lizi-learning-management/sql/20261028_folder_share.sql`，按现有 `sql/` 日期命名约定）：

```sql
CREATE TABLE IF NOT EXISTS `user_document_folder_share` (
  `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '主键',
  `user_id` BIGINT NOT NULL COMMENT '分享创建人',
  `category_id` BIGINT NOT NULL COMMENT '分类 id（雪花）',
  `token` VARCHAR(64) NOT NULL COMMENT 'URL 安全随机 token',
  `status` TINYINT NOT NULL DEFAULT 1 COMMENT '1 有效 / 0 已撤销',
  `include_sub_categories` TINYINT NOT NULL DEFAULT 1 COMMENT '是否包含子分类文档',
  `password_hash` VARCHAR(255) DEFAULT NULL COMMENT 'PBKDF2，null 表示无密码',
  `expires_at` DATETIME DEFAULT NULL COMMENT 'null 表示永久',
  `visit_count` INT NOT NULL DEFAULT 0,
  `last_visit_at` DATETIME DEFAULT NULL,
  `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `update_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_folder_share_user_category` (`user_id`, `category_id`),
  UNIQUE KEY `uk_folder_share_token` (`token`),
  KEY `idx_folder_share_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='云端文件夹分享';
```

> 一个用户对一个分类只有一条记录：重新生成 = 换 token；撤销 = status=0。与文档分享表保持一致的语义。

## 4. 接口契约（三端按此并行开发）

### 4.1 管理端（Tau 调用，需登录）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/miniProgram/cloud/categories/{categoryId}/folder-share` | 创建或重新生成；body `{ password?: string, expiresInDays?: number, includeSubCategories?: boolean }` |
| GET | `/miniProgram/cloud/categories/{categoryId}/folder-share` | 查询当前分享状态 |
| DELETE | `/miniProgram/cloud/categories/{categoryId}/folder-share` | 撤销（status=0） |

响应体（POST/GET 一致）：

```json
{
  "shared": true,
  "token": "32位url安全串",
  "url": "/s/f/32位url安全串",
  "hasPassword": false,
  "expiresAt": "2026-11-28 00:00:00",
  "includeSubCategories": true,
  "docCount": 12,
  "created": true
}
```

未分享时 GET 返回 `{ "shared": false }`。

### 4.2 公开页（免登录，`/blog/share/folder/**` 需补进 `SecurityConfig.PUBLIC_PATHS`）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/blog/share/folder/{token}` | 目录数据；有密码时 `needPassword=true`、`docs=[]` |
| POST | `/blog/share/folder/{token}/verify` | body `{ password }`；成功返回带 `ticket` 的目录数据 |
| GET | `/blog/share/folder/{token}/docs/{docId}?ticket=` | 文本类文档正文（markdown/code/text）；非文本返回 415 语义错误 |
| GET | `/blog/share/folder/{token}/docs/{docId}/assets/{assetId}?ticket=` | 文档内图片（复用 CloudDocAssetService 的公开取图逻辑，按 folder token 校验归属） |

目录响应：

```json
{
  "title": "JavaGuide",
  "authorName": "栗子",
  "updatedAt": "2026-10-28 18:00:00",
  "hasPassword": false,
  "needPassword": false,
  "ticket": null,
  "docCount": 2,
  "docs": [
    {
      "docId": "2114279859393396737",
      "title": "README.md",
      "kind": "markdown",
      "size": 12345,
      "version": 3,
      "updatedAt": "2026-10-28 12:00:00"
    }
  ]
}
```

正文响应：`{ "docId", "title", "kind", "content" }`。

### 4.3 安全要求（与现有文档分享对齐）

- token：32 位 URL 安全随机串（复用现有 token 生成工具）；
- 密码：沿用文档分享的 PBKDF2 方案与常量时间比较；错误次数/频率限制复用 `ShareRateGuard` 类机制；
- 过期/撤销/分类删除/token 不存在 → 统一 404；
- `docs/{docId}` 必须校验：`doc.user_id = share.user_id`、`doc.is_deleted = 0`、`doc.category_id ∈ 分享分类（含子分类时按子树展开）`；
- 预览 `ticket`：有密码的分享，验密成功后下发 ticket，取正文/图片必须带 ticket（防绕过）；
- 公开页只暴露标题/类型/大小/更新时间/作者显示名，不暴露 path、categoryId、tags 等私有字段。

## 7. 验收标准

- [ ] Tau 右键分类「一键分享文件夹」→ 生成链接并可复制；再次打开显示已分享状态；重新生成旧链接立即失效；撤销后 404。
- [ ] 公开页免登录可看目录与文本类文档正文；markdown 流程图/表格/折叠块/代码正常；图片能显示。
- [ ] 设置密码后：无 ticket 打不开正文/图片；错误密码有限流；正确密码可读。
- [ ] 有效期到期后 404；删除分类后 404。
- [ ] 越权：用 A 的 folder token 访问 B 的 docId（或在别的分类下）→ 404。
- [ ] 后端单测 + Tau 单测 + admin-pro `vue-tsc` 全绿。

## 8. 风险

| 风险 | 对策 |
| --- | --- |
| 新增 DDL 影响线上（刚经历误删事故） | 只新增表、不改旧表；执行前 `mysqldump` 备份；DDL 幂等可重复执行 |
| 公开页暴露私密文档 | 严格校验 owner + 分类归属；只暴露白名单字段；有密码必须 ticket |
| 大目录（数百文档）页面性能 | 目录接口分页上限（如 500）+ 前端懒加载正文（点开才取） |
| 二进制文档无法在线预览 | v1 明确卡片提示；后续可复用 office→PDF 转换链路（需登录态替代方案） |
| token 泄露 | 支持撤销与重新生成；记录 visit_count/last_visit_at 便于审计 |
